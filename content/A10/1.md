# A10. 언어고르기와 서버감잡기

<div class="tldr"><b>3줄요약</b>

1. 언어 고민하지 마라. **첫 앱은 AI가 추천하는 거 그냥 써라**
2. 대충: 정리 스크립트는 **Python**, 화면 있는 웹앱은 **JavaScript/TypeScript**
3. 서버는 **"남의 컴퓨터 빌려 쓰기"**. 첫 배포는 Vercel 같은 데 올리면 끝 (B9)

## 1. 언어 고르기 1분 컷

| 하고 싶은 거 | 보통 추천 |
|---|---|
| 엑셀·PDF·파일 정리 스크립트 | **Python** |
| 화면 있는 웹앱 | **JavaScript / TypeScript** (+ React, Next.js) |
| 내 컴에서만 쓰는 간단한 화면 | **HTML 파일 하나** |
| 폰 앱 | 처음엔 웹앱으로 시작 추천 (폰 브라우저로 열면 됨) |

> AI한테: "비전공자인데 이런 거 만들고 싶어. 제일 쉬운 방법 추천해주고 이유도 3줄로"

### 언어 이름 정리 (구분만)

| 이름 | 한 줄 |
|---|---|
| Python | 데이터·자동화·AI 쪽 국민 언어 |
| JavaScript | 웹 브라우저의 기본 언어 |
| TypeScript | JS + 실수 방지 기능 |
| Java / Kotlin | 대기업 서버, 안드로이드 |
| Swift | 아이폰 앱 |
| SQL | DB랑 대화 (A7) |

## 2. 프레임워크·라이브러리

| | 비유 | 예 |
|---|---|---|
| **라이브러리** | 부품 (내가 가져다 씀) | 차트 그리기, 날짜 계산 |
| **프레임워크** | 식당 설계도 (그 틀에 맞춰 씀) | React, Next.js, Django |

남이 만든 거 쓰면 빠른데, **버전**이 안 맞으면 터짐. 그래서 "내 컴에선 되는데" 사건이 생김 (B9).
