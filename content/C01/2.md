## 4. 첫 대화

```bash
cd ~/Documents/연습폴더
claude
```

"이 폴더 믿어도 됨?" → **Yes** (모르는 폴더면 No)

| 하고 싶은 거 | 이렇게 |
|---|---|
| 새 대화 | `claude` |
| 방금 대화 이어서 | `claude -c` |
| 대화 이름 붙이기 | `/rename 가계부작업` |
| 이름으로 다시 열기 | `claude -r "가계부작업"` |
| 지난 대화 목록 | `/resume` |
| 파일 콕 집기 | `@` 치고 파일 선택 |
| 끝내기 | `/exit` |

### 되돌리기 = `Esc` 두 번

체크포인트 선택 화면을 열고 돌아갈 지점을 고르는 기능입니다. 파일 편집 복구 범위는 도구와 작업에 따라 다르며, 터미널 명령으로 실행한 이동·삭제까지 모두 되돌려 주지는 않습니다. 중요한 파일은 별도로 백업하세요.

## 5. 첫 실전: 다운로드 폴더 정리

1. 가짜 파일 몇 개를 넣은 **별도 연습 폴더**에서 `claude` 실행
2. **`Shift+Tab`** 눌러서 **Plan 모드** (계획만 세우고 손 안 댐. C2에서 자세히)
3. 말하기:
> 이 폴더 파일들을 종류별(문서/이미지/압축/설치파일)로 나눌 계획 세워줘. 아직 옮기지 마. 3개월 넘은 설치파일은 목록만 따로.
4. 계획 맘에 안 들면 고쳐달라고
5. 괜찮으면 일반 모드로 돌리고 "계획대로 해줘"

<div class="danger"><b>이거 모르면 큰일남</b>

- **파일 이동·삭제는 `Esc Esc`로 안 돌아옴.** 그래서 중요한 폴더면 "삭제해줘" 말고 **"목록만 보여줘"**부터
- **진짜 개인 자료·회사 자료 폴더에서 연습 금지.** 연습 폴더 따로
