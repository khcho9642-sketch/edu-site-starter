3. **`Esc` 두 번**으로 체크포인트 선택. 파일 이동·삭제는 별도 백업 필요

## 1. 챗봇이랑 뭐가 다름?

챗봇: "이렇게 하시면 됩니다~" 하고 **말만 함**. 복붙은 내가 함.
클코: "ㅇㅋ 제가 할게요" 하고 **파일을 직접 열고, 고치고, 실행함**.

우리가 평소 쓰는 Claude 앱(챗봇)은 이렇게 생겼음. 질문하면 화면에 답 보여주는 데서 끝남.

![Claude 앱 홈 화면. 가운데 입력창에 질문을 적는다](/images/c1/home-input.png)

![Claude 앱 대화 예시. 질문하면 화면에 답이 뜬다](/images/c1/chat-example.png)

클코는 여기서 한 발 더 감. **내 폴더 안의 파일을 직접 읽고, 고치고, 명령까지 실행함.**

| | 일반 챗봇 | 클코 |
|---|---|---|
| 파일 | 내가 업로드 | 폴더째로 알아서 읽음 |
| 결과 | 답변 텍스트 | 실제로 바뀐 파일 |
| 비유 | 전화로 조언해주는 선배 | 옆자리 앉은 신입 |

> 처음엔 **"하나하나 확인받는 신입"**으로 쓰다가, 믿음 생기면 맡기는 범위를 넓혀라

## 2. 어디서 쓰냐

| 방법 | 누구한테 | 특징 |
|---|---|---|
| **데스크톱 앱** (Code 탭) | 검은 창 무서운 사람 | 클코 내장. 설치 따로 안 해도 됨 |
| **터미널** | 좀 해본 사람 | 기능 제일 많음 (A4 참고) |
| **VS Code 확장** | 코드 편집기 쓰는 사람 | 편집기 안에서 같이 |

이 강좌는 터미널 기준. 명령어가 공통이라서.

## 3. 설치 (진짜 한 줄)

**맥 / 리눅스**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**윈도우 (PowerShell)**
```powershell
irm https://claude.ai/install.ps1 | iex
```

> 윈도우 유저: **Git for Windows 먼저 깔아라.** 없으면 클코가 길 잃음

확인:
```bash
claude --version
claude doctor
```
