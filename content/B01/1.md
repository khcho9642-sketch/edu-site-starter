# B01. 뭘 만들지부터

<div class="tldr"><b>3줄요약</b>

1. AI한테 **"가계부 앱 만들어줘"** 하면 AI 상상 속 가계부가 나옴. 니 거 아님
2. 먼저 **누구의 / 어떤 불편을 / 지금 어떻게 하고 있는지** 3개 적어라
3. AI랑 개발할 때 제일 비싼 실수 = **잘못된 걸 잘 만드는 거**

</div>

## 0. 개발 7단계 지도 (B 과정 전체)

```
① 사전분석 → ② 요구사항 → ③ 설계 → ④ 구현 → ⑤ 검증 → ⑥ 배포 → ⑦ 운영
   B1          B2·B3        B4      B5·B6    B7·B8     B9       B10
```

거창해 보이지만 혼자 만드는 작은 앱이면 단계당 30분~하루임.

## 1. 썰

> 야근요정님이 "가계부 앱 만들어줘" 시킴
> → AI가 로그인, 예산 설정, 친구랑 공유, 그래프 10종 있는 거 만듦
> → 3시간 걸림, 버그 투성이
> → 정작 필요한 건 "카드 명세서 넣으면 카테고리별 합계"였음
> → 다 버림

## 2. 사전분석 = 3가지 질문

| 질문 | 나쁜 답 | 좋은 답 |
|---|---|---|
| **누가** 씀? | 모든 사람 | 나 + 자취하는 동생 |
| **뭐가** 불편함? | 가계부가 불편함 | 카드 명세서 엑셀을 매달 손으로 분류함. 1시간 걸림 |
| **지금은** 어떻게 함? | 그냥 함 | 은행앱에서 엑셀 받음 → 한 줄씩 보고 식비/교통 적음 → 피벗 |

**지금 방식(AS-IS)**을 구체적으로 적어야 **바뀐 모습(TO-BE)**이 보임.
