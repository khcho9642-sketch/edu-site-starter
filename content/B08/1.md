# B08. 보안 개인정보

<div class="tldr"><b>3줄요약</b>

1. **회사 자료는 회사 규정이 먼저.** 외부 AI에 넣어도 되는지 확인부터
2. **비밀값(.env, API 키, 비밀번호)은 코드·Git·채팅·캡처에 절대 넣지 마라**
3. 개발·연습은 **가짜 데이터.** 진짜 데이터는 가리고(마스킹) 넣어라

</div>

## 0. 왜 진지하냐

가계부만 해도 카드번호, 계좌, 어디서 뭘 샀는지 다 나옴. 회사 자료면 고객 정보, 매출, 인사 정보.
**한 번 새면 주워담기 불가.** 이 강은 체크리스트 그대로 지켜라.

## 1. 데이터 3등급

| 등급 | 예시 | AI에 넣어도 됨? |
|---|---|---|
| 🟢 **공개** | 뉴스, 공개 자료, 가짜 데이터 | ㅇㅇ |
| 🟡 **내부** | 회사 업무 절차, 내부 양식 | **회사 정책 확인 후** |
| 🔴 **민감** | 주민번호, 카드·계좌번호, 건강, 급여, 고객명+연락처 | **가린 뒤에만** 또는 금지 |

## 2. 비밀값 관리

| ❌ 하지 마 | ✅ 이렇게 |
|---|---|
| 코드에 `key = "sk-abc..."` | `.env` 파일에 두고 코드는 이름으로 불러옴 |
| `.env`를 Git 커밋 | `.gitignore`에 `.env` (A9) |
| AI 채팅에 키 붙여넣기 | "`.env`에 KEY라는 이름으로 넣었어" 이름만 |
| 캡처해서 단톡에 공유 | 공유 금지 |

### 털렸으면?

**파일 지우는 걸로 끝 아님.** 기록·로그에 남음.
→ **즉시 그 키 폐기 + 새로 발급.** 이게 유일한 정답.
