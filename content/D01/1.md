## [강좌] C01. 앱 설치와 첫 대화 — Code부터 누를 필요 없음

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 일반 대화, 업무 작업(Cowork가 보이면 해당 선택), Code 화면 비교

> 먼저 읽을 강의: 선행 강의 없음.

## 3줄요약

1. Desktop은 대화·자료 작업·앱 개발을 시작하는 입구다. 일반 대화에서도 파일을 만들 수 있다.
2. 앱 설치, 기능 이용 자격, 폴더 접근 권한은 서로 다른 확인 항목이다.
3. 첫 성공은 답변을 받는 것에서 끝나지 않는다. 결과 파일을 저장하고 열어봐야 한다.

## 1. 오늘의 결과와 준비물

목표는 가짜 지출 자료를 읽고 `첫_결과.md` 한 개를 저장하는 것. 실제 회사 파일은 쓰지 않는다. [지출 샘플](/desktop-materials/expenses)을 준비하고, 탐색기에서 `Documents/Claude_연습/입력`과 `출력` 폴더를 만든다.

## 2. 설치하고 내 화면 확인하기

1. [공식 다운로드](https://claude.com/download)에서 Windows용 앱을 받고 설치한다. Mac은 macOS용을 선택한다.
2. 앱을 열고 본인 계정으로 로그인한다. 무료 계정의 기본 대화와 유료·조직 설정이 필요한 업무 작업·Code의 자격을 구분한다. 보이지 않는 기능 때문에 바로 결제하지 말고 공식 지원 범위부터 확인한다.
3. 입력창에 Chat/Cowork 선택이 있으면 간단한 질문은 Chat, 여러 단계의 자료 작업은 Cowork에서 시작한다. 선택이 없는 통합 화면이면 같은 입력창에서 요청한다.
4. Code는 프로젝트 파일을 수정하고 앱을 만드는 작업에 쓴다. 오늘 실습에서는 Code를 열 필요 없다.
5. 파일 생성이 막히면 설정에서 **Capabilities / Create and edit files** 또는 **Code execution and file creation** 항목과 조직 정책을 확인한다. 제공되지 않으면 표·Markdown 답변을 복사해 메모장에 저장하는 대체 실습으로 진행한다.
