## 3. "안 할 것"이 왜 제일 중요하냐

| 안 적으면 AI가 하는 짓 | 결과 |
|---|---|
| 로그인 기능 추가 | 비밀번호 관리, 보안 문제 생김 |
| 은행 API 연동 시도 | 인증 지옥 |
| 그래프 10종 | 9개는 안 봄 |
| 다크모드 | 버그 2배 |

> 안 할 것 = **"다음 버전에 할 것"**이라고 생각해라. 영원히 안 하는 게 아님

## 4. AI랑 같이 쓰기

혼자 다 쓰지 마라. AI가 질문 잘 함.

> 가계부 미니앱 만들고 싶어. 바로 만들지 말고 기획서 한 장 같이 쓰자. 나한테 질문 5개만 해줘. 그다음에 '누구/문제/바뀐모습/성공기준/안 할 것/데이터' 형식으로 정리해서 `기획서.md`로 저장해줘.

AI가 "환불 건은 어떻게 처리해요?", "현금 지출도 넣어요?" 이런 거 물어봄. **그게 기획의 핵심임.**

<div class="danger"><b>이거 모르면 큰일남</b>

- 기획서는 **파일로 저장.** 머릿속에만 있으면 AI는 모름
- 바꿔도 됨. 대신 **파일을 고쳐라**

</div>
