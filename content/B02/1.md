# B02. 기획서 한장컷

<div class="tldr"><b>3줄요약</b>

1. 기획서 = **누구 / 문제 / 바뀐 모습 / 성공 기준 / 안 할 것 / 데이터** 6칸
2. **"안 할 것"** 안 적으면 AI가 친절하게 다 만들어줌. 그리고 다 버그 남
3. 성공 기준은 **숫자로.** "편하게"는 기준 아님

</div>

## 1. 기획서 한 장 템플릿 (복붙해서 써라)

```markdown
# 기획서: 가계부 미니앱

## 1. 누가 쓰나
- 나 (+ 나중에 자취하는 동생)

## 2. 지금 뭐가 불편한가 (AS-IS)
- 카드 명세서 엑셀을 매달 손으로 분류함. 87건, 70분
- 분류 기준이 달마다 달라서 비교가 안 됨

## 3. 바뀐 모습 (TO-BE)
- 명세서 CSV 넣으면 가게 이름 보고 카테고리 자동 분류
- 월별·카테고리별 합계 표

## 4. 성공 기준 (숫자로!)
- 100건 처리 1분 이내
- 합계가 엑셀 SUM이랑 100% 일치
- 자동 분류 못 한 건 "미분류"로 따로 보여줌

## 5. 이번엔 안 할 것
- 로그인 / 여러 명 동시 사용 / 은행 자동 연동 / 예산 알림 / 폰 앱

## 6. 쓰는 데이터
- 지출 (날짜, 가게, 금액, 카테고리)
- 가게→카테고리 규칙표 (예: "김밥" 들어가면 식비)
- ※ 연습은 가짜 데이터로
```

## 2. 성공 기준 좋은 예 / 나쁜 예

| ❌ 기준 아님 | ✅ 기준 |
|---|---|
| 빠르게 | 100건 1분 이내 |
| 정확하게 | 합계가 엑셀 SUM과 일치 |
| 편하게 | 클릭 3번 안에 결과 |
| 예쁘게 | (빼라. 첫 버전엔 필요 없음) |

**누가 봐도 O/X 판정 가능해야 기준임.**
