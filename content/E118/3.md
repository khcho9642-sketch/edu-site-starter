## 숙제

1. 새 브랜치에서 README 합계 표를 추가하고 PR을 만든다.
2. Files changed에서 변경된 파일 이름과 줄 수를 메모한다.
3. 직접 계산한 확정 합계와 README 숫자를 대조한 뒤 머지한다.


[확인 퀴즈 5문항 풀기](/lessons/E118/quiz)

## 념글 박제

PR = 머지 전 마지막 검문소. Files changed 안 읽고 누르면 검문소가 아니라 톨게이트 하이패스임.
