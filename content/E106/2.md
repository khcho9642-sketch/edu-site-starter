## 3. 예상 결과와 교차검증

| 확인 항목 | 기대값 |
|---|---|
| 전체 거래 수 | 6건 |
| 확정 금액 거래 | 5건 |
| 미확정 금액 거래 | 1건, T004 |
| 환불 | T005, -2,000원 |
| 확정 합계 | 28,000원 |
| 식비 / 교통 / 쇼핑 / 구독 확정 합계 | 10,000 / 3,000 / 10,000 / 5,000원 |

기타의 금액은 T004가 미확정이므로 “기타 총액 0원”으로 확정하지 않는다. 보고서 문장은 **“확인된 5건 합계 28,000원, 금액 미확정 1건 별도”**로 쓴다.

다운로드한 CSV를 Excel에서 열어 금액 열이 숫자인지 확인한다. 정제 출력이 안내의 7열 구조라면 금액은 D열이고 `=SUM(D2:D7)`로 대조할 수 있다. 열 배치가 다르면 실제 금액 열을 선택한다. Excel이 없으면 숫자 12,000+3,000+10,000-2,000+5,000을 계산기로 합산해 비교한다.

## 4. 막혔을 때

- 30,000원이면 환불 행 T005가 집계에서 빠졌는지 확인한다. 32,000원이면 -2,000원이 +2,000원으로 바뀌었는지 확인한다. 행별로 대조한다.
- 0으로 채운 빈 값이 있으면 정제를 되돌려 미확정으로 남긴다.
- CSV 한글이 깨지면 UTF-8 인코딩으로 저장했는지 확인하고 Excel의 텍스트/CSV 가져오기에서 인코딩을 선택한다.
- 수식·병합셀이 있는 실제 Excel은 원본을 보존하고 필요한 시트·범위를 특정한다. 무조건 값만 남기는 방식으로 수식을 지우지 않는다.

**내 화면에서:** 비로그인 웹에서는 텍스트 정제 결과를 확인했습니다. 두 번째 그림은 공통 기준을 설명하는 Claude 다운로드 CSV 검산표이며 ChatGPT 파일 생성 증거가 아닙니다. 다운로드 파일이 없으면 CSV 코드 블록을 UTF-8 파일로 저장한 대체 실습입니다.

2. 정제 결과는 지정한 7열로 요청합니다. 금액_원에는 숫자 또는 빈 값만, 미확정은 검토상태에 넣습니다.
3. 다운로드한 CSV를 다시 열어 행 수·T004 빈칸·T005 음수·합계를 대조합니다. XLSX·차트가 없으면 CSV만 만들었다고 정확히 기록합니다.

## ChatGPT 시작 화면과 검수 보강

ChatGPT의 첨부 가능한 대화 또는 Work에서 같은 샘플을 사용한다. 파일 생성이 제공되지 않으면 정제표·집계표·차트 설계를 MD로 남긴다. 표·CSV·XLSX·차트의 실제 생성 여부를 구분한다.

기존 GPT D05의 원본 보존·계산식·예외표 검수를 흡수했다. 이번 공통 원본은 T001~T006 여섯 행이며 X002 중복이 있는 예전 40,000원 자료와 다르다. 중복을 발견하지 않았는데 임의로 한 행을 지우지 않는다. 확인된 합계 28,000원을 미확정 금액까지 포함한 최종 총액이라고 부르지 않는다.
