# C1 만화 생성 지시문 (Codex CLI용)

C1 "클로드 코드 기본기" 5개 단원 각각에 들어갈 민수 캐릭터 4컷 만화 지시문입니다.
Codex CLI가 이 문서를 읽고 이미지를 생성해서 아래 **출력 경로**에 저장하면,
`content/C1/*.md`에는 이미 이미지 참조가 들어가 있어서 그대로 렌더링됩니다.

## 공통 스타일 가이드

- **그림체**: 플랫 벡터 일러스트, 부드러운 라운드 형태, 외곽선 있음. 사실적인 묘사가 아닌 심플한 캐릭터 일러스트.
- **색상**: 사이트 톤에 맞춰 크림/베이지 배경(#F5F1E8 계열) + 민트·틸 포인트 컬러(#2F6F62 계열). 과하게 화려한 색 지양.
- **캐릭터 "민수"**: 30대 비전공 사무직 직장인. 짧은 머리, 무난한 체크 셔츠 또는 가디건, 안경은 선택(모든 컷에서 동일하게 유지). 표정 변화가 풍부해야 함(당황·몰입·깨달음·안도 등).
- **텍스트**: 말풍선·캡션은 모두 한국어, 폰트는 둥글고 읽기 쉬운 서체. 화면 속 UI 텍스트를 직접 재현하지 말고 "화면" 느낌만 간단한 사각형 + 아이콘으로 표현(저작권·브랜드 요소 재현 금지).
- **형식**: 2x2 그리드 4컷, 완성 이미지 1장. 권장 해상도 1000×1000px (컷 사이 여백 20px, 배경색 통일).
- **파일명 규칙**: `public/images/c1/comic-{단원번호}.png`

## comic-1.png (1단원 · Claude 앱과 Claude Code, 무엇이 다른가)

1. 민수가 책상에서 노트북 두 창을 번갈아 보며 "어... 이거 둘이 뭐가 다른 거지?" (당황한 표정, 물음표 효과)
2. 왼쪽 화면(Claude 앱 느낌의 심플한 말풍선 아이콘)을 가리키며 "하나는 그냥 글로 대답만 해주고,"
3. 오른쪽 화면(폴더·파일 아이콘이 화면 안에서 움직이는 느낌)을 가리키며 "하나는 파일을 직접 열어서 고쳐준다고?"
4. 민수가 포스트잇에 "앱 = 대화만 / 코드 = 파일도 직접!"이라고 적어 붙이며 밝은 표정으로 "아하, 이제 알겠다!"

## comic-2.png (2단원 · 화면 둘러보기)

1. 민수가 사이드바 아이콘들을 하나씩 손가락으로 짚으며 "이 메뉴들은 다 뭐지?" (살짝 막막한 표정)
2. 아티팩트 메뉴(문서 아이콘)를 눌러보고 "오, 내가 만든 문서들이 여기 모여있네"
3. Claude Code 화면에서 오른쪽 패널(저장소·브랜치 표시)을 보며 "여기엔 지금 다루는 저장소랑 브랜치가 뜨네"
4. 파일 패널을 열어 실제 폴더 목록을 보고 놀란 표정으로 "진짜 내 프로젝트 파일이 그대로 보이잖아!"

## comic-3.png (3단원 · 대화 다루기)

1. 민수가 "보고서 정리해줘"라고 대충 입력하고, 화면에 "어떤 보고서요?"라는 되물음이 뜨며 당황
2. 동료가 옆에서 어깨를 두드리며 "어느 폴더, 뭘 어떻게 정리할지까지 적어야지"
3. 민수가 다시 "reports 폴더 10월 엑셀에서 지점별 매출 합계만 새 시트로 정리해줘"라고 구체적으로 입력
4. 깔끔하게 정리된 결과 화면을 보며 엄지를 척 들고 "이제 좀 알겠다!"

## comic-4.png (4단원 · 세션과 권한)

1. 민수가 새 대화창을 열고 "어제 말한 거 기억하지?"라고 묻는데, 화면 반응이 "처음 뵙겠습니다" 느낌이라 당황
2. 민수가 머리를 긁적이며 "아... 세션이 다르면 다 까먹는구나"라고 혼잣말
3. 삭제 요청 확인 버튼("허용") 앞에서 손을 멈추고 내용을 다시 읽는 신중한 표정
4. 확인 후 안전하게 진행된 결과를 보며 안도하는 표정으로 "한 번 더 읽어보길 잘했다"

## comic-5.png (5단원 · 적용·내 업무에 연결하기)

1. 월요일 아침, 민수가 지난주 매출 엑셀 파일을 열어보며 한숨 쉬는 모습
2. 구체적인 지시문을 적어 보내고, 화면에 "실행됨 명령 1개" 같은 처리 표시가 뜨는 걸 지켜봄
3. 결과 파일을 열어 숫자를 손가락으로 짚으며 하나하나 확인하는 민수
4. 팀장에게 보고서를 전달하고 여유롭게 커피를 마시며 "오늘은 일찍 끝났네" 미소
