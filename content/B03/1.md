# B03. MVP와 할일쪼개기

<div class="tldr"><b>3줄요약</b>

1. **MVP** = "이것만 되면 쓸 만하다"의 최소 버전. 처음부터 오토바이 만들지 마라
2. 기능은 **"~할 수 있다"** 문장 + **"다 된 기준"** 세트로
3. 할 일은 **끝날 때마다 눈으로 확인 가능한 크기로 5~7개.** 간트차트 필요 없음

</div>

## 1. MVP: 판자 → 킥보드 → 자전거

| 버전 | 내용 | 비유 |
|---|---|---|
| **v0.1 (MVP)** | CSV 넣으면 월별 합계 표 | 바퀴 달린 판자 |
| v0.2 | + 카테고리 자동 분류 | 킥보드 |
| v0.3 | + 차트 | 자전거 |
| v1.0 | + 웹에 올려서 동생도 씀 | 오토바이 |

**판자 타보니까** "어 카테고리별이 더 급하네" 같은 게 보임. 처음부터 오토바이 설계하면 엔진 만들다 지침.

## 2. 기능 = 문장 + 다 된 기준

| 기능 (~할 수 있다) | 다 된 기준 (O/X 가능하게) |
|---|---|
| CSV 파일을 선택해서 불러올 수 있다 | 가짜 30건 넣으면 30행 보임 |
| 월별 합계를 볼 수 있다 | 11월 합계 = 엑셀 SUM |
| 이상한 값은 "확인필요"로 표시된다 | 금액에 "만원" 넣은 행만 빨간색 |
| 결과를 CSV로 내보낼 수 있다 | 내보낸 파일이 엑셀에서 열림 |

이 "다 된 기준"이 B7에서 **테스트**가 됨. 지금 써두면 나중에 편함.

## 3. 할 일 쪼개기

거창한 WBS·간트차트 필요 없음. 체크리스트면 됨.

```
[ ] 1. 화면 뼈대 (파일 선택 버튼 + 빈 표 + 안내 문구)
[ ] 2. CSV 읽어서 표에 보여주기
[ ] 3. 월별 합계 계산
[ ] 4. 이상한 값 "확인필요" 표시
[ ] 5. 결과 CSV로 내보내기
```

### 적당한 크기 판단

| ❌ 너무 큼 | ✅ 적당 | ❌ 너무 작음 |
|---|---|---|
| "백엔드 구현" | "CSV 읽어서 표에 보여주기" | "버튼 색 정하기" |
| 끝났는지 모름 | 끝나면 눈으로 확인됨 | 할 일 50개 됨 |
