# A04. 검은창 기초

<div class="tldr"><b>3줄요약</b>

1. 터미널 = **마우스 대신 글자로 컴퓨터한테 시키는 창.** 안 무서움
2. 알아야 할 건 **"지금 어디 있냐(경로)"** 하나. 나머지는 클코가 함
3. 명령어 5개면 생존 가능: `pwd` `ls` `cd` `cd ..` `mkdir`

</div>

## 1. 터미널이 뭔데

| 마우스로 | 터미널로 |
|---|---|
| 폴더 더블클릭 | `cd 폴더이름` |
| 폴더 안 보기 | `ls` (윈도우 PowerShell은 `dir`도 됨) |
| 새 폴더 | `mkdir 새폴더` |

똑같은 일을 **글자로** 하는 것뿐임. 클코는 이 창 안에서 일함.

### 여는 법

| OS | 방법 |
|---|---|
| 윈도우 | 시작 → "터미널" 또는 "PowerShell" |
| 맥 | Spotlight(⌘+Space) → "터미널" |

> 클로드 데스크톱 앱 쓰면 터미널 안 열어도 됨. 근데 원리는 알아두면 덜 헤맴

## 2. 경로 = 파일의 주소

```
C:\Users\홍길동\Documents\가계부\지출.csv     ← 윈도우
/Users/hong/Documents/가계부/지출.csv         ← 맥
```

| 용어 | 뜻 |
|---|---|
| **절대경로** | 맨 꼭대기부터 쓴 전체 주소 |
| **상대경로** | 지금 위치 기준 주소. `./지출.csv` = 여기 있는 지출.csv |
| `~` | 내 홈 폴더 (`/Users/hong`) |
| `..` | 한 칸 위 폴더 |
