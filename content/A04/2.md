## 3. 생존 명령어 5개

| 명령 | 뜻 | 비유 |
|---|---|---|
| `pwd` | 지금 어디야? | 지도에서 내 위치 |
| `ls` | 여기 뭐 있어? | 서랍 열어보기 |
| `cd 폴더` | 그 폴더로 들어가 | 방 들어가기 |
| `cd ..` | 한 칸 위로 | 방에서 나오기 |
| `mkdir 이름` | 폴더 만들어 | 서랍 하나 추가 |

### 따라하기

```bash
cd ~/Documents
mkdir 가계부연습
cd 가계부연습
pwd
```

마지막에 `.../Documents/가계부연습`이 나오면 성공.

## 4. 에러 읽는 법

| 이런 글 나오면 | 뜻 |
|---|---|
| `No such file or directory` / `찾을 수 없습니다` | 그런 파일/폴더 없음. 경로 오타 or 위치 틀림 |
| `command not found` / `인식되지 않습니다` | 그 프로그램 안 깔렸음 |
| `Permission denied` / `액세스 거부` | 권한 없음 |

**모르면 그대로 복사해서 AI한테.** 이게 정답임.

<div class="danger"><b>이거 모르면 큰일남</b>

- **`rm` (삭제) 명령은 휴지통 안 거침.** 직접 치지 말고, 클코가 쓰려고 하면 뭘 지우는지 확인
- 폴더 이름에 **띄어쓰기** 있으면 `"따옴표"`로 감싸야 함: `cd "내 문서"`

</div>
