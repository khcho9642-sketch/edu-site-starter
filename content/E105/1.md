## [강좌] D05. 같은 설명 줄이기 — 맞춤 지침·프로젝트·AGENTS.md

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D03 · D04.

## 3줄요약

1. 개인 맞춤 지침, 업무 프로젝트 지침, Codex의 AGENTS.md는 적용 범위가 다르다.
2. 규칙은 짧게 쓰고 두 대화에서 실제 적용 결과를 확인한다.
3. 지침·메모리는 비밀값 저장소나 기술적 접근 차단 장치가 아니다.

## 1. 준비와 오늘의 결과

[보고서 견본](/chatgpt-materials/report)과 지출 샘플을 준비한다. 목표는 `지출연습` 프로젝트에 짧은 지침을 넣고 두 대화에서 결과를 비교하는 것.

## 2. 업무 프로젝트에 지침 넣기

1. 왼쪽 **Projects**에서 새 프로젝트를 만든다. 새로 시작하는 항목을 선택하고 이름을 `지출연습`으로 정한다.
2. 프로젝트의 지침·Instructions 항목을 열어 아래 내용을 넣는다. 계정에 프로젝트 기능이 없으면 `작업지침.md`로 저장해 매번 첨부하는 대체 실습을 한다.

> 답변은 한국어로 쉽게 쓴다. 금액은 원 단위로 표시한다. 확정 금액과 미확정 금액을 구분한다. 금액이 빈 거래는 0원으로 바꾸지 않는다. 원본은 보존하고 결과를 새 파일로 만든다. 보고서 수치는 제공 자료에서 확인한 것만 사용한다.

3. 프로젝트에 샘플을 추가하고 “T004의 금액을 어떻게 처리할지 설명해줘”라고 묻는다.
4. 같은 프로젝트의 새 대화에서도 같은 질문을 한다. **미확정으로 유지**하는지 확인한다.
5. 웹의 Settings → Personalization 등 현재 개인화 설정에서 공통 선호를 확인한다. 이번 프로젝트의 날짜·합계를 전역 선호에 고정하지 않는다. 데스크톱의 개인화·Codex 지침은 적용 범위를 따로 읽는다.

## 3. Codex를 사용할 때의 AGENTS.md

Codex 로컬 프로젝트에서는 `AGENTS.md`가 프로젝트 작업 지침에 사용된다. 이것은 `CLAUDE.md`를 이름만 바꾸면 모든 기능이 같아진다는 뜻이 아니다. 현재 Codex가 읽는 프로젝트 범위와 더 가까운 하위 경로 지침을 확인한다.

Codex를 이미 사용하는 사람은 연습 프로젝트에서 다음을 요청한다.

```text
이 연습 프로젝트에만 적용할 AGENTS.md 초안을 보여줘.
원본 보존, 빈 금액은 미확정, 환불 음수 유지, 결과 검수 규칙을 넣어줘.
기존 AGENTS.md 또는 AGENTS.override.md가 있으면 먼저 읽고 차이를 설명해줘.
내 개인 전역 지침이나 다른 프로젝트 설정은 바꾸지 마.
```

생성 경로·파일 내용을 확인하고 새 작업에서도 적용되는지 시험한다. 웹 프로젝트 지침과 로컬 AGENTS.md가 자동 동기화된다고 가정하지 않는다. 아직 Codex를 쓰지 않으면 이 절은 개념만 읽고 D14 이후에 실습한다.
