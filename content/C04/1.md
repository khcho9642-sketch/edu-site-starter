## [필독] 같은 잔소리 두 번 하지 마라 — CLAUDE.md와 말 잘 거는 법

<div class="tldr"><b>3줄요약</b>

1. **CLAUDE.md** = 클코가 매번 시작할 때 읽는 업무 수첩. 한 번 적으면 끝
2. 좋은 지시 3요소: **어디(파일) / 뭘 / 어떻게(결과)**
3. 기호 3개면 절반 해결: **`/`** 명령 · **`@`** 파일 · **`!`** 터미널

</div>

## 1. CLAUDE.md

새 대화 열면 클코는 **백지 상태.** 어제 "금액에 콤마 찍어"라고 했어도 까먹음.

- 만들기: 폴더에서 `/init`
- 위치:
  - 프로젝트 폴더 `CLAUDE.md` → 그 폴더 전용
  - `~/.claude/CLAUDE.md` → 내 모든 작업

### 예시

```markdown
# 작업 규칙
- 답변은 한국어로, 쉽게
- 금액은 원 단위, 천 단위 콤마
- 날짜는 YYYY-MM-DD
- 원본 파일은 덮어쓰지 말고 _수정본으로 새로 저장
- 합계 낼 땐 계산 근거 열도 같이
- 테스트는 고치지 말 것
```

| 넣을 것 | 뺄 것 |
|---|---|
| 클코가 추측 못 하는 거 (규칙, 형식, 말투) | 보면 아는 거, 자주 바뀌는 거 |
| "2칸 들여쓰기"처럼 구체적 | "깔끔하게" 같은 뜬구름 |

> **Auto Memory**: CLAUDE.md는 **내가** 쓰는 수첩, Auto Memory는 **클코가 스스로** 쓰는 메모. `/memory`로 봄

## 2. 좋은 지시 3요소

| ❌ 구린 지시 | ✅ 좋은 지시 |
|---|---|
| 엑셀 정리해줘 | `@지출.csv`에서 금액 빈 행 찾아서 목록만 보여줘. 고치지 마 |
| 에러 나요 | (에러 전체 붙여넣고) `@집계.py` 실행하니까 나왔어. 어제까진 됐어 |
| 보고서 써줘 | 지난달 `@10월보고.docx` 형식 그대로, 11월 숫자만 바꿔서 초안 |
