## [정보] 클코 쓰다가 돈 버리는 사람 특 — 작업 노트·모델·사용량

<div class="tldr"><b>3줄요약</b>

1. 클코는 **작업 노트 크기가 정해져 있음.** 차면 앞에 한 말 까먹음 → `/clear` `/compact`
2. 모델은 **베테랑(Opus) / 실무자(Sonnet) / 막내(Haiku).** 일 난이도 맞춰서
3. 대화 길게 끌면 **돈도 더 나가고 멍청해짐.** 일 하나 끝나면 `/clear`

</div>

## 1. 작업 노트 (컨텍스트)

| 명령 | 비유 | 언제 |
|---|---|---|
| `/context` | 노트 얼마나 찼나 보기 | 수시로 |
| `/compact` | 핵심만 요약해서 다시 적기 | 같은 일 계속할 때 |
| `/clear` | 새 노트로 시작 | 완전히 다른 일 시작할 때 |

### 국룰
- 70% 넘으면 `/compact` 고려
- **같은 실수 두 번 고쳐줬는데 또 틀리면** → 싸우지 말고 `/clear` 하고 더 구체적으로 다시

## 2. 모델 고르기

| 모델 | 비유 | 언제 |
|---|---|---|
| **Opus** | 베테랑 전문가 | 복잡한 일, 설계 |
| **Sonnet** | 든든한 실무자 | 일상 업무 대부분 |
| **Haiku** | 빠른 막내 | 간단한 질문, 정리 |

- 바꾸기: `/model`
- 생각 깊이: `/effort low` ~ `max` (낮을수록 빠르고 쌈)
- 이번 한 번만 깊게: 메시지에 **`ultrathink`**

> 파일 이름 바꾸는 데 Opus max = 짜장면 배달에 람보르기니
