## 0. 오늘 만들 거

B3의 MVP: **CSV 넣으면 → 표로 보여주고 → 월별 합계 + 이상한 값 "확인필요"**

**HTML 파일 하나짜리.** 서버도 DB도 없음. 더블클릭하면 브라우저에서 열림.

## 1. 준비

```
가계부앱/
├── 기획서.md      ← B2
├── 할일.md        ← B3
├── 설계.md        ← B4
├── CLAUDE.md      ← C4
└── 샘플/
    └── 지출.csv    ← 가짜 데이터
```

CLAUDE.md에 추가:
```markdown
# 이 프로젝트
- 비전공자가 쓰는 앱. 설명은 쉽게
- HTML 파일 하나로 만든다. 외부 서버 없음
- 할 일 하나 끝날 때마다 멈추고 나한테 확인받을 것
```

가짜 데이터:
> 가계부 연습용 `샘플/지출.csv` 만들어줘. 30건, 날짜/가게/금액. 일부러 금액에 "만원" 1건, 빈 칸 1건 넣어줘.
