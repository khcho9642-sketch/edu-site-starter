# A05. 엑셀시트가 DB가 되기까지

<div class="tldr"><b>3줄요약</b>

1. DB **별거 아님.** 규칙 엄격한 엑셀 시트 여러 장이라고 보면 됨
2. 엑셀은 금액 칸에 "만원" 들어가는데, DB는 **거부함.** 이게 핵심 차이
3. **빈 칸(NULL) ≠ 0.** 이거 섞이면 합계 틀어짐

</div>

## 1. 엑셀이랑 DB 차이

| | 엑셀 | DB |
|---|---|---|
| 금액 칸에 "만원" 입력 | 들어감 ㅋㅋ | **거부함** |
| 같은 파일 3명 동시 수정 | 충돌·덮어쓰기 | 알아서 줄 세움 |
| 10만 행 | 버벅 | 멀쩡 |
| 실수로 행 삭제 | Ctrl+Z 아니면 끝 | 규칙으로 막을 수 있음 |

> 엑셀 = 자유로운 노트 / DB = 양식 엄격한 장부

## 2. 기본 용어 = 엑셀 용어로 번역

| DB 용어 | 엑셀로 치면 | 가계부 예 |
|---|---|---|
| **테이블** | 시트 하나 | "지출" 시트 |
| **행 (row)** | 한 줄 | 지출 1건 |
| **열 (column)** | 항목 | 날짜, 가게, 금액 |
| **자료형** | 셀 서식. 근데 **강제**임 | 금액 = 숫자만 |

### 자료형 예시

| 열 | 자료형 | 들어가면 안 되는 것 |
|---|---|---|
| 날짜 | 날짜 | "어제", "11월쯤" |
| 금액 | 정수 | "만원", "12,000원" |
| 카테고리 | 글자 (목록 중 하나) | 오타 "식뷔" |
| 메모 | 글자 | (자유) |
