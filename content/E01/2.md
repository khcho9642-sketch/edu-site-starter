## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
다음 가짜 안내를 처음 듣는 동료에게 세 문장으로 설명해 줘.
새싹팀 교육: 2026-12-03 14:00~15:00, 온라인, 정원 12명.
신청 기한: 2026-12-01. 접속 링크와 녹화 여부는 미정.
주어진 사실만 사용하고 미정인 것은 미정이라고 적어 줘.
```

### 이어서 보낼 요청

```text
방금 답에서 날짜·시간·정원·미정 항목을 따로 뽑아 원문과 대조하는 표를 만들어 줘. 새 사실은 추가하지 마.
```

## 6. 기대 결과와 직접 검수

- [ ] 교육일 12월 3일과 신청 기한 12월 1일이 구분됩니다.
- [ ] 시간 14:00~15:00와 정원 12명이 유지됩니다.
- [ ] 녹화 가능·접속 링크 확정 같은 약속이 추가되지 않습니다.
- [ ] 원문과 결과를 직접 비교한 뒤 최종 답을 D01_첫대화.md로 저장합니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 입력창이 안 보임 | 로그인과 현재 작업 공간을 확인하고 공식 웹에서 새 대화를 엽니다. |
| 답이 너무 김 | 세 문장, 동료 대상이라는 조건을 다시 지정합니다. |
