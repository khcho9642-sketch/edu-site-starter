# C06. 영수증 PDF와 보고서

<div class="tldr"><b>3줄요약</b>

1. 영수증 사진·PDF → 표(CSV)로. **못 읽은 칸은 비우지 말고 "확인필요"**
2. 보고서는 **개요 → 구조 → 초안 → Word** 순서. 지난번 완성본을 견본으로 주면 퀄 확 오름
3. 초안은 **출발점.** 숫자·이름·출처는 사람이 확인

</div>

## 1. 영수증·PDF 추출

```
영수증폴더/ 에 사진이랑 PDF 섞여 있음
→ 날짜, 가게, 금액 뽑아서 CSV로
```

### 따라하기

1. 폴더에 **5장만** 먼저:
> 이 폴더 영수증 5장에서 날짜/가게/금액 뽑아서 표로. 못 읽은 칸은 "확인필요"로 적어
2. 원본이랑 눈으로 대조 → 틀린 거 지적
3. 형식 확정되면:
> 같은 형식으로 폴더 전체 돌려서 `영수증_추출.csv`. 마지막에 총 건수, 확인필요 건수
4. C5 방식으로 월별 집계까지

### 써먹을 데

| 상황 | 예 |
|---|---|
| 개인 | 연말정산용 의료비·기부금 영수증 정리 |
| 회사 | 출장비·법인카드 영수증 정산 |
| 자영업 | 매입 영수증 월별 정리 |

### 주의
- **손글씨·흐린 사진·구겨진 감열지**는 인식률 떨어짐. "확인필요" 표시가 핵심
- 금액은 **원본과 대조 필수**
- **카드번호·개인정보는 가려라** (B8)

## 2. 보고서·문서 초안

### 순서

| 단계 | 지시 예 |
|---|---|
| ① 개요 | "11월 지출 분석 보고서 목차 5개만" |
| ② 구조 | "각 장 핵심 메시지 1문장씩" |
| ③ 초안 | "`@지출_집계.csv` 숫자로 본문" |
| ④ Word | "docx로 저장. 표는 Word 표로" |

> 정기 보고서면 **지난번 완성본을 견본으로.** "이거랑 똑같은 형식, 숫자만 바꿔" 하면 퀄 확 올라감

### 다른 문서들

| 문서 | 지시 예 |
|---|---|
| 업무 매뉴얼 | "우리 팀 월말 정산 절차를 단계별 표로. 담당·체크포인트·필요 서류" |
| 기획서 | "B2 템플릿 형식으로 이 아이디어 정리" |
| 회의 안건 | "지난 회의록 미결 사항으로 다음 안건 초안" |
