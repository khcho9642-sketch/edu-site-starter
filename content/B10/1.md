## 0. 썰

> 월요일: 가계부 앱 동생이랑 친구 2명한테 공유
> 수요일: "11월 합계가 0원이에요"
> 원인: 친구가 엑셀에서 CSV 저장할 때 인코딩이 달라서 한글 깨짐 → 금액 열 못 읽음 → 에러 숨김 처리돼서 0원 표시
> 교훈: B7 엣지 케이스 + **로그** 있었으면 10분 컷

## 1. 로그 = 블랙박스

| ✅ 남겨 | ❌ 남기지 마 |
|---|---|
| 언제, 무슨 기능, 성공/실패 | 이름, 카드번호, 계좌 |
| 에러 메시지 전체 | 비밀번호, API 키 |
| 처리 건수 ("30건 중 28건 성공") | 개인 지출 상세 |

> AI한테: "로그 추가해줘. 업로드 건수, 성공/실패/확인필요 건수, 에러 메시지. 개인정보는 남기지 마."

## 2. 터졌을 때 5단계

```
① 멈춤 → ② 확인(로그, 언제부터, 누구) → ③ 되돌림(롤백) → ④ 원인 → ⑤ 재발 방지(테스트 추가)
```

사용자한테는 **뭐가 / 영향 범위 / 언제까지** 세 개만 알리면 됨.
