## 3. 백업

| 상태 | 실제 |
|---|---|
| "백업 설정했어요" | 희망 |
| "백업 파일 있어요" | 아마도 |
| **"복구 테스트 해봤어요"** | **백업** |

- 자동 백업 + **다른 장소**에도
- 한 달에 한 번 복구 연습
- Git은 코드, 백업은 데이터 (A9)

## 4. 개선 요청 처리

| 요청 | 판단 |
|---|---|
| 버그 ("합계 틀려요") | **최우선** |
| 불편 ("버튼 찾기 힘들어요") | 다음 버전 |
| 새 기능 ("예산 알림도…") | 기획서에 적고 우선순위 정하기 |

개선도 B1~B9 흐름 그대로 반복.

## 5. 졸업작품 체크리스트

**목표: 친구 1명 이상이 링크로 접속해서 가짜 지출 CSV를 올리면 월별·카테고리별 합계를 보는 가계부 앱**

| 강 | 체크 |
|---|---|
| B1·B2 | [ ] `기획서.md` (누구/문제/성공기준/**안 할 것**) |
| B3 | [ ] `할일.md` 5개 이상 + 다 된 기준 |
| B4 | [ ] `설계.md` (화면/데이터/흐름, 갈림길 3개+) |
| B5·B6 | [ ] 할 일 하나씩 완료 + 커밋 10개 이상 |
| B7 | [ ] 엣지 케이스 7개 O/X, 기대값은 사람이 계산 |
| B8 | [ ] 보안 체크리스트 통과, 가짜 데이터만 |
| B9 | [ ] https 링크 배포, 다른 사람 접속 확인 |
| B10 | [ ] 로그(개인정보 X) + 백업 복구 1회 |

### 발표 (5분)
1. 무슨 문제를 풀었나 (전 → 후, 숫자로)
2. 데모
3. 제일 많이 막혔던 것 + 어떻게 풀었나
4. 다음 버전에 넣을 것 / **안 넣을 것**
