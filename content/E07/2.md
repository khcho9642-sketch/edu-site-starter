## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
가짜 교육 안내문과 회의 메모만 사용해 줘.
1. 결정/할 일/미정으로 구분한 표.
2. 팀장용 한 페이지 보고서: 일정, 준비 현황, 확인 필요 사항.
3. 동료용 메일 초안: 제목과 본문, 짧고 정중하게.
담당·기한·숫자는 유지. 새로운 약속이나 실제 메일 주소는 추가하지 마.
모든 결과에 초안이라고 표시. 외부 발송이나 일정 등록은 하지 마.
[교육 안내문과 회의 메모 전체 붙여 넣기]
```

### 이어서 보낼 요청

```text
메일만 더 짧게 고쳐 줘. 가람 11월 25일, 나래 11월 27일의 할 일과 기한은 유지하고 녹화·접속 링크는 미정으로 남겨 줘. 원문 대비 새 사실이 추가됐는지 확인표도 붙여 줘.
```

## 6. 기대 결과와 직접 검수

- [ ] 가람의 신청 현황표 기한은 2026-11-25, 나래의 안내 초안 기한은 2026-11-27입니다.
- [ ] 보고서와 메일에 교육 일정이 같고 녹화·링크는 미정입니다.
- [ ] 메일은 초안 상태이고 발송 완료라고 쓰지 않습니다.
- [ ] 미정 항목을 후속 확인 목록으로 남깁니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 보고서에 예산 승인이 생김 | 원문에 없는 내용을 삭제하고 근거가 있는 결정만 남깁니다. |
| 담당이 바뀜 | 할 일·담당·기한 표를 원문과 먼저 대조한 후 초안을 다시 만듭니다. |
| 발송했다고 함 | 실제 작업 기록과 도구 결과가 없으면 초안 작성으로 바로잡습니다. |
