## [정보] 웹 화면은 3형제가 만듦 + 초보가 맨날 빼먹는 화면 4가지 상태

<div class="tldr"><b>3줄요약</b>

1. 웹 화면 = **HTML(뼈대) + CSS(인테리어) + JavaScript(직원)**
2. 코드 몰라도 됨. "색 바꿔" = CSS, "누르면 계산" = JS 감만 있으면 AI랑 대화 됨
3. 화면은 **빈 상태 / 로딩 / 성공 / 실패** 4개 다 있어야 함. 이거 빼먹으면 사용자 멘붕

</div>

## 1. 웹 화면 3형제

| 이름 | 비유 | 하는 일 | 예 |
|---|---|---|---|
| **HTML** | 뼈대 | 여기 제목, 여기 입력칸, 여기 버튼 | `<button>저장</button>` |
| **CSS** | 인테리어 | 색깔, 크기, 배치 | 버튼 파란색, 둥글게 |
| **JavaScript** | 직원 | 누르면 뭔가 일어나게 | 누르면 합계 계산 |

> AI한테 시킬 때: "버튼 색 바꿔줘"는 CSS 영역, "버튼 누르면 월별 합계 보여줘"는 JS 영역. 이 감만 있으면 됨

### 크롬에서 직접 보기

아무 웹사이트에서 `F12` → Elements 탭 → 이게 HTML. 오른쪽 Styles가 CSS.
**구경만 해라.** 거기서 고쳐도 새로고침하면 원상복구됨 ㅋㅋ

## 2. 컴포넌트 = 레고 블록

화면을 **재사용 가능한 블록**으로 쪼갠 것.

```
가계부 화면
├── [헤더]
├── [지출 입력 폼]  ← 날짜칸 + 가게칸 + 금액칸 + 저장버튼
├── [지출 목록]     ← [지출 한 줄] × N개
└── [월별 합계 카드]
```

"지출 한 줄" 블록 하나 만들어두면 300번 재사용. React 같은 거 쓰면 이렇게 만듦.
