## 3. 화면은 4가지 상태를 다 그려야 함

**잘 될 때만 있는 게 아님.** 초보가 제일 많이 빼먹는 거.

| 상태 | 가계부 예시 |
|---|---|
| **비어있음** | "아직 지출이 없어요. 첫 지출을 추가해보세요" |
| **로딩 중** | 빙글빙글 (버튼은 비활성화해서 두 번 못 누르게) |
| **성공** | 표 뜸 + "저장됨" 표시 |
| **실패** | "저장 실패. 금액엔 숫자만 넣어주세요" |

AI한테 화면 시킬 때 **"빈 상태, 로딩, 에러 화면도 같이"** 한 줄 붙이면 퀄 확 올라감.

## 4. 폼(입력칸) 규칙

| 칸 | 규칙 예시 |
|---|---|
| 날짜 | 필수, 미래 날짜는 경고 |
| 금액 | 필수, 숫자만, 0보다 큼 |
| 카테고리 | 목록에서 고르기 (식비/교통/쇼핑/기타) |
| 메모 | 선택, 100자 이내 |

규칙은 **틀렸을 때 뭐라고 보여줄지**까지 정해야 끝임.

<div class="danger"><b>이거 모르면 큰일남</b>

- 저장 버튼 누른 뒤 **로딩 상태 없으면** 사람들 두세 번 누름 → 지출이 3번 저장됨
- 에러 메시지 "오류 발생" 이렇게만 쓰면 사용자는 뭘 고쳐야 할지 모름. **뭘 고치면 되는지** 써라
