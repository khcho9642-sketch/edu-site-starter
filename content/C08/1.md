# C08. PPT 리서치 스케줄 브라우저

<div class="tldr"><b>3줄요약</b>

1. PPT는 **Marp(마크다운→슬라이드)**나 **PowerPoint 애드인**으로
2. 매주 반복하는 일은 **스케줄 태스크**. 단, **수동으로 먼저 다듬고** 등록
3. 브라우저 자동화는 맛보기만. **은행·관공서 같은 민감 사이트엔 쓰지 마라**

</div>

## 1. PPT 자동 생성

### 방법 A: Marp
> 이 보고서로 Marp 슬라이드 10장. 각 장 제목 + 핵심 메시지 1문장 + 불릿 3개 이내. 발표자 노트도.

- 슬라이드 구분은 `---`
- PDF로: `marp slides.md --pdf`
- **디자인에 약함.** 중요하면 PPTX로 뽑아서 파워포인트에서 다듬기

### 방법 B: PowerPoint 애드인
파워포인트 안에서 바로 Claude. 회사 템플릿 쓸 때 편함.

## 2. 리서치

### 여러 개 비교
> A, B, C 서비스 공개 자료를 각각 따로 분석해서(서로 섞지 말고) 마지막에 비교표 하나로

| 써먹을 데 | 예 |
|---|---|
| 개인 | 노트북 3개 비교, 여행지 비교 |
| 회사 | 경쟁 서비스 비교, 도입 검토 |
| 자영업 | 동네 경쟁 가게 메뉴·가격 정리 |

### 주의
- **공개 정보만.** 회사 내부 자료 넣지 마라
- 숫자는 **추정일 수 있음.** 출처 확인
