## 3. 스케줄 태스크: 알아서 도는 루틴

예: 매일 아침 브리핑, 매주 금요일 주간 정리

### 따라하기
1. **수동으로 3번 이상 돌려봄** (결과 맘에 들 때까지 지시문 다듬기)
2. 사용하는 제품의 예약 작업 메뉴를 엽니다. Desktop·Cowork·클라우드 작업은 지원 메뉴와 실행 환경이 다릅니다.
3. 다듬은 지시문 + 시간 설정

> 예: "이번 주 한 일 정리, 다음 주 할 일 초안, 걱정거리 3개. 금요일 오후 4시."

### 주의
- 로컬에서 실행하는 예약은 컴퓨터·앱 실행 상태를 확인합니다. 클라우드 예약은 별도 실행 조건과 연결 권한을 확인합니다.
- 처음 몇 주는 결과 매번 확인

## 4. 브라우저 자동화 (맛보기)

**Claude in Chrome** 확장 깔면 클코가 브라우저 직접 조작. 반복 웹 입력·조회에 씀.

- 지원 브라우저와 설치·연결 방법은 [Claude Code 브라우저 공식 안내](https://code.claude.com/docs/en/chrome)를 확인합니다.
- **내 로그인 상태를 공유함.** 은행·관공서·쇼핑 결제 같은 민감 사이트에선 쓰지 마라
- 이 강좌는 결제·송금·은행·관공서 작업을 자동화 실습 범위에 포함하지 않습니다. 제품의 지원 범위를 안전 보장으로 해석하지 마세요.

- 브라우저 자동화 = 내 계정으로 행동함. **뭘 하는지 지켜봐라**
