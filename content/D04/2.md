## 3. 모델과 사용량 확인

- 입력창의 모델 선택기를 열고 **현재 선택 가능한 모델만** 기록한다. 모델 이름과 제공 여부는 플랜·조직 설정에 따라 달라진다.
- 먼저 기본 모델로 작은 표 정리를 해본다. 복잡한 비교나 설계는 사용 가능한 더 높은 추론 설정을 검토한다.
- 비교 실습은 같은 입력과 같은 확인 기준으로 한다. “더 길게 답함” 대신 누락·정확성·작업 시간·소비한 사용량을 비교한다.
- 계정 설정의 사용량·요금 화면에서 현재 한도와 별도 과금 설정을 확인한다. 구독 사용량 제한과 API의 사용량 과금은 같은 개념이 아니다.
- 긴 대화, 큰 첨부, 도구 실행, 병렬 작업은 사용량에 영향을 줄 수 있다. 새 대화를 열면 무조건 싸진다고 단정하지 않는다.

## 4. 예상 결과와 막혔을 때

인수인계 메모에는 확인한 내용과 확인하지 못한 내용이 구분돼 있어야 한다. 샘플의 알려진 합계는 28,000원이고 미확정 거래는 1건이지만, 정제를 아직 하지 않았다면 메모에 “집계 검증 전”이라고 써야 한다. 특정 모델이 메뉴에 없으면 설치 오류로 단정하지 말고 현재 선택 가능한 모델끼리 비교한다.
