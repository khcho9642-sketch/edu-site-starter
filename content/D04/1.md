## [강좌] C04. 모델과 작업 노트 — 어제 하던 일 이어가기

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 앱의 대화 목록·모델 선택·계정 사용량 화면
> 터미널의 /context·/compact를 필수 조작으로 사용하지 않습니다.

> 먼저 읽을 강의: C01 · C02.

## 3줄요약

1. 같은 작업은 기존 대화에서 이어가고, 주제가 바뀌면 새 대화로 분리한다.
2. 대화 요약과 프로젝트 지침·기억은 역할이 다르다.
3. 사용 가능한 모델과 사용량을 실제 화면에서 확인한다. 모델 이름만으로 비용을 단정하지 않는다.

## 1. 준비와 오늘의 결과

C01의 대화나 [지출 샘플](/desktop-materials/expenses)을 연다. 결과는 `작업인수인계.md` 한 개다.

## 2. 지난 작업 이어가기

1. 왼쪽 최근 대화·작업 목록에서 기존 작업을 연다.
2. 제목이나 이름 편집 메뉴가 있으면 `연습_지출정리`처럼 찾기 쉽게 바꾼다.
3. “지금까지 확정한 규칙과 아직 해결하지 않은 부분을 구분해줘”라고 요청한다.
4. 없는 기억을 안다고 답하면 원문 자료를 다시 첨부하고 근거를 확인한다.

> 인수인계 메모를 만들어줘. 목표, 사용한 파일명, 확정 규칙, 완료 작업, 미해결 항목, 다음 할 일, 결과 파일 위치를 적어줘. 확인하지 않은 내용을 완료했다고 쓰지 마.

5. 메모를 저장하고 새 대화에 첨부한다. 새 대화에서 **T004 금액 미확정, T005 환불**을 그대로 이해했는지 확인한다.
6. 새 대화를 열어도 파일이 삭제되는 것은 아니다. 반대로, 이전 대화 내용이 새 대화로 전부 자동 전달된다고 가정해서도 안 된다.
