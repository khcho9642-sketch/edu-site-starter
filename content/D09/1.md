## [강좌] C09. PPT·리서치·예약·브라우저 — 기능을 고르는 지도

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 일반 업무 작업, 필요할 때 브라우저·예약 작업 메뉴

> 먼저 읽을 강의: C06 · C07.

## 3줄요약

1. 문서를 파일로 만드는 일, 웹을 조사하는 일, 정해진 때 반복하는 일은 다르다.
2. PPTX는 파일 생성 기능으로 요청할 수 있다. Marp나 터미널이 필수는 아니다.
3. 예약의 실행 위치와 로컬 자료 접근 조건을 나눠 확인한다.

## 1. 오늘의 목표

가계부 결과를 설명하는 일을 네 단계로 나누고, 필요한 기능을 고르는 표를 만든다. 한 번에 전부 자동화하지 않는다.

| 원하는 결과 | 시작할 기능 | 뒤에서 따라 할 강의 |
|---|---|---|
| 검토한 숫자로 발표 자료 | 파일 생성·미리보기·다운로드 | [C10 PPT](/lessons/C10/1) |
| 여러 자료의 사실 비교 | 첨부 자료 분석, 필요하면 웹 조사 | [C11 리서치](/lessons/C11/1) |
| 매주 같은 보고 초안 | 수동 검수 뒤 예약 | [C13 예약](/lessons/C13/1) |
| 웹 화면을 열어 조사·검사 | 내장 브라우저 또는 지원되는 연결 | [C11 리서치](/lessons/C11/1) |

## 2. 기능 선택부터 계획하기

1. 일반 업무 대화에서 C06의 집계 결과를 첨부한다.
2. 다음처럼 요청한다.

> 확정 합계 28,000원과 미확정 1건을 팀에 설명하고 싶어. 발표 자료 작성, 추가 조사, 정기 보고를 별도 작업으로 나눠줘. 각 작업에 필요한 입력 자료, 도구, 결과물, 검수 방법을 적어줘. 지금은 예약이나 외부 연결을 만들지 마.

3. 계획표에서 PPT 제작에 웹 조사가 꼭 필요한지 확인한다. 제공한 자료만으로 가능한 부분을 먼저 끝낸다.
4. 발표 자료는 **편집 가능한 PPTX**를 요청하고 다운로드 후 PowerPoint에서 열어 확인한다. 미리보기만 있거나 텍스트 초안만 나온 경우를 완성 PPTX와 구분한다.
5. 리서치는 출처·기준일·확인 못 한 항목을 기록한다.
6. 예약은 수동 결과를 확인한 뒤 별도 강의에서 등록한다.
