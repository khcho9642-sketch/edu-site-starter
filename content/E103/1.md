## [강좌] D03. 계획과 권한 — 승인 버튼 읽는 법

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D01 · D02.

## 3줄요약

1. 큰 작업은 분석·계획부터 받고, 입력·결과·검수 범위를 정한다.
2. 계획을 요청하는 것과 실제 권한 설정은 다르다. 화면에 보이는 권한 선택을 확인한다.
3. 폴더·파일·계정·외부 동작의 범위를 따로 확인하고 승인 결과도 검수한다.

## 1. 준비와 오늘의 결과

[지출 샘플](/chatgpt-materials/expenses)을 첨부한다. 오늘 결과는 **실행 전 계획표와 승인 판단표**다. 실제 삭제·메일 발송·설정 변경은 실습하지 않는다.

## 2. 일반 업무 화면에서 계획부터

1. ChatGPT의 새 대화 또는 지원되는 Work 작업에 샘플을 첨부한다.
2. 다음처럼 범위를 제한한다.

> 이 자료를 정리할 계획만 작성해줘. 읽을 자료, 만들 결과물, 수정할 파일, 외부 연결 필요 여부, 검증 방법을 표로 적어줘. 지금은 파일을 옮기거나 외부로 보내지 마.

3. 계획에 없는 외부 서비스나 원본 덮어쓰기가 보이면 이유를 묻고 범위를 수정한다.
4. 정제 결과를 만들 때도 원본은 두고 별도 파일을 만들도록 요청한다. 자연어 지시는 작업 의도이며, 기술적인 접근 차단을 설정한 것과는 다르다.

## 3. Codex 앱의 권한 선택을 실제로 확인하기

Codex 앱을 쓰는 사람만 현재 대화의 권한 선택기를 확인한다. 계획 문서를 요청하는 것만으로 읽기 전용 환경이 된 것은 아니다.

| 확인할 표시 | 이번 판단 |
|---|---|
| Ask for approval | 작업 범위를 확인하며 시작할 기본 선택 |
| Approve for me | 지원되는 요청을 자동 검토에 보냄. 작업 공간의 접근 경계 자체가 넓어지는 것은 아님 |
| Full access 등 넓은 접근 | 범위와 영향을 이해하기 전 초보 연습의 해결책으로 켜지 않음 |

모든 선택지가 모든 계정에 보여야 하는 것은 아니다. 조직 정책과 현재 선택된 상태를 기록한다. Claude의 Plan·Manual·Accept edits 목록을 ChatGPT의 공통 모드라고 외우지 않는다. 메뉴가 없으면 실제 환경의 공식 안내와 관리자 정책을 확인한다. 사용자가 터미널에 `/permissions`를 입력하는 것을 기본 실습으로 두지 않는다.
