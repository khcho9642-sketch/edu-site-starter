## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
다음 공통 응답 선호를 짧은 맞춤 지침 후보로 정리해 줘.
한국어로 간결하게. 사실/추정/미확인을 구분. 원문 숫자 유지.
특정 행사 날짜나 개인 정보는 공통 지침에 넣지 않음.
별도로 새싹팀 프로젝트 지침 후보를 만들어 줘:
제공된 안내문과 회의 메모만 근거로 하고, 없는 정보는 미정.
실제 발송·공유는 이번 연습에서 하지 않음.
후보 작성만 하고 설정을 바꿨다고 말하지 마.
```

### 이어서 보낼 요청

```text
가능하면 내가 웹 설정과 가짜 교육 프로젝트에 지침을 직접 넣고 새 대화에서 시험할게. 프로젝트가 없으면 지침+원자료를 인계 MD로 묶어 줘. 설정·업로드·테스트 중 실제로 완료한 것과 아직 안 한 것을 구분해 줘.
```

## 6. 기대 결과와 직접 검수

- [ ] 공통 지침에는 교육일·이름 같은 이번 업무의 사실이 없습니다.
- [ ] 프로젝트용 지침에는 자료 범위와 미정 처리 기준이 있습니다.
- [ ] 새 대화의 교육일·정원 답이 원문과 맞는지 확인합니다.
- [ ] 직접 한 설정과 후보 문서만 작성한 상태를 구분해 기록합니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 다음 업무에 옛 날짜가 섞임 | 공통 지침에서 업무 사실을 빼고 최신 원문을 명시합니다. |
| 프로젝트가 파일을 못 찾음 | 실제 업로드·연결 여부를 확인합니다. |
| 메모리 메뉴가 없음 | 계정 설정을 확인하고 중요한 규칙은 인계 MD로 전달합니다. |
