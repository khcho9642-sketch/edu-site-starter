## [정보] 이것만 알면 개발자랑 대화 됨: 용어 20개 (나머진 몰라도 됨)

<div class="tldr"><b>3줄요약</b>

1. 개발 용어 수백 개 중 **비전공자가 실제로 마주치는 건 20개** 정도
2. 외우지 말고 **"아 그거"** 수준으로만. 모르면 AI한테 "비유로 설명해줘"
3. 특히 **에러 메시지, .env, 배포** 이 셋은 진짜 알아야 함

</div>

## 1. 장소 관련 (5개)

| 용어 | 쉬운 뜻 |
|---|---|
| **로컬** | 내 컴퓨터 |
| **서버** | 24시간 켜져서 요청 받는 컴퓨터 |
| **클라우드** | 남의 서버를 빌려 쓰는 것 (AWS, Vercel 등) |
| **배포** | 내 컴에서 만든 걸 서버에 올려서 남들도 쓰게 하는 것 |
| **도메인** | `mysite.com` 같은 주소 이름 |

## 2. 주고받기 관련 (5개)

| 용어 | 쉬운 뜻 |
|---|---|
| **요청 / 응답** | 홀이 주방에 주문 / 주방이 음식 내줌 (A1 참고) |
| **API** | 주문서 양식 = 프로그램끼리의 약속 |
| **JSON** | 주문서 쓰는 형식. `{"금액": 12000, "가게": "김밥천국"}` |
| **HTTPS** | 주고받는 내용 암호화. 주소창 자물쇠 |
| **상태 코드** | 응답에 붙는 숫자. 200 성공, 404 없음, 500 서버 터짐 (A8) |

## 3. 만들기 관련 (6개)

| 용어 | 쉬운 뜻 |
|---|---|
| **코드 / 소스** | 프로그램 설계도 (글자로 됨) |
| **라이브러리** | 남이 만든 부품. 가져다 씀 |
| **프레임워크** | 남이 만든 식당 설계도. React, Next.js 등 |
| **빌드** | 코드를 배포용으로 포장하는 것 |
| **버그** | 의도와 다르게 동작하는 것 |
| **에러 메시지** | 뭐가 터졌는지 알려주는 글. **AI한테 통째로 복붙할 것** |
