## [정보] 비전공자용 개발 세계관 지도 — 앱은 식당임 (프론트·백·DB·API)

<div class="tldr"><b>3줄요약</b>

1. 앱 = **식당**. 홀(프론트엔드) / 주방(백엔드) / 창고(DB) / 주문서(API)
2. 용어 **외울 필요 없음.** "이거 어디 문제야?" 구분만 되면 됨
3. 이 구분 하나로 AI한테 에러 물어볼 때 해결 속도 10배 빨라짐

</div>

## 1. 앱은 식당이다

```
 손님(사용자)
    │  "아메리카노 하나요"
    ▼
┌──────────┐  주문서(API)  ┌──────────┐       ┌────────┐
│ 홀        │ ────────────▶ │ 주방      │ ────▶ │ 창고    │
│(프론트엔드)│ ◀──────────── │(백엔드)   │ ◀──── │ (DB)   │
└──────────┘   음식(응답)   └──────────┘       └────────┘
```

| 식당 | 개발 용어 | 하는 일 | 가계부 앱 예시 |
|---|---|---|---|
| 홀·메뉴판 | **프론트엔드** | 손님이 보는 화면 | 지출 입력칸, 월별 표 |
| 손님 | **클라이언트** | 화면 띄우는 쪽 | 내 크롬, 내 폰 |
| 주방 | **백엔드 / 서버** | 실제 처리, 규칙 검사 | "금액이 숫자 맞나?" 검사 |
| 창고 | **DB** | 기록 보관 | 지출 300건 |
| 주문서 양식 | **API** | 홀↔주방 약속 | "지출 저장: 날짜, 가게, 금액 줘" |

## 2. 왜 알아야 함?

에러 났을 때 **"어디가 문제인지"** 짐작하면 AI도 빨리 고침.

| 증상 | 의심 장소 |
|---|---|
| 버튼 눌렀는데 반응 없음 | 홀 (프론트) |
| "저장 실패" 메시지 | 주방 (백엔드) or 주문서 (API) |
| 저장됐다는데 새로고침하면 없음 | 창고 (DB) |
| 내 컴에선 되는데 친구 폰에선 안 됨 | 배포 문제 (B9) |
