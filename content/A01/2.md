## 3. 한 앱에 다 있어야 함?

ㄴㄴ. 작은 앱은 **푸드트럭**처럼 홀·주방·창고가 한 대에 다 들어있음.

| 규모 | 비유 | 예 |
|---|---|---|
| HTML 파일 하나 | 푸드트럭 | 내 컴에서만 쓰는 가계부 |
| 화면 + 서버 | 작은 식당 | 친구들이랑 같이 쓰는 회비 장부 |
| 화면 + 서버 + DB + 여러 서비스 | 프랜차이즈 | 배달앱, 은행앱 |

> 엑셀 매크로 = 홀·주방·창고가 한 파일에 다 있는 푸드트럭임. 혼자 쓸 땐 편하고 여럿이 쓰면 터짐

<div class="danger"><b>이거 모르면 큰일남</b>

- **화면에서 검사했다고 끝 아님.** 홀 직원이 이상한 주문 걸러도 주방에서 한 번 더 봐야 함. 중요한 검사는 **서버에서도**
- **브라우저에 보이는 값 ≠ 저장된 값.** 새로고침해서 날아가면 저장 안 된 거임

</div>
