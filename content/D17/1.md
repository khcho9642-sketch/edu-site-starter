## [강좌] C17. 말로 커밋·푸시 — 올리기 전에 목록부터

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: Desktop의 Code 화면(로컬 폴더 선택) + GitHub 웹
> 이 강의는 파일을 수정하고 Git을 실행하므로 Code 화면을 사용합니다. Code가 없는 계정은 읽기 실습으로 진행합니다.

> 먼저 읽을 강의: C14 · C15 · C16.

## 3줄요약

1. 올리기 전에 **"무엇이 올라가는지 목록부터"** 받는다.
2. `.env`·개인 자료는 **`.gitignore`로 제외**하고, 제외됐는지 직접 확인한다.
3. 푸시 완료 증거는 **GitHub 웹에 파일이 보이는 것**이다.

## 1. 준비와 오늘의 결과

[GitHub 연습 안내](/desktop-materials/github)를 확인한다. C15에서 README를 넣어 만든 원격 저장소는 **먼저 복제(clone)한 뒤** 가짜 실습 파일을 추가한다. 오늘 결과는 **확인한 연습 저장소로 푸시 1회 + `.gitignore`**다.

## 2. Code 화면에서 폴더 연결

1. GitHub 웹의 본인 연습 저장소에서 **Code → HTTPS 주소 복사**로 정확한 저장소 주소를 확인한다.
2. Desktop Code에서 상위 연습 폴더를 선택하고, 그 주소의 저장소를 `my-gagyebu-practice`에 복제해 달라고 요청한다. 이미 해당 폴더가 있으면 덮어쓰지 말고 내용·Git 연결 상태부터 확인하도록 한다. 실제 로그인은 본인이 한다.
3. 복제한 폴더를 새 세션의 작업 폴더로 선택한다. 원격 README가 로컬에서도 보이는지 확인한 뒤 실습자료의 가짜 파일을 추가한다.
4. 권한 모드는 처음에 **Plan 또는 확인하며 진행(Manual)** 쪽을 고른다(C03).
5. 먼저 상태만 묻는다.

> 이 폴더가 Git 저장소인지, 연결된 GitHub 저장소가 있는지 확인만 해줘. 아직 아무것도 바꾸지 마.

## 3. 제외 목록 → 커밋 → 푸시

1. 제외 규칙부터 만든다.

> `.gitignore`를 만들어서 `.env`와 `개인자료/` 폴더를 제외해줘. 만든 뒤 내용 보여줘.

2. 올라갈 목록을 받는다.

> 지금 커밋하면 포함될 파일 목록과 `.env`·`개인자료/`의 기존 Git 추적 여부를 확인해줘. 둘 중 하나가 커밋 예정 목록에 있거나 이미 추적 중이면 멈추고 상태만 설명해줘. 아직 커밋·푸시하지 마.

`.gitignore`는 새로 추적하지 않을 파일을 정하는 규칙이다. 이미 추적 중인 파일이나 과거 커밋의 비밀값은 이 파일을 작성하는 것만으로 사라지지 않는다. 실제 비밀값을 이미 올렸다면 C16의 폐기·재발급 대응부터 하고, 이번 수업의 가짜 파일과 구분한다.

3. 목록이 맞으면 커밋한다. 메시지는 내용이 드러나게 쓴다.

> 이 목록으로 커밋해줘. 메시지는 "가계부 연습 첫 파일과 제외 규칙 추가".

4. GitHub의 `my-gagyebu-practice`(Private)에 연결하고 푸시해 달라고 한다. **로그인·인증 창이 뜨면 내가 직접** 처리한다.

> 이 폴더를 GitHub의 my-gagyebu-practice 비공개 저장소에 연결하고 푸시해줘. 인증이 필요하면 멈추고 나한테 알려줘.
