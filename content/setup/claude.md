앱 설치부터 개발 도구와 배포 준비까지 한곳에서 확인합니다. **처음에는 1~2단계만 확인하고 첫 대화를 시작하세요.** 3단계부터는 앱을 만들거나 DART 공시 데이터 프로젝트를 진행할 때 필요한 준비입니다.

## 1. 클로드 앱 설치와 첫 대화

### 1-1. 공식 사이트에서 설치 파일 받기

[클로드 공식 다운로드](https://claude.com/download)를 열고 아래 그림과 같은 다운로드 영역을 찾습니다. 휴대폰용 앱과 PC용 앱을 구분하세요.

![클로드 PC 다운로드 버튼](/materials/setup/claude-download.jpg)

### 1-2. 받은 파일을 실행하고 앱 열기

Windows는 브라우저 다운로드 목록 또는 파일 탐색기의 **다운로드** 폴더에서 받은 파일을 엽니다. Mac은 .dmg를 열어 화면의 설치 안내를 따릅니다. 설치 창이 닫혔다면 시작 메뉴(Windows) 또는 응용 프로그램(Mac)에서 Claude를 찾습니다.

![클로드 운영체제별 다운로드](/materials/setup/claude-os.jpg)

### 1-3. 로그인하기

앱의 로그인 버튼을 눌러 본인 Claude 계정으로 로그인합니다. 브라우저에서 인증이 진행되면 완료 후 앱으로 돌아갑니다. 기존에 쓰던 계정과 같은 로그인 방법을 선택하세요. 다른 사람 계정이 보이면 진행하지 말고 계정을 확인합니다.

**확인:** 앱에서 새 대화를 열 수 있어야 합니다. 다운로드만 끝난 상태는 설치·로그인 완료가 아닙니다.

### 1-4. 첫 질문 보내고 답변 확인하기

새 대화의 입력창에 아래 문장을 넣고 전송합니다. 앱 설치가 어려우면 [클로드 웹](https://claude.ai/)에서도 같은 대화 실습을 할 수 있습니다.

> 처음 사용하는 사람이야. 가짜 자료로 연습할 거야. 오늘 할 수 있는 일을 세 가지 알려줘.


![클로드 웹 대체 실습의 입력창](/materials/setup/claude-chat.png)

**완료 기준:** 보낸 질문과 실제 답변이 함께 보이고, 제안한 일 세 가지를 읽을 수 있습니다. 그림을 보기만 했거나 질문을 입력만 한 상태는 완료가 아닙니다.

### 설치 중 막혔다면

| 화면·증상 | 지금 할 일 |
|---|---|
| Windows와 arm64 중 모르겠음 | 설정 → 시스템 → 정보 → 시스템 종류 확인 |
| 다운로드했는데 앱이 안 보임 | 다운로드 폴더에서 설치 파일을 실행했는지, 시작 메뉴에 Claude가 있는지 확인 |
| 회사 PC에서 설치가 차단됨 | 담당자에게 설치 가능 여부 확인. 가능한 웹 대화 실습부터 진행 |
| 로그인 후 앱으로 돌아오지 않음 | 브라우저의 인증 완료 여부 확인 후 앱을 다시 열기. 계속 실패하면 웹에서 계정 로그인 확인 |
| Code·Cowork 메뉴가 안 보임 | 앱 업데이트·현재 계정의 기능·조직 정책 확인. 우선 가능한 기본 대화 진행 |


Chat은 대화, Cowork는 여러 단계의 업무 작업, Code는 프로젝트 코드 작업에 사용합니다. 통합 화면이나 다른 메뉴 구성이 보이면 현재 앱 안내를 확인하세요. 기본 대화 실습을 시작하려고 별도의 터미널용 Claude Code부터 설치할 필요는 없습니다. 설치가 어려우면 [클로드 웹](https://claude.ai/)에서 가능한 대화 실습부터 진행합니다.

앱 개발을 할 때는 Claude 앱의 Code에서 **로컬 연습 폴더**를 선택합니다. 앱 설치와 Python·Node.js·Git 같은 프로젝트 실행 도구 설치는 별개입니다. 필요한 도구는 아래 3단계에서 확인합니다.

공식 참고: [Claude 다운로드](https://claude.com/download) · [Desktop의 Code 화면](https://code.claude.com/docs/en/desktop)

## 2. 계정과 이용 범위 확인

현재 계정에서 대화·파일 작업·Cowork·Code 중 무엇을 사용할 수 있는지 확인합니다. 메뉴가 없거나 사용량 제한이 나타나면 [현재 요금제와 제공 기능](https://claude.com/pricing)을 먼저 봅니다. 강의 수강을 위해 특정 요금제 결제를 필수로 요구하지 않습니다.

결제를 선택한다면 공식 계정의 요금제·결제 화면에서 **금액, 세금, 월간·연간 주기, 다음 결제일, 해지·환불 안내**를 본인이 확인합니다. 결제 정보와 비밀번호를 AI 대화에 붙이지 않습니다. 조직 계정은 관리자의 이용 정책도 확인하세요. 이 설치 안내에서 결제나 계정 연결을 자동으로 진행하지는 않습니다.

**확인할 결과:** 앱에서 로그인한 계정과 첫 답변을 확인하고, 사용할 기능과 제한을 자신의 말로 적을 수 있습니다.
