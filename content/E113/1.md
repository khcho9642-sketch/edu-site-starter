## [강좌] D13. 예약 작업 — 어디서 돌고 무엇을 읽는지 확인하기

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D03 · D06 · D09.

## 3줄요약

1. 수동 결과를 검증한 후 같은 기준으로 예약한다.
2. 클라우드 실행과 내 PC 파일·앱 접근의 조건을 따로 확인한다.
3. 실행 위치·시간대·입력 자료·결과·중지 방법까지 확인해야 예약을 이해한 것이다.

## 1. 예약 전에 수동 결과 확인

[지출 샘플](/chatgpt-materials/expenses)만 사용한다. 다음 요청을 세 번 수동으로 실행하고 결과가 일치하는지 확인한다.

> 이 연습 자료의 거래 수, 확정 금액 합계, 미확정 거래 ID, 환불 거래 ID를 표로 정리해줘. 새 메일 조회나 외부 발송은 하지 마. 원본을 수정하지 말고 보고 초안만 만들어줘.

세 번 모두 **6건 / 확정 5건 28,000원 / T004 / T005**가 나오는지 기록한다. 한 번이라도 틀리면 예약 전에 요청과 자료를 고친다.

## 2. 실행 위치와 입력 자료 확인

| 종류 | 먼저 확인 |
|---|---|
| ChatGPT 웹 예약 | 저장된 작업의 입력·업로드 자료·연결 도구가 실제 접근 가능한가 |
| 데스크톱 로컬 예약 | 프로젝트 위치, PC·앱 실행 상태, 입력 파일 접근이 가능한가 |
| Worktree 작업 | 원래 폴더가 아닌 분리한 Git 작업 복사본의 입력인가 |
| 클라우드 작업에서 로컬 자원 사용 | 해당 기능의 로컬 접근 지원·연결 조건을 따로 확인했는가 |

현재 대화에 첨부한 자료가 다음 예약에 자동 전달된다고 가정하지 않는다. 복사본과 실제 로컬 파일의 갱신 방식도 확인한다. 지원 범위가 불분명하면 명세 작성까지만 한다.
