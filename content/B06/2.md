## 3. AI 코드 이해하기 (전부 말고 이 정도만)

### 매번 붙일 말
> 방금 바꾼 거 비전공자한테 설명하듯 3줄로. 어느 파일 어디를 왜 바꿨는지.

### 궁금할 때
> 이 코드에서 월별 합계 계산하는 부분이 어디야? 날짜가 비어있으면 어떻게 돼?

> 이 줄(붙여넣기) 한 줄씩 해석해줘.

### 감 잡는 키워드

| 코드에서 보이면 | 뜻 |
|---|---|
| `function 이름()` | 기능 하나 (레시피) |
| `if (...)` | 갈림길 (B4 흐름도) |
| `for` / `forEach` | 반복 (30줄에 똑같이) |
| `try { } catch` | 실패 대비 |
| `// 글자` | 주석 = 메모 |

## 4. 이상한 낌새

| AI가 이러면 | 의심 |
|---|---|
| 에러 메시지를 **안 보이게** 고침 | 문제 숨긴 거임. 원인 물어봐라 |
| 안 시킨 파일까지 대량 수정 | "왜 바꿨어?" 물어보고 필요 없으면 되돌려 |
| "아마 될 거예요" | 돌려봤는지 물어봐 |
| 같은 수정을 왔다갔다 | 3번 규칙 발동 |

<div class="danger"><b>이거 모르면 큰일남</b>

- **"에러 안 나게 해줘"** 이러면 AI가 에러를 숨김. **"에러 나면 사용자한테 이유 보여줘"**라고 해라
- 모르는 코드 위에 모르는 코드 쌓으면 결국 처음부터 다시 만들게 됨

</div>
