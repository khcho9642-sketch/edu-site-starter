# A09. Git 게임 세이브파일

<div class="tldr"><b>3줄요약</b>

1. **Git = 게임 세이브 파일.** 커밋 = 세이브, 브랜치 = 세이브 슬롯 2
2. 명령어 몰라도 됨. 클코한테 **"커밋해줘"** 한 마디
3. **잘 될 때마다 세이브.** AI가 망쳐도 거기로 돌아가면 됨

</div>

## 1. 용어 = 게임 용어

| Git | 게임 | 뜻 |
|---|---|---|
| **저장소 (repo)** | 세이브 폴더 | Git이 지켜보는 폴더 |
| **커밋 (commit)** | 세이브 | 지금 상태 + 메모 저장 |
| **브랜치 (branch)** | 세이브 슬롯 2 | 본편 안 건드리고 실험 |
| **머지 (merge)** | 실험 결과 본편에 반영 | |
| **되돌리기** | 로드 | 예전 세이브로 |
| **GitHub** | 클라우드 세이브 | 인터넷 백업 + 공유 |
| **푸시 (push)** | 클라우드 업로드 | |

## 2. Ctrl+Z랑 뭐가 다름?

| | Ctrl+Z / Esc Esc | Git |
|---|---|---|
| 범위 | 지금 하던 것만 | **모든 변경 영구 기록** |
| 프로그램 끄면 | 못 돌아감 | 언제든 |
| 남한테 공유 | 불가 | GitHub로 가능 |

## 3. 말로 Git 쓰기 (클코 기준)

| 하고 싶은 것 | 이렇게 말해 |
|---|---|
| 처음 시작 | "이 폴더 Git 저장소로 만들어줘. .env 같은 비밀 파일은 기록 안 되게 .gitignore도" |
| 세이브 | "지금까지 한 거 커밋해줘" |
| 기록 보기 | "커밋 목록 쉽게 보여줘" |
| 로드 | "'월별 합계 추가' 커밋 상태로 돌아가고 싶어. **어떻게 할지 먼저 설명하고** 해줘" |
| 실험 | "차트 기능 실험해보고 싶어. 본편 두고 새 브랜치에서" |
| 실험 성공 | "이 브랜치 main에 합쳐줘" |
| 실험 실패 | "이 브랜치 버리고 main으로" |

**"먼저 설명하고"** 꼭 붙여라. 되돌리기는 신중하게.
