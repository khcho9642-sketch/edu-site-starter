## 5. 코드 되돌리기 ≠ 데이터 되돌리기

Git은 **코드**를 되돌림. DB 안의 지출 기록은 안 돌아옴. 데이터는 **백업** 따로 (B10).

<div class="danger"><b>이거 모르면 큰일남</b>

- **`.env`, 비밀번호, API 키 커밋 금지.** GitHub에 올라가면 봇이 몇 분 만에 긁어감
- **개인 데이터 파일 커밋 금지.** `.gitignore`에 `데이터/` 폴더 넣어라
- "강제 푸시", "reset --hard" = **세이브 덮어쓰기.** 클코가 하자고 하면 이유 물어봐라

</div>
