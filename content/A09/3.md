## 숙제

<div class="tryit"><b>가짜 데이터로 직접 확인</b>

1. 연습 폴더 Git 저장소로 만들기 + `.gitignore`
2. 파일 하나 만들고 커밋 → 고치고 커밋 → 첫 커밋으로 되돌리기
3. (선택) GitHub **비공개(Private)** 저장소에 푸시

</div>

## 핵심 정리

<div class="best">

1. 잘 될 때마다 세이브
2. 실험은 브랜치
3. 비밀번호·개인 데이터는 절대 커밋 금지

</div>

3단원을 모두 읽으면 강의가 완료됩니다. 퀴즈는 자가학습용이며 점수는 이 브라우저에 저장됩니다.
