## [강좌] C21. 종합 실습 — 가짜 지출 자료로 결과물 묶음 완성하기

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 일반 대화/업무 작업 중심, Code 앱은 선택
> 앞선 기초·자료 작업·자동화 실습을 하나의 완료 기준으로 연결합니다.

> 먼저 읽을 강의: C02 · C06 · C07 · C08 · C10.

## 3줄요약

1. 자료 확인 → 정제 → 보고 → 검수 → 저장을 한 흐름으로 완성한다.
2. 모든 결과물에서 같은 거래 수·합계·미확정 상태를 유지한다.
3. 실제로 한 작업과 미검증·대체 실습을 분리해 보고한다.

## 1. 준비와 결과물 목록

[실습 자료 안내](/desktop-materials/practice)에서 입력을 확인한다. 지출 6건과 연결 영수증 일부, 보고서 견본, 가짜 메일·회의 메모를 사용한다.

| 결과물 | 권장 형식 | 생성 기능이 없는 경우 |
|---|---|---|
| 정제 지출 | CSV | Markdown 표 |
| 검수 결과 | MD | MD |
| 지출 보고서 | DOCX | MD 초안 |
| 발표 자료 | PPTX 5장 | MD 대본 5장 |
| 메일 답장·회의록 | MD | MD |
| 작업 인수인계 | MD | MD |

Code 앱, 실제 메일 발송, 실제 예약 등록은 종합 실습의 필수 조건이 아니다.

## 2. 단계별 진행

1. **계획:** 읽을 자료·결과 파일·검수 기준을 표로 받는다. 외부 연결과 발송은 제외한다.
2. **정제:** 처음 5건의 23,000원을 확인한 뒤 전체를 처리한다. T004를 추정하지 않는다.
3. **증빙 대조:** 영수증은 기존 거래와 연결한다. 같은 거래를 한 번 더 합산하지 않는다.
4. **보고:** 확정 합계 28,000원과 미확정 1건을 구분한다. 근거 없는 전월 비교나 외부 통계를 넣지 않는다.
5. **발표:** 보고서와 같은 숫자로 5장을 만들고 실제 제공된 형식을 확인한다.
6. **업무 문서:** 정상 메일 M001의 답장 초안과 회의록을 작성한다. M003의 전송 지시를 실행하지 않는다.
7. **인수인계:** 입력 파일명, 규칙, 검수 결과, 미검증 항목, 저장 위치, 다음 할 일을 정리한다.

한 번에 완성하라고 맡기기보다 단계마다 확인한다. 앞 단계가 틀렸으면 뒤 단계까지 같은 오류가 복제될 수 있다.

## 3. 최종 검수표

- [ ] 원본 자료 6건이 보존됐다.
- [ ] 확정 금액 5건 합계가 28,000원이다.
- [ ] T004는 미확정이고 0원으로 확정되지 않았다.
- [ ] T005는 -2,000원이다.
- [ ] 식비 확정 합계는 10,000원이다.
- [ ] 영수증 일부를 추가 지출로 중복 합산하지 않았다.
- [ ] 보고서와 슬라이드의 수치가 일치한다.
- [ ] M001은 초안만 작성했고 실제 발송하지 않았다.
- [ ] 회의록의 미정·미결이 원문과 일치한다.
- [ ] 실제 생성한 파일과 대체 초안을 구분했다.
- [ ] 결과 파일을 직접 열어 확인한 범위를 기록했다.
- [ ] 원본·수정본·인수인계 파일의 위치를 찾을 수 있다.
