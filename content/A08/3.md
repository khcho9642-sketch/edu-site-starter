## 숙제

<div class="tryit"><b>가짜 데이터로 직접 확인</b>

1. 크롬 `F12` → Network 탭 열고 아무 사이트 새로고침 → 오가는 요청들 구경 (숫자 200 찾기)
2. AI한테: "가계부 지출 저장 API를 만든다면 요청·응답 JSON 예시랑 실패하면 몇 번 코드인지 표로"

</div>

## 핵심 정리

<div class="best">

1. API = 주문서, JSON = 주문서 형식
2. 4xx는 요청·인증·권한 확인, 5xx는 서버 처리 확인
3. 응답 없다고 바로 다시 보내지 마라

</div>

3단원을 모두 읽으면 강의가 완료됩니다. 퀴즈는 자가학습용이며 점수는 이 브라우저에 저장됩니다.

## 예시 댓글 (학습용 가상 대화)

**ㅇㅇ(8.080)**

**야근요정**
> Network 탭 처음 열어봤는데 요청 수백 개 오감 ㄷㄷ

  ↳ **조회계사** : 웹페이지 하나 여는 데 주문서 수백 장 왔다갔다 하는 거임

**카페사장**
> 배달앱 주문 두 번 들어간 적 있는데 4번 얘기네

  ↳ **엑셀장인** : 응답 없어서 또 누른 케이스 ㅋㅋ
