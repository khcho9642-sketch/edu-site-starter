# A08. API와 JSON

<div class="tldr"><b>3줄요약</b>

1. **API = 프로그램끼리 주고받는 주문서 양식.** 날씨앱도 기상청 API로 날씨 받아옴
2. **JSON = 주문서 쓰는 형식.** `{"이름": 값}` 이 모양만 알면 됨
3. 응답 숫자 **200 성공 / 400 니가 잘못 / 401·403 권한 없음 / 404 없음 / 500 서버 터짐**

## 1. API는 주문서다

```
가계부 화면 ──[요청: 지출 저장해줘 + 내용]──▶ 서버
가계부 화면 ◀──[응답: 200 저장됨, 번호 E031]── 서버
```

| 요청에 들어가는 것 | 식당 비유 |
|---|---|
| **주소 (URL)** | 어느 창구 (`/api/지출`) |
| **방식 (GET/POST 등)** | 조회냐, 새로 주문이냐 |
| **내용 (body)** | 주문 내용 (JSON) |
| **인증 정보** | 회원카드 |

### 방식 4개

| 방식 | 뜻 | 가계부 |
|---|---|---|
| **GET** | 조회 | 11월 지출 목록 줘 |
| **POST** | 새로 만들기 | 지출 1건 저장 |
| **PATCH/PUT** | 고치기 | 금액 수정 |
| **DELETE** | 지우기 | 지출 삭제 |

## 2. JSON 읽는 법

```json
{
  "날짜": "2026-11-12",
  "가게": "김밥천국",
  "금액": 4500,
  "카테고리": "식비",
  "태그": ["점심", "회사근처"],
  "메모": null
}
```

| 모양 | 뜻 |
|---|---|
| `{ }` | 묶음 (한 건) |
| `"이름": 값` | 항목 하나 |
| `"글자"` | 따옴표 = 글자 |
| `4500` | 따옴표 없음 = 숫자 |
| `[ ]` | 목록 |
| `null` | 비어있음 (A5의 NULL) |

> `"금액": "4500"` 이랑 `"금액": 4500`은 다름. 앞에건 글자라서 더하면 이상해짐
