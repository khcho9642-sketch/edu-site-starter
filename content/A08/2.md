## 3. 상태 코드 = 응답의 표정

| 코드 | 뜻 | 누구 잘못 |
|---|---|---|
| **200 / 201** | 성공 / 만들어짐 | - |
| **400** | 요청이 이상함 (금액에 글자 등) | 보낸 쪽 |
| **401** | 로그인 안 함 | 보낸 쪽 |
| **403** | 로그인은 했는데 권한 없음 | 보낸 쪽 |
| **404** | 그런 거 없음 | 주소 틀림 |
| **429** | 너무 많이 보냄 | 보낸 쪽 (잠깐 쉬어) |
| **500** | 서버 터짐 | 서버 |

**4로 시작 = 내 쪽 문제, 5로 시작 = 서버 쪽 문제.** 이것만 외워도 반은 감.

## 4. 응답 안 오면?

인터넷 끊겨서 응답이 안 왔다고 **실패라고 단정하면 안 됨.** 저장은 됐는데 대답만 못 받은 걸 수도 있음.
→ 그래서 "다시 누르기" 전에 **목록 새로고침해서 확인.** 안 그러면 중복 저장.

- 응답 없음 ≠ 실패. 확인하고 다시 보내라
