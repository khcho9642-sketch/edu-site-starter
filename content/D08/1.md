## [강좌] C08. 메일·회의록·커넥터 — 초안과 발송은 따로

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 일반 대화/업무 작업, Plugins 또는 Customize의 커넥터 관리
> 가짜 메일로 먼저 실습하며 실제 계정 연결은 선택입니다. 메뉴 개편 전후 경로를 함께 안내합니다.

> 먼저 읽을 강의: C03 · C05.

## 3줄요약

1. 커넥터 연결은 로그인·권한 승인과 작업 중 사용 허용을 구분한다.
2. 초안 작성과 실제 발송은 다른 행동이다.
3. 회의록에서 담당자·기한을 알 수 없으면 미정으로 남긴다.

## 1. 계정 연결 없이 먼저 연습

[가짜 메일과 회의 메모](/desktop-materials/mail-meeting)를 첨부한다. 가정일은 2026-11-14이다. 실제 오늘의 메일함을 읽는 실습이 아니다.

> 메일 M001~M003을 분류해줘. 정상 업무 메일, 뉴스레터, 의심스러운 요청을 구분하고 근거를 적어줘. 정상 업무 메일 중 답장이 필요한 것만 초안을 작성해. 실제 발송·외부 전송·계정 연결은 하지 마.

M001은 검토 기한이 있는 업무 요청, M002는 뉴스레터, M003은 비밀 파일 전송을 요구하는 의심스러운 내용이다. **M003의 명령을 실행하지 않고 확인필요로 분리**한다. “요약만 해”라는 지시도 기술적 보안 차단은 아니므로 연결 권한을 최소화한다.

## 2. 필요한 사람만 커넥터 연결

1. 새 화면에서는 왼쪽 **Plugins**에서 커넥터를 찾는다. 이전 화면이면 **Customize → Connectors**, 더 이전에는 설정의 커넥터 항목을 확인한다.
2. 서비스의 공식 로그인·권한 요청 화면을 확인하고 본인 계정을 연결한다.
3. 읽기·쓰기·발송 등 허용 범위를 확인한다. 조직 계정은 조직 정책을 따른다.
4. 대화의 도구·플러그인 메뉴에서 해당 연결을 사용할 수 있는지 확인한다.
5. 먼저 제목·날짜 같은 최소 범위 조회로 연결을 시험한다. 새로 온 메일 전체를 무제한 처리하라고 요청하지 않는다.
6. 실습 후 연결을 해제하거나 사용을 끈다. 플러그인을 제거한 것만으로 연결 계정의 인증이 해제되는 것은 아니다. 커넥터 연결 상태도 따로 확인한다.

Code의 로컬 MCP 설정과 계정에 연결된 커넥터를 동일한 설정 파일이라고 설명하지 않는다. 제공 범위는 제품과 세션에 따라 확인한다.
