## 두 가지 도구: Claude 앱과 Claude Code

> 이전판 원고 보관본입니다. 최신 강의는 C01에서 읽을 수 있습니다.

"클로드"라는 이름으로 묶이지만, 실제로는 성격이 다른 두 가지 도구가 있습니다. 이번 강의 시리즈는 이 둘을 구분해서 다룹니다.

- **Claude 앱**(일반 챗봇): 질문하면 화면에 글·이미지·표 같은 답을 보여줍니다. 내 컴퓨터의 파일을 직접 건드리지는 않습니다.
- **Claude Code**: 여기서 한 걸음 더 나아가, **지정한 작업공간(저장소·폴더)의 파일을 직접 읽고·쓰고·실행**할 수 있는 비서입니다. "README 파일 요약해줘"라고 말하면 실제로 그 저장소를 열어서 파일 내용을 읽고 답합니다.

실제 화면으로 비교해보겠습니다.

![Claude 앱 홈 화면](/images/c1/home-input.png)

위는 **Claude 앱**의 홈 화면입니다. 가운데 입력창에 질문을 적으면 바로 아래에 답이 나타납니다.

![Claude Code 세션 화면](/images/c1/claude-code-session.png)

위는 같은 질문을("README.md 파일 내용을 요약해줘") **Claude Code**에 보낸 화면입니다. "**실행됨 명령 1개**"라는 표시가 보이는데, 이는 실제로 그 저장소의 README.md 파일을 열어서 읽었다는 뜻입니다. 오른쪽에는 지금 다루고 있는 저장소(`khcho9642-sketch/edu-site`)와 브랜치(`main`)가 표시된 **환경** 패널이 있습니다.

<div class="note"><b>비유로 이해하기</b>
<p>Claude 앱은 전화로 상담해주는 직원이고, Claude Code는 내 사무실 책상(파일)까지 와서 직접 서류를 꺼내 보고 고쳐주는 직원이라고 생각하면 됩니다. 다만 이 직원은 지시받은 범위(작업공간) 안에서만 움직이고, 범위를 벗어나는 일(예: 파일 삭제, 결제)을 하기 전에는 반드시 다시 확인을 받습니다.</p></div>

| 구분 | Claude 앱 | Claude Code |
| --- | --- | --- |
| 결과물 | 화면에 뜨는 글 | 실제로 수정·생성된 파일, 실행된 명령 |
| 할 수 있는 일 | 설명, 요약, 초안 작성 | 위 기능 + 파일 읽기/쓰기, 프로그램 실행, 외부 서비스 연결 |
| 확인 방식 | 답을 읽고 판단 | 결과물을 직접 열어서 확인 |
| 되돌리기 | 해당 없음 | 민감한 작업(삭제·결제·발송)은 실행 전에 허락을 구함 |

### 이 강의 시리즈에서 다루는 범위

이어지는 C2·C3에서는 메일·엑셀·보고서 자동화 같은 실제 업무 사례를 다루고, C4·C6에서는 설정과 보안을, C7 이후에는 더 깊은 활용을 다룹니다. 이번 C1에서는 먼저 두 도구의 화면 구성과 기본 동작 원리부터 익힙니다.

## 세 가지 핵심 개념: 세션 · 권한 · 작업공간

두 도구 모두에 공통으로 적용되는, 꼭 알아야 할 개념은 세 가지입니다.

| 개념 | 뜻 | 왜 중요한가 |
| --- | --- | --- |
| 세션 | 하나의 대화가 시작돼서 끝날 때까지의 범위 | 세션 안에서는 앞서 말한 내용을 기억하지만, 새 세션을 열면 기억하지 못합니다 |
| 권한 | 어떤 작업까지 허락했는지 | 파일을 읽기만 허락했는지, 고치거나 실행까지 허락했는지에 따라 할 수 있는 일이 달라집니다 |
| 작업공간 | 지금 다루고 있는 폴더(프로젝트) 범위 | 지정한 폴더 밖의 파일은 원칙적으로 건드리지 않습니다 |

![Claude Code 파일 패널](/images/c1/claude-code-files.png)

**작업공간**은 Claude Code 화면 오른쪽의 파일 아이콘을 누르면 직접 확인할 수 있습니다. 위 화면처럼 `app`, `content`, `lib`, `public` 같은 실제 폴더·파일 목록이 보이는데, 이 목록에 있는 범위가 바로 지금 세션이 다룰 수 있는 작업공간입니다.
