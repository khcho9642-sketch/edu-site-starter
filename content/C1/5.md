## 채워진 예시: 민수의 첫 요청

> 이전판 원고 보관본입니다. 최신 강의는 C01에서 읽을 수 있습니다.

민수는 매주 월요일, 지난주 지점별 매출 엑셀을 정리해서 팀장에게 보고합니다. 지금까지 배운 개념을 하나의 요청으로 묶으면 이렇게 됩니다.

| 항목 | 채워진 예시 |
| --- | --- |
| 목표 | 지점별 매출 엑셀을 정리해 보고용 요약본 만들기 |
| 작업공간 | `reports` 폴더 (이 폴더 밖 파일은 건드리지 않음) |
| 첨부 | 이번 주 원본 엑셀 파일 (6번: 파일 첨부) |
| 지시문 | "reports 폴더의 이번 주 엑셀에서 지점별 매출 합계만 새 시트로 정리해줘. 원본은 그대로 두고" |
| 필요한 권한 | 수정 허용(새 파일 생성) — 삭제·발송은 포함하지 않음 |
| 확인할 표시 | 대화창에 "실행됨 명령 1개"처럼 실제로 파일을 처리했다는 표시가 뜨는지 |
| 완료 확인 | 결과 파일을 직접 열어서 합계가 맞는지 확인 |

<div class="note"><b>완료는 화면 문구가 아니라 결과로 확인</b>
<p>"완료했습니다"라는 답을 받았다고 끝난 것이 아닙니다. 실제 결과 파일을 열어서 숫자가 맞는지, 원본이 그대로 남아있는지 직접 확인해야 합니다.</p></div>

## 자주 하는 오해와 바로잡기

| 흔한 오해 | 바로잡는 방법 |
| --- | --- |
| 한 번 설명하면 다음 대화에서도 기억한다 | 세션이 다르면 기억하지 못합니다. 중요한 규칙은 반복해서 알려주거나 문서로 남깁니다 |
| 권한을 다 열어줘야 더 잘 작동한다 | 필요한 권한만 열어도 대부분의 업무는 충분히 처리됩니다 |
| "허용"은 눌러도 되는 형식적인 절차다 | 특히 삭제·발송·결제 요청은 내용을 읽고 판단해야 합니다 |
| 화면에 뜬 결과가 곧 실제 파일 결과다 | 실제 파일을 열어서 다시 확인하기 전까지는 완료로 보지 않습니다 |
| 첨부한 파일은 안전하게 처리된다 | 민감한 개인정보는 꼭 필요한 경우가 아니면 올리지 않는 것이 안전합니다 |

<div class="tryit"><b>직접 해보기</b>
<p>자신의 반복 업무 중 하나를 골라, 위 표의 "채워진 예시" 형식(목표·작업공간·지시문·필요한 권한·완료 확인)으로 적어보세요.</p>
<details><summary>예시 답 · 판단 기준</summary><p>예: 매주 받는 영수증 사진을 엑셀로 정리하는 업무라면, 작업공간은 "영수증" 폴더, 지시문은 "첨부한 영수증 사진들을 날짜·금액·항목으로 표에 정리해줘", 필요한 권한은 수정 허용(새 파일 생성) 정도로 충분합니다.</p></div>
