## 메시지는 구체적으로

> 이전판 원고 보관본입니다. 최신 강의는 C01에서 읽을 수 있습니다.

Claude 앱이든 Claude Code든, 글로 적은 지시를 그대로 실행하려고 합니다. 지시가 모호하면 AI가 임의로 해석해서 원하지 않은 결과가 나올 수 있습니다.

![Claude 앱 대화 예시](/images/c1/chat-example.png)

위는 Claude 앱에 "오늘 서울 날씨 어때?"라고 구체적으로 물었을 때의 답변입니다. 장소(서울)와 시점(오늘)을 명확히 적었기 때문에, 바로 필요한 정보(기온·날씨 위젯)가 돌아왔습니다. 모호하게 "날씨 알려줘"라고만 물으면 어느 지역인지 되물어야 할 수 있습니다.

| 모호한 지시 | 구체적인 지시 |
| --- | --- |
| "보고서 정리해줘" | "reports 폴더의 10월 엑셀 파일에서 지점별 매출 합계만 뽑아서 새 시트에 정리해줘" |
| "메일 답장 써줘" | "첨부한 메일에 '다음 주 화요일 오후 2시 미팅 가능하다'는 내용으로 정중하게 답장 초안을 써줘" |
| "파일 고쳐줘" | "A 시트의 2번째 줄 오타만 고치고 나머지는 그대로 둬" |

<div class="note"><b>범위를 함께 말하기</b>
<p>"무엇을", "어디까지", "무엇은 건드리지 말 것"을 같이 적으면 AI가 임의로 범위를 넓히는 일을 줄일 수 있습니다.</p></div>

## 파일 첨부하기

참고할 자료가 있다면 대화에 직접 올릴 수 있습니다. 입력창의 **+** 버튼을 누르면 첨부 메뉴가 열립니다.

![파일 첨부 메뉴](/images/c1/attach-menu.png)

| 메뉴 | 하는 일 |
| --- | --- |
| 파일 업로드 또는 추가 | 내 컴퓨터의 파일(엑셀·문서·이미지 등)을 올립니다 |
| Skills | 미리 정해둔 작업 절차(스킬)를 불러와 적용합니다 |
| 커넥터 | 구글 드라이브·캘린더 같은 외부 서비스와 연결합니다 |
| 디자인 시스템 | 저장해둔 디자인 톤·색상 규칙을 불러옵니다 |
| 플러그인 | 추가 기능 모음을 불러옵니다 |
| 리서치 | 여러 자료를 폭넓게 조사하도록 맡깁니다 |

올린 파일은 그 세션 안에서 AI가 읽고 참고합니다.

| 상황 | 하면 좋은 것 |
| --- | --- |
| 엑셀 파일을 정리해달라고 할 때 | 원본 파일을 첨부하고, 결과를 어떤 형식으로 받고 싶은지 설명 |
| 메일 답장을 써달라고 할 때 | 받은 메일 내용(스크린샷 또는 파일)을 첨부 |
| 민감한 개인정보·고객정보가 담긴 파일 | 꼭 필요한 경우가 아니면 올리지 않거나, 민감한 부분을 가리고 올리기 |

<div class="tryit"><b>직접 해보기</b>
<p>지금 반복하고 있는 업무 파일 하나를 떠올리고, 그 파일에서 "가려야 할 민감한 항목"이 있는지 적어보세요.</p>
<details><summary>예시 답 · 판단 기준</summary><p>예: 고객 이름·연락처·계좌번호 등 개인정보. 꼭 필요하지 않다면 가리거나 샘플 데이터로 바꿔서 올립니다.</p></details></div>

## AI가 멈춰 서서 물어볼 때

Claude Code가 실제로 작업을 수행하면, 2단원에서 본 "**실행됨 명령 1개**"처럼 무엇을 했는지 대화창에 표시가 남습니다. 그런데 모든 작업을 조용히 바로 실행하는 것은 아닙니다. AI가 파일을 삭제하거나, 외부로 메일을 보내거나, 결제처럼 되돌리기 어려운 작업을 하려고 할 때는 바로 실행하지 않고 **"이 작업을 해도 될까요?"**라고 먼저 물어봅니다. 이때 사람이 "허용" 또는 "거부"를 선택합니다.

| 상황 | AI의 행동 |
| --- | --- |
| 파일 내용을 읽기만 할 때 | 바로 진행 (보통 확인을 구하지 않음) |
| 파일을 새로 만들거나 고칠 때 | 대부분 바로 진행하되, 결과를 보여줌 |
| 파일을 삭제할 때 | 먼저 확인을 구함 |
| 메일 발송·결제처럼 외부에 영향을 주는 작업 | 반드시 먼저 확인을 구함 |

<div class="note"><b>확인 요청이 뜨면 내용을 꼭 읽기</b>
<p>"허용"을 누르기 전에 무엇을 하겠다는 요청인지 한 줄이라도 읽어보는 습관이 중요합니다. 특히 삭제·발송·결제처럼 되돌릴 수 없는 작업은 한 번 더 확인합니다.</p></div>

<p>"고객 목록 파일에서 중복된 이메일 주소를 찾아서 지워줘"라는 지시를 받으면, AI는 확인을 구해야 할까요?</p>
<details><summary>예시 답 · 판단 기준</summary><p>예. 파일 내용을 지우는(삭제하는) 작업이므로 실행 전에 확인을 구하는 것이 안전합니다.</p></details></div>
