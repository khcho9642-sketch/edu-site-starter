## 세션의 기억 범위

> 이전판 원고 보관본입니다. 최신 강의는 C01에서 읽을 수 있습니다.

세션은 대화가 시작돼서 끝날 때까지의 한 묶음입니다. 같은 세션 안에서는 앞서 올린 파일과 지시를 기억하지만, 새 세션을 열면 처음부터 다시 설명해야 합니다.

| 상황 | 기억하는가 |
| --- | --- |
| 같은 세션에서 이어서 질문 | 기억함 (앞서 올린 파일·지시 포함) |
| 새 대화(세션)를 열어서 질문 | 기억하지 못함. 필요한 내용을 다시 알려줘야 함 |
| 세션 중간에 자리를 비웠다가 돌아옴 | 세션이 살아있다면 기억함 |

<div class="note"><b>중요한 내용은 파일로 남기기</b>
<p>세션이 기억하는 내용에만 의존하면, 다음에 새 대화를 열었을 때 같은 설명을 반복해야 합니다. 자주 쓰는 규칙이나 설명은 문서(CLAUDE.md 등, C4·C5에서 다룸)로 남겨두면 매번 반복하지 않아도 됩니다.</p></div>

## 권한 단계 이해하기

"권한"은 AI가 어디까지 할 수 있는지를 정하는 설정입니다. 모든 걸 다 허락할 필요는 없고, 하는 일에 맞게 단계를 조절할 수 있습니다.

| 권한 단계 | 할 수 있는 일 | 어울리는 상황 |
| --- | --- | --- |
| 읽기만 허용 | 파일을 열어서 내용을 보고 설명만 함 | 자료 검토, 요약만 필요할 때 |
| 수정 허용 | 파일을 고치거나 새로 만듦 | 문서·엑셀 정리, 초안 작성 |
| 실행 허용 | 프로그램·명령을 직접 실행함 | 반복 작업 자동화, 데이터 처리 |
| 외부 연결 허용 | 메일 발송, 외부 서비스와 연동 | 실제 업무 자동화(이메일 전송 등) |

<div class="tryit"><b>직접 해보기</b>
<p>"엑셀 파일을 읽고 요약만 해줘"라는 요청에는 어느 권한 단계면 충분할까요?</p>
<details><summary>예시 답 · 판단 기준</summary><p>읽기만 허용으로 충분합니다. 파일을 고치거나 실행할 필요가 없기 때문입니다.</p></details></div>

권한을 넓게 열어둘수록 AI가 더 많은 일을 대신해주지만, 그만큼 잘못됐을 때 되돌리기 어려운 일도 늘어납니다. 아래 습관을 기억해두면 좋습니다.

<div class="note"><b>세 가지 확인 습관</b>
<p>① 지금 이 작업에 꼭 필요한 권한만 허용하기 ② 삭제·발송·결제 요청은 내용을 읽고 판단하기 ③ 중요한 파일은 작업 전 복사본을 남겨두기</p></div>

자세한 권한·보안 설정 방법은 C6(권한·보안·프라이버시)에서 더 다룹니다. 지금은 "권한에는 단계가 있고, 필요한 만큼만 연다"는 감각만 잡아두면 충분합니다.

<div class="note"><b>Claude 앱과 Claude Code의 권한 차이</b>
<p>Claude 앱은 파일을 직접 건드리지 않으므로 권한 개념이 크게 와닿지 않을 수 있습니다. 반대로 Claude Code는 2단원에서 본 작업공간(파일 패널) 안에서 실제로 읽기·쓰기·실행까지 할 수 있기 때문에, 권한 단계를 확인하는 습관이 더 중요해집니다.</p></div>
