## 화면 둘러보기

> 이전판 원고 보관본입니다. 최신 강의는 C01에서 읽을 수 있습니다.

Claude 앱과 Claude Code는 메뉴 배치가 다릅니다. 먼저 **Claude 앱** 화면부터 보고, 이어서 **Claude Code** 화면을 보겠습니다.

## Claude 앱 화면

Claude 앱 화면은 크게 세 군데를 눌러보면 됩니다. **왼쪽 사이드바**(새 대화·검색·아티팩트 등 바로가기), **오른쪽 위 계정 메뉴**(설정·사용량·로그아웃 등), **창 맨 위 툴바**(보기 전환·공유·창 조작)입니다. 실제 화면 캡처로 하나씩 보겠습니다.

### 왼쪽 사이드바 퀵메뉴

![왼쪽 사이드바 퀵메뉴](/images/c1/sidebar-menu.png)

| 메뉴 | 하는 일 |
| --- | --- |
| + 새로 만들기 | 새 대화(세션)를 시작합니다. 이전 대화의 기억은 이어지지 않습니다 |
| 검색 | 지난 대화를 찾아 다시 열어봅니다 |
| 아티팩트 | 지금까지 만든 문서·코드·이미지 같은 결과물만 모아서 봅니다 |
| 사용자 지정 | 자주 쓰는 설정이나 스타일을 저장해 재사용합니다 |
| 더 보기 | 위 네 가지 외의 추가 메뉴를 펼칩니다 |

### 오른쪽 위 계정 메뉴

![오른쪽 위 계정 메뉴](/images/c1/account-menu.png)

| 메뉴 | 하는 일 |
| --- | --- |
| 설정 | 언어·테마 같은 환경설정을 바꿉니다 |
| 사용량 | 이번 기간에 얼마나 썼는지 확인합니다 |
| 도움 받기 · 피드백 보내기 | 사용법이 궁금하거나 문제가 있을 때 이용합니다 |
| 플랜 업그레이드 | 유료 플랜으로 바꿀 때 씁니다 |
| 앱 및 확장 프로그램 다운로드 | 데스크톱·브라우저 확장 등을 추가로 설치합니다 |
| API 키 받기 | 개발자가 프로그램에서 클로드를 호출할 때 필요한 키입니다. 업무용으로 그냥 쓰는 중이라면 몰라도 됩니다 |
| 로그아웃 | 현재 계정에서 나갑니다 |

### 창 맨 위 툴바

![창 맨 위 툴바](/images/c1/window-toolbar.png)

왼쪽부터 화면 보기 방식을 바꾸는 아이콘 두 개, **공유** 버튼(대화를 다른 사람과 공유할 링크를 만듭니다), 그리고 창을 최소화·최대화·닫는 버튼입니다.

<div class="note"><b>버전마다 배치는 조금씩 다를 수 있습니다</b>
<p>웹·앱·운영체제에 따라 메뉴 이름과 위치가 조금씩 바뀔 수 있지만, "새 대화를 시작한다" · "지난 대화를 찾는다" · "계정을 관리한다" 라는 역할 자체는 공통적으로 존재합니다.</p></div>

## Claude Code 화면

Claude Code 화면은 가운데 **대화창**(요청과 답변이 오가는 곳)과 오른쪽 **환경 패널**(지금 다루는 저장소·브랜치·컨텍스트 사용량)로 나뉩니다.

![Claude Code 세션 화면](/images/c1/claude-code-session.png)

| 영역 | 하는 일 |
| --- | --- |
| 상단 제목 | 이번 세션에서 하려는 작업을 요약해서 보여줍니다 |
| 대화창 | 사람이 보낸 요청과, "실행됨 명령 1개"처럼 실제로 수행한 작업, 그리고 결과 답변이 순서대로 쌓입니다 |
| 환경 · 저장소 | 지금 세션이 다루고 있는 저장소(예: `khcho9642-sketch/edu-site`)와 브랜치(예: `main`)를 보여줍니다 |
| 컨텍스트 | 이번 세션이 지금까지 얼마나 "기억"을 채웠는지 비율로 보여줍니다 |

오른쪽 위 폴더 아이콘을 누르면 저장소의 실제 파일 목록도 열어볼 수 있습니다.

![Claude Code 파일 패널](/images/c1/claude-code-files.png)

`app`, `content`, `lib`, `public` 같은 폴더가 보이는데, 이것이 바로 지금 세션의 **작업공간**입니다. 대화창에서 "README.md 요약해줘"라고만 말해도, Claude Code가 이 목록에서 실제 파일을 찾아 열어봅니다.
