## 4. 예상 결과와 검수표

| 항목 | 확인 |
|---|---|
| 장 수 | 정확히 5장 |
| 수치 | 6건 / 확정 5건 / 미확정 1건 / 28,000원 |
| 식비 | 환불 포함 10,000원 |
| 미확정 | T004가 0원 확정으로 표현되지 않음 |
| 편집 | 제목과 표의 실제 편집 가능 여부 확인 |
| 화면 | 글자 겹침·잘림·범례·단위 확인 |
| 발표자 노트 | 요청한 노트가 실제 포함됐는지 확인 |

PowerPoint에서 직접 열었다면 그 결과를 기록한다. 프로그램이 없어 Claude 미리보기만 봤다면 **실제 PowerPoint 열람 미검증**이라고 남긴다. 파일 기능이 없으면 대본 5장과 표를 Markdown으로 작성하는 대체 실습으로 진행한다.

## 5. 막혔을 때

PPTX 다운로드가 없으면 생성 도구의 사용 가능 여부를 확인한다. 단순히 확장자만 pptx로 바꾸지 않는다. 글자·표가 이미지로 들어갔으면 어떤 요소가 편집 가능한지 확인하고 필요한 부분의 재생성을 요청한다. 내용이 많으면 글씨를 무작정 줄이기보다 다섯 장 안에서 내용을 재배치하거나 본문을 줄이고 세부 설명은 노트로 옮긴다. 이번 제출본의 완료 기준은 끝까지 5장이다.

## 화면 보며 따라 하기

**준비:** 보고서 견본과 검토한 28,000원 집계를 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** 파일 생성 기능이 제공되는 업무 대화에서 요청합니다. Marp 설치를 먼저 할 필요는 없습니다.

1. 목적 → 데이터 품질 → 분류별 집계 → T004 → 다음 조치 순서로 5장 구성만 먼저 받습니다.
2. 6건·확정 5건·미확정 1건·28,000원과 식비 10,000원을 확인한 뒤 편집 가능한 PPTX를 요청합니다.
3. 파일이 없으면 대본 5장을 MD로 저장합니다. PPTX가 있으면 실제 슬라이드 수와 노트·표 편집·잘림을 따로 확인합니다.

**완료 확인**

- 표지 포함 총 5장
- 표·슬라이드의 숫자와 미확정 표시가 보고서와 같음

**막혔을 때:** 대본에 .pptx 확장자를 붙여도 PowerPoint 파일이 되지 않습니다. 글씨가 작으면 5장 안에서 본문을 줄이고 노트로 옮기도록 요청합니다.
