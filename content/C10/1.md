# C10. 망했을때 치트시트

<div class="tldr"><b>3줄요약</b>

1. 망하면 아래 **응급처치 표.** 대부분 여기서 해결됨
2. 치트시트는 **출력해서 모니터 옆에**
3. 30강 통틀어 **념글 5개**만 기억해라

</div>

## 1. 망했을 때 보는 글 (응급처치 표)

| 증상 | 먼저 해볼 것 |
|---|---|
| 같은 실수 반복 | `/clear` 후 더 구체적으로. 반복되면 CLAUDE.md에 한 줄 |
| 앞에 한 말 까먹음 | `/context` 확인 → `/compact` or `/clear` |
| 엉뚱한 걸 만듦 | Plan 모드로 계획부터. 기획서 `@`로 주기 |
| 파일 다 꼬임 | Git 마지막 정상 커밋으로 (커밋 안 했으면… 다음엔 해라) |
| 에러를 클코도 못 고침 | 파일·에러 전체·재현 방법·언제까지 됐는지. 3번 실패면 `/clear` 후 다른 접근 |
| "완료!" 했는데 안 됨 | "실행 결과 그대로 보여줘". 직접 열어보기 |
| 테스트 실패 → 클코가 테스트를 고침 | "테스트는 고치지 마" + CLAUDE.md |
| 내 컴에선 되는데 남 컴에선 안 됨 | 라이브러리, `.env`, 경로 (B9) |
| 배포했는데 옛 화면 | `Ctrl+Shift+R`, 시크릿 창 |
| 합계 이상함 | 엑셀 SUM 대조, 헤더 행·빈 칸·인코딩 확인 |
| 한글 깨짐 | CSV를 UTF-8로 저장 |
| 설치·설정 문제 | `claude doctor` / `/doctor` |
| 사용량 금방 바닥 | 모델·`/effort` 낮추기, 대화 짧게, 서브에이전트 줄이기 |
| 비밀키 노출 | **즉시 폐기 + 재발급.** 파일 삭제로 끝 아님 |
| 기능 모르겠음 | `/` 눌러서 목록. 클코한테 "이거 어떻게 해?" |

## 2. 치트시트

### 시작·세션
| 명령 | 뜻 |
|---|---|
| `claude` | 시작 |
| `claude -c` | 방금 대화 이어서 |
| `claude -r "이름"` | 이름으로 열기 |
| `/rename 이름` | 대화 이름 붙이기 |
| `/resume` | 지난 대화 목록 |
| `/exit` | 종료 |

### 기호
| 기호 | 뜻 |
|---|---|
| `/` | 명령어 목록 |
| `@` | 파일 지정 |
| `!` | 터미널 명령 직접 |

### 단축키
| 키 | 뜻 |
|---|---|
| `Shift+Tab` | 권한 모드 전환 |
| `Esc` | 작업 멈추기 |
| `Esc` `Esc` | 체크포인트 선택 (이동·삭제는 별도 백업) |

### 관리
| 명령 | 뜻 |
|---|---|
| `/context` | 노트 얼마나 찼나 |
| `/compact` | 요약해서 정리 |
| `/clear` | 새로 시작 |
| `/model` | 모델 바꾸기 |
| `/effort` | 생각 깊이 |
| `/init` | CLAUDE.md 만들기 |
| `/memory` | 자동 메모리 |
| `/permissions` | 권한 규칙 |
| `/hooks` | 훅 |
| `/agents` | 서브에이전트 |
| `/mcp` | MCP 연결 |
| `/plugin` | 플러그인 |
| `/doctor` | 문제 진단 |

> 명령어 이름은 업데이트로 바뀔 수 있음. 안 되면 `/` 눌러서 확인

### 복붙 지시문 BEST 5
1. `바로 하지 말고 계획부터 보여줘. 질문 있으면 먼저 해줘.`
2. `원본은 두고 _수정본으로 새로 저장해줘.`
3. `됐는지 직접 실행해서 확인하고, 결과를 그대로 보여줘.`
4. `방금 바꾼 거 비전공자한테 설명하듯 3줄로.`
5. `이 기능 망가뜨릴 만한 입력 10개로 테스트해줘. 테스트는 고치지 마.`
