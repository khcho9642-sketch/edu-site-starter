## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
자료실의 가상 공지 A·B만으로 날짜 읽기 연습을 해 줘.
기준일: 2026-12-03. 두 자료는 실습용이며 실제 웹 검색 결과가 아님.
질문: 이날 정원은 몇 명인가? 새 정원은 언제부터인가? 예약 개시일은?
표: 주장/근거 문장/게시일/적용일/기준일에 맞는 결론/미확인.
존재하지 않는 URL을 만들지 말고 자료 A·B로 표시해 줘.
[가상 공지 A·B 전체 붙여 넣기]
```

### 이어서 보낼 요청

```text
이제 ChatGPT 공식 문서 https://learn.chatgpt.com/docs/image-inputs 를 직접 열어 이미지 입력 안내를 확인하자. 검색·접근이 가능한 경우에만 확인한 내용과 직접 URL·확인일을 기록해 줘. 접근하지 못하면 못 했다고 말해 줘. 나는 링크를 직접 열어 주장과 본문을 대조할게.
```

## 6. 기대 결과와 직접 검수

- [ ] 가상 공지 기준 12월 3일 정원은 기존 12명이며 새 정원 16명은 12월 10일부터입니다.
- [ ] 교육실 예약 개시일은 12월 1일입니다. 게시일과 혼동하지 않습니다.
- [ ] 가상 자료는 실제 웹 출처와 분리됩니다. 실제 페이지는 직접 열어 확인한 항목만 기록합니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 검색이 안 됨 | 직접 공식 페이지를 열어 발췌를 제공하고 접근하지 못한 범위를 명시합니다. |
| 최신 글이니 무조건 적용이라 함 | 게시일과 적용일, 기준일을 별도 열로 다시 확인합니다. |
| 출처 링크가 다른 내용임 | 해당 주장을 미확인으로 돌리고 직접 뒷받침하는 출처를 찾습니다. |
