# 클로드 데스크톱 과정 — 읽는 법

C01~C25 순서로 공부합니다. C22~C25는 Code 스킬·훅·서브에이전트·MCP 선택 심화입니다. 일반 업무 활용은 C01~C13 다음 C20~C21로, 앱 개발과 GitHub도 필요하면 C14~C19를 이어 읽습니다. 과정 A·B·C 중 클로드 데스크톱 활용은 과정 C입니다.

## 1. 먼저 내 화면 고르기

| 내 화면 | 시작 방법 |
|---|---|
| 입력창에 Chat / Cowork가 보임 | 간단한 대화는 Chat, 여러 단계의 업무는 Cowork에서 시작 |
| Chat / Cowork 선택이 보이지 않는 통합 화면 | 같은 입력창에서 필요한 업무를 설명 |
| Code 화면 | 로컬/클라우드 프로젝트의 코드와 앱을 다룰 때 사용 |

일반 대화도 기능이 제공되면 파일을 만들 수 있다. “대화는 글만, Code만 파일 생성”으로 구분하지 않는다. 업무 작업과 Code의 지침·권한·저장 위치가 항상 같다고 가정하지 않는다.

## 2. 메뉴 개편과 확인 기준

- **기준일:** 공식 문서는 2026-11-14에 확인했다. 개인 계정의 실제 앱 화면을 클릭해 검증한 교재는 아니다.
- **Plugins / Customize:** 새 Plugins 페이지와 이전 Customize의 Skills·Connectors·Plugins 화면을 구분해 안내한다. Enterprise 적용 시점 등 조직별 전환이 다를 수 있다.
- **프로젝트:** 업무 프로젝트의 지침·계정 파일과 Code의 로컬 프로젝트·CLAUDE.md를 구분한다.
- **파일 생성:** 설정의 Capabilities / Create and edit files 또는 Code execution and file creation 지원과 조직 정책을 확인한다.
- **메뉴가 없음:** 실제 보이는 화면과 공식 안내를 확인한다. 없는 버튼을 있다고 가정하거나 AI가 현재 화면을 보고 있다고 가정하지 않는다. 캡처를 제공할 때 비밀값을 가린다.
- **비용:** 고정 가격이나 특정 플랜 구매를 강요하지 않는다. 현재 제공 기능과 사용량·별도 과금 조건은 본인 계정에서 확인한다.

이 원고는 실제 화면 캡처를 포함하지 않는다. 기존 웹사이트 전용 이미지 경로를 제거했고, 각 강의에 공식 참고 링크를 넣었다. 원고만 별도 폴더로 옮겨도 내부 MD 링크가 유지되도록 구성했다.

## 3. 공통 준비

탐색기에서 `Documents/Claude_연습/입력`, `출력`, `검수`를 만든다. [실습 자료 안내](/desktop-materials/practice)의 MD를 첨부해 시작한다. 터미널에 명령을 입력하는 단계는 필수가 아니다.

- 모든 데이터·인물·메일·가게·서비스는 가짜다.
- 파일 생성 기능이 없으면 Markdown 표·초안으로 대체한다. 파일 생성 성공으로 꾸미지 않는다.
- 로컬 폴더·브라우저·앱이 필요한 작업은 Desktop 연결 상태와 권한을 확인한다.
- 실제 회사 계정 연결·메일 발송·예약 등록은 기본 실습에 필수가 아니다.
- 결과물은 원본·수정본·검수 기록을 나눠 보관한다.

## 5. 학습 순서와 선택 경로

번호 순서대로 읽으면 준비가 필요한 내용을 먼저 배운다.

1. **C01~C05 기초:** 설치·첫 대화 → 파일 전달·저장 → 계획·권한 → 작업 이어가기·모델 → 프로젝트 지침.
2. **C06~C11 자료 업무:** 엑셀·CSV → 영수증·보고서 → 메일·회의록 → 기능 지도 → PPT → 리서치·브라우저.
3. **C12~C13 반복 업무:** 스킬·플러그인 → 예약 작업. 수동 검수 뒤 재사용·반복으로 넘어간다.
4. **C14~C19 앱과 GitHub:** 첫 앱 → GitHub 기초 → 사고 예방 → 커밋·푸시 → 브랜치·PR → 이슈·검사.
5. **C20~C21 마무리:** 문제 해결·치트시트 → 종합 실습.
6. **C22~C25 선택 심화:** Code 스킬 → 훅 → 독립 검토자 → MCP·커넥터. C14의 로컬 프로젝트 작업을 먼저 익히고 진행한다. 기본 업무 활용 과정만 필요하면 건너뛰어도 된다.

- **업무 활용만 필요하면:** C01~C13을 읽고 C20~C21로 가도 된다. 앱 개발·GitHub는 선택 과정이다.
- **앱 개발도 필요하면:** C14부터 이어 읽는다. 첫 푸시 전에 C16의 보안 점검을 먼저 한다.
- **막혔을 때:** C20은 언제든 먼저 열어도 된다.
- **선행 안내:** 각 강의 첫머리에 먼저 읽을 강의를 적었다. 뒤 강의로 가는 링크가 있어도 개요·참고인지, 선행 필수인지 구분한다.


## 6. 강의 구조와 퀴즈

각 강의는 3줄요약 → 준비·입력 → 따라 하기 → 예상 결과·검수 → 막혔을 때 → 숙제 → **4지선다 5문항과 정답·해설**로 구성한다. 기본 21강 105문항과 선택 심화 4강 20문항, 총 125문항이다. 정답은 해설에서 확인하며 브라우저 채점 API나 로그인 없이 원고만으로 공부할 수 있다.

[실습 정답 기준](/desktop-materials/practice)은 자신의 결과를 만든 뒤 비교한다. 숫자를 맞췄어도 미확정을 숨기거나 실제 하지 않은 실행을 했다고 쓰면 검수를 통과한 것이 아니다.

[검토 반영표·공식 참고자료](/desktop-materials/review)에 수정 근거와 원고 검수 상태를 기록했다. 실제 앱에서 실행한 결과와 원고·데이터 검사를 구분한다.

## 8. 추가 원고와 사이트 공개 범위

C22~C25는 사용자가 제공한 확장 기능 4부작을 Desktop Code 중심으로 보완한 추가 원고다. [심화 공통 샘플](/desktop-materials/extensions)로 실습한다. 터미널 명령을 직접 입력하는 대신 Code 입력창에서 생성·검토를 요청한다. 지원되지 않는 기능은 대체 실습과 실제 기능 실행을 구분해 기록한다.

C22~C25는 사이트 과정 C의 강의 목록·본문·퀴즈에도 연결한다. 기본 21강과 선택 심화 4강을 합쳐 데스크톱 25강이며, 원고·실습 자료를 25강 통합 ZIP으로 제공한다. 기존 21강 ZIP은 보관한다. C22~C25에도 강의별 8컷 만화를 사이트에서 볼 수 있다.
