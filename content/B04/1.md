# B04. 설계 그려보기

<div class="tldr"><b>3줄요약</b>

1. 설계 = **화면 그림 / 데이터 표 / 흐름 화살표** 3장. 종이에 그려도 됨
2. 그림마다 답하는 질문이 다름. 하나로 다 설명하려 하지 마라
3. 설계를 AI한테 주면 **"알아서 상상"**하는 부분이 확 줄어듦

</div>

## 1. 설계 3장 세트

| 그림 | 답하는 질문 | 가계부 예 |
|---|---|---|
| **화면 그림** | 사용자가 뭘 보고 뭘 누르나? | 파일 선택 버튼, 표, 합계 카드 |
| **데이터 표** | 뭘 저장하고 어떻게 연결되나? | 지출 테이블, 카테고리 규칙표 (A5·A6) |
| **흐름도** | 무슨 순서로 일이 일어나나? | 파일 선택 → 읽기 → 분류 → 합계 → 표시 |

## 2. 화면 그림 (와이어프레임)

예쁠 필요 없음. 네모 박스로.

```
┌────────────────────────────────────┐
│  가계부 미니앱                       │
│  [CSV 파일 선택]                    │
├────────────────────────────────────┤
│  날짜     | 가게      | 금액 | 분류  │
│  11/01   | 김밥천국   | 4500 | 식비  │
│  11/01   | 지하철     | 1550 | 교통  │
│  11/02   | ???마트    | 만원 | ⚠확인 │ ← 빨간색
├────────────────────────────────────┤
│  11월 합계: 523,400원                │
│  식비 210,000 | 교통 62,000 | ...    │
│  [결과 CSV로 내보내기]               │
└────────────────────────────────────┘
```

화면마다 **4가지 상태**(A2) 체크: 파일 선택 전(빈 상태), 읽는 중, 성공, 실패.

## 3. 데이터 표

| 테이블 | 열 | 규칙 |
|---|---|---|
| 지출 | 날짜, 가게, 금액, 카테고리 | 금액 숫자·0 이상, 날짜 필수 |
| 분류규칙 | 키워드, 카테고리 | "김밥" → 식비, "지하철" → 교통 |

MVP는 DB 안 쓰고 CSV로 해도 됨. 그래도 **열 이름과 규칙은 정해둬라.**
