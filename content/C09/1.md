# C09. 클코 고인물되기

<div class="tldr"><b>3줄요약</b>

1. **CLAUDE.md는 업무 규칙, 훅은 설정된 이벤트의 자동 검사.** 실제 차단 여부는 이벤트·설정·권한을 함께 검증해야 합니다.
2. **같은 지시 3번 했으면 스킬로.** 한 줄로 부름
3. **서브에이전트** = 따로 일하는 팀원, **MCP** = 외부 서비스에 꽂는 손, **플러그인** = 다 묶은 패키지

</div>

## 0. 뭘 언제 씀? (이 표만 외워도 됨)

| 상황 | 도구 | 비유 |
|---|---|---|
| 항상 지킬 규칙 | **CLAUDE.md** | 업무 수첩 (가끔 까먹음) |
| **절대** 어기면 안 되는 규칙 | **훅** | 자동 차단기 |
| 자주 하는 작업 절차 | **스킬** | 업무 매뉴얼 |
| 따로 맡길 전문 일 | **서브에이전트** | 전문 팀원 |
| 외부 서비스 연결 | **MCP** | 외부 도구에 꽂는 손 |
| 위 것들 묶어서 공유 | **플러그인** | 업무 패키지 |

## 1. 훅: 이벤트에 맞춰 실행하는 자동 장치

| 순간 | 예 |
|---|---|
| 도구 실행 **직전** | 위험 명령 **차단** |
| 파일 수정 **직후** | 자동 검사 |
| 내 입력 기다릴 때 | 알림 띄우기 |
| 작업 끝났을 때 | 완료 알림 |

말로 설정:
> 클코가 내 입력 기다릴 때 컴퓨터 알림 띄워줘

> 전체 삭제, 강제 푸시 같은 위험 명령은 실행 전에 막아줘

확인: `/hooks`

## 2. 스킬: 반복 작업을 한 줄로

C5에서 저장해둔 잘 먹힌 지시문 → 스킬로.

```
.claude/skills/
└── 지출정리/
    └── SKILL.md
```

```markdown
---
name: 지출정리
description: 카드 명세서나 지출 CSV를 받아 카테고리 분류하고 월별 합계를 낼 때 사용
---

1. 5건만 먼저 분류해서 보여주고 확인받는다
2. 카테고리: 식비/교통/쇼핑/구독/기타. 애매하면 "미분류"
3. 원본은 두고 `_정리.csv`로 저장
4. 월별·카테고리별 합계 + 건수
5. 마지막에 총 건수, 미분류 건수 보고
```

이제 **"지출 정리해줘"** 한 마디면 이 절차대로.

- **description이 성패를 가름.** "**언제** 쓰는지" 구체적으로
- 클코한테 "방금 한 작업 스킬로 만들어줘" 해도 됨
