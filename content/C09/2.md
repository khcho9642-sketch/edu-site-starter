## 3. 서브에이전트: 따로 일하는 팀원

메인 클코가 다 하면 노트 금방 참(C3). 서브에이전트는 **자기 노트 따로** → 메인은 결과 요약만 받음.

| 언제 | 예 |
|---|---|
| 큰 폴더 뒤지기 | 내장 **Explore** 에이전트 (읽기만) |
| 검수 | B7 "자기 숙제 자기 채점" 방지 |

### 리뷰어 만들기
`/agents` → 새로 만들기 → 도구는 **Read, Grep, Glob만** (읽기 전용)

> 처음엔 **권한 좁게.** 리뷰어한테 수정 권한 주면 리뷰하다 고쳐버림

## 4. MCP: 외부 서비스에 꽂는 손

C7 **커넥터**의 정체가 MCP. 커넥터에 없는 건 직접 연결.

```bash
claude mcp add --transport http 이름 https://서비스주소/mcp
```
- `/mcp`로 로그인·확인, `claude mcp list`로 목록
- **비밀키는 설정 파일에 직접 쓰지 마라** (B8)

## 5. 플러그인: 묶음 설치

`/plugin` → Discover에서 검색 → 설치. **남이 만든 거니까 뭘 실행하는지 읽고 설치.**

<div class="danger"><b>이거 모르면 큰일남</b>

- **남의 플러그인·MCP 무작정 설치** = 남의 코드를 내 권한으로 실행
- 서브에이전트 남발 = **사용량 순삭** (C3)
- 스킬 description 대충 쓰면 안 불리거나 엉뚱할 때 불림

</div>
