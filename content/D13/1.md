## [강좌] C13. 예약 작업 — 어디서 돌고 무엇을 읽는지 확인하기

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 업무 작업의 Scheduled / 예약 메뉴, Code 로컬 예약과 비교
> 실제 예약 생성은 선택입니다. 등록 자체와 다음 실행 성공을 구분해 기록합니다.

> 먼저 읽을 강의: C03 · C06 · C09.

## 3줄요약

1. 수동 결과를 검증한 후 같은 기준으로 예약한다.
2. 클라우드 실행과 내 PC 파일·앱 접근의 조건을 따로 확인한다.
3. 실행 위치·시간대·입력 자료·결과·중지 방법까지 확인해야 예약을 이해한 것이다.

## 1. 예약 전에 수동 결과 확인

[지출 샘플](/desktop-materials/expenses)만 사용한다. 다음 요청을 세 번 수동으로 실행하고 결과가 일치하는지 확인한다.

> 이 연습 자료의 거래 수, 확정 금액 합계, 미확정 거래 ID, 환불 거래 ID를 표로 정리해줘. 새 메일 조회나 외부 발송은 하지 마. 원본을 수정하지 말고 보고 초안만 만들어줘.

세 번 모두 **6건 / 확정 5건 28,000원 / T004 / T005**가 나오는지 기록한다. 한 번이라도 틀리면 예약 전에 요청과 자료를 고친다.

## 2. 실행 위치와 입력 자료 확인

| 종류 | 실행 조건을 확인할 것 |
|---|---|
| 현재 Cowork 클라우드 예약 | 클라우드에서 실행. 연결 도구와 계정에 저장된 자료의 접근 가능 여부 확인 |
| 기존 로컬 Cowork 예약 | 로컬 실행인지 상세 화면과 기존 작업 정보를 확인 |
| Code Desktop 로컬 예약 | 해당 PC·앱 실행 상태와 로컬 프로젝트 환경 확인 |
| 클라우드 예약에서 내 PC 파일·브라우저·앱 사용 | 원격 작업과 별개로 Desktop의 실행·연결·허용 조건 확인 |

“매주 보고서”라는 이름만으로 종류를 판단하지 않는다. 같은 폴더 이름의 로컬 파일과 계정에 저장된 파일은 다른 자료다. 현재 대화 첨부가 새 예약 작업에도 자동으로 전달된다고 생각하지 않는다.
