## 3. "해도 됨?" 물어볼 때

Default 모드에서 클코가 승인 요청하면:

| 요청 | 판단 |
|---|---|
| 파일 읽기 | 대부분 OK |
| 파일 수정 | 무슨 파일인지 확인 |
| 명령 실행 | **명령 내용 읽어봐라.** 모르면 "이 명령 뭐 하는 거야?" |
| 삭제 (`rm` 등) | **무조건 확인.** 뭘 지우는지 |
| 외부 전송 | 안 시킨 거면 거절 |

## 4. 위험한 건 아예 막기

말로 하면 됨:
> `.env` 파일이랑 `개인자료/` 폴더는 읽지도 못하게 막아줘

> 전체 삭제, 강제 푸시 같은 위험 명령은 실행 못 하게 막아줘

현황 보기: `/permissions`. **차단(deny)이 허용(allow)을 이김.**

<div class="danger"><b>이거 모르면 큰일남</b>

- **Auto 모드 = "덜 물어보는" 거지 "안전한" 게 아님**
- 승인 버튼 **습관적으로 연타 금지.** 그럼 Default 쓰는 의미 없음
- 한 달에 한 번 `/permissions` 열어서 안 쓰는 허용 규칙 청소

</div>
