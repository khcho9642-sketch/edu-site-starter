## [정보] 신입한테 얼마나 맡길래? — 권한 모드와 Plan 모드

<div class="tldr"><b>3줄요약</b>

1. **`Shift+Tab`**으로 클코한테 얼마나 맡길지 정함
2. 큰 일은 무조건 **Plan 모드**부터. **10분 계획이 2시간 삽질 막음**
3. **Bypass(전부 알아서)는 처음에 쓰지 마라.** 신입 첫날 법인카드 주는 거임

</div>

## 1. 권한 모드 4종

| 모드 | 하는 짓 | 언제 |
|---|---|---|
| **Plan** | 계획만 세움. 손 안 댐 | 큰 작업 시작 전 **(강추)** |
| **Default** | 고칠 때마다 "해도 됨?" 물어봄 | 처음 쓸 때 |
| **Auto-accept** | 파일 수정은 알아서, 명령 실행만 물어봄 | 익숙해진 뒤 |
| **Bypass** | 전부 알아서 | 거의 안 씀. 무서움 |

## 2. Plan 모드가 왜 중요하냐

AI랑 일할 때 제일 큰 낭비 = **방향 틀려서 처음부터 다시 하는 거**.

### 흐름

```
Plan 모드로 계획 → 내가 읽고 태클 → 계획 수정 → 확정 → 일반 모드로 "계획대로 해줘"
```

### 태클 거는 법

| 계획에 이런 게 보이면 | 이렇게 |
|---|---|
| 안 시킨 기능 추가 | "이건 빼" |
| 파일 대량 수정 | "왜 이 파일까지 바꿔?" |
| 애매한 단계 | "3번 단계 더 구체적으로" |
| 확인 방법 없음 | "다 됐는지 어떻게 확인해?" |
