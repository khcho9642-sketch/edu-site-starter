## 4. 배포 전 체크

```

[ ] B8 보안 체크리스트 통과

[ ] 다른 사람 폰·브라우저로 열어봤다

```

## 5. 옛날 화면이 계속 보이면

대부분 **캐시** (브라우저가 예전 거 들고 있음)
- `Ctrl+Shift+R` (강력 새로고침) / 시크릿 창
- 그래도 그러면 AI한테 "배포했는데 옛 화면 보여. 캐시인지 확인해줘"

<div class="danger"><b>이거 모르면 큰일남</b>

- **운영 환경에서 실험 금지**
- 배포 링크는 **아는 사람 누구나 접속 가능.** 개인 데이터 다루는 앱은 로그인·권한(B8) 없이 배포 금지
- 무료 플랜도 **한도 넘으면 과금**될 수 있음

</div>
