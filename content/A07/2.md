## 3. 데이터 넣을 때: 바로 넣지 마라

CSV 받았다고 바로 DB에 넣으면 쓰레기 들어감.

```
불러오기 → 검사(형식·빈칸·중복) → 문제 목록 확인 → 고친 것만 넣기 → 건수·합계 맞춰보기
```

마지막 **"건수·합계 맞춰보기"** 중요. 원본 300건 합계 85만원인데 DB엔 298건 84만원이면 2건 어디 갔는지 찾아야 함.
