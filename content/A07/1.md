# A07. SQL 4개만

<div class="tldr"><b>3줄요약</b>

1. SQL = **DB한테 말 거는 언어.** 쓰는 건 AI가 함. 우리는 **읽을 줄만** 알면 됨
2. `SELECT`(필터) · `GROUP BY`(피벗) · `JOIN`(VLOOKUP) · `UPDATE`(수정) 4개면 끝
3. **`UPDATE`·`DELETE`에 `WHERE` 없으면 전체가 날아감.** 이거 하나는 진짜 외워라

</div>

## 1. SQL 4개 = 엑셀 감각

| SQL | 엑셀 감각 |
|---|---|
| `SELECT ... WHERE` | 필터 |
| `GROUP BY` + `SUM` | 피벗 |
| `JOIN` | VLOOKUP |
| `UPDATE` / `DELETE` | 값 고치기 / 행 삭제 **(위험)** |

## 2. 하나씩 읽어보기

### ① 필터: 11월 지출만

```sql
SELECT * FROM 지출
WHERE 날짜 >= '2026-11-01' AND 날짜 < '2026-12-01';
```
"지출 테이블에서, 날짜가 11월인 것만, 전부(*) 보여줘"

### ② 피벗: 가게별 합계

```sql
SELECT 가게ID, SUM(금액) AS 합계, COUNT(*) AS 건수
FROM 지출
GROUP BY 가게ID;
```
"가게별로 묶어서 금액 합계랑 건수"

### ③ VLOOKUP: 가게 이름 붙이기

```sql
SELECT 지출.날짜, 가게.이름, 지출.금액
FROM 지출 JOIN 가게 ON 지출.가게ID = 가게.가게ID;
```
"지출에 가게 테이블을 가게ID 기준으로 붙여서"

### ④ 수정 ⚠️

```sql
UPDATE 가게 SET 이름 = '김밥천국 강남점' WHERE 가게ID = 'S01';
```
**WHERE 빼먹으면 모든 가게 이름이 '김밥천국 강남점'이 됨.**
