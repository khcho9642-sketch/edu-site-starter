## 4. 주의 사항

- 첫 실습은 **비공개 저장소 + 가짜 데이터**로만 한다.
- 계정명·다른 비공개 저장소 이름이 보이는 화면은 캡처해서 공유하지 않는다.
- GitHub 로그인, 2단계 인증 코드, 토큰은 **내가 직접** 처리한다. 채팅에 붙여넣지 않는다.
- 화면 메뉴 이름은 업데이트로 바뀔 수 있다. 보이는 이름을 그대로 적어두고 공식 문서로 확인한다.

## 5. 이렇게는 쓰지 말자

| ❌ 이렇게 하지 말자 | ✅ 대신 이렇게 | 이유 |
|---|---|---|
| "일단 Public으로 만들고 나중에 비공개로 바꾸자" | 처음부터 Private | 공개된 동안 누가 복사했는지 알 수 없다 |
| 실제 회사 엑셀로 첫 실습 | 실습자료의 가짜 CSV | 회사 정책 위반·유출 위험 |
| "내 GitHub 비밀번호는 ○○야, 로그인해줘" | 로그인은 내가 직접 | 비밀번호를 AI에 주면 안 된다 |
| 저장소 화면 전체 캡처를 단톡방에 공유 | 필요한 부분만, 계정명 가리고 | 계정명·다른 저장소 이름이 노출된다 |

## 6. 확인 방법과 막혔을 때

- 저장소 화면에 Private 표시가 있는지 직접 본다.
- README가 보이면 성공이다. 안 보이면 README 추가 버튼으로 한 줄 써서 저장(Commit)한다.
- 가입·인증 단계가 막히면 GitHub 공식 도움말을 따른다. AI에게는 "보이는 화면 문구"만 전달한다.

## 화면 보며 따라 하기

**준비:** GitHub 계정과 연습 저장소 이름을 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** 같은 GitHub 화면을 재사용합니다. Codex가 없어도 GitHub의 저장소·README를 읽을 수 있습니다.

1. 로그인 뒤 + → New repository를 엽니다. 그림의 설정 위치만 참고하고 내 이름·Private·README 추가를 확인합니다.
2. 이미 만든 연습 저장소가 있다면 다시 만들지 말고 그 저장소를 엽니다.
3. 저장소 화면의 Private 표시와 README를 직접 확인합니다. Code라는 초록 버튼은 GitHub의 복제 메뉴입니다.

**완료 확인**

- Private 표시·README·정확한 저장소 주소
- 앱의 Code 화면과 GitHub Code 버튼을 구분

**막혔을 때:** 원본 그림이 Public·README Off 상태이면 그대로 따라 만들지 않습니다. 이번 연습은 Private·README On입니다. GitHub 웹 로그인과 로컬 Git 인증은 별개일 수 있습니다.
