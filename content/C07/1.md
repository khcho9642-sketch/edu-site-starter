# C07. 메일 회의록 커넥터

<div class="tldr"><b>3줄요약</b>

1. **커넥터** 연결하면 Gmail·Slack·Notion 같은 데 클코가 직접 들어감 (속은 MCP. C9)
2. **보내기 전엔 초안까지만.** 발송 버튼은 몇 주간 사람이 누른다
3. 회의 녹음 → 텍스트 → **결정 / 할 일(담당·기한) / 미결** 회의록

</div>

## 1. 커넥터 연결

1. Claude 앱·Cowork의 커넥터 설정에서 필요한 서비스와 접근 범위를 확인합니다. CLI에서는 MCP 연결을 사용하며 설정 방식이 다릅니다.
2. 연결된 계정과 읽기·쓰기 범위를 확인하고, 먼저 읽기나 초안 작업부터 시작합니다.

입력창 왼쪽 `+` 버튼 누르면 커넥터·Skills·플러그인 메뉴 나옴.

> 커넥터는 **내 계정 권한 그대로** 씀. 회사 계정이면 IT팀 확인 먼저

## 2. 메일 정리

> 최근 3일 안 읽은 메일 중에 답장 필요한 것만 골라서 긴급도(상/중/하)랑 한 줄 요약 표로. 답장 초안은 '상'만, 정중한 톤으로.

톤 맘에 안 들면 **같은 대화에서** "더 짧게", "덜 딱딱하게".

### 활용 예

| 상황 | 지시 |
|---|---|
| 휴가 복귀 | "휴가 기간 메일 중 내가 처리해야 할 것만 목록" |
| 뉴스레터 폭탄 | "뉴스레터는 제목만 모아서 한 줄씩" |
| 답장 초안 | "이 메일에 거절하는 답장, 정중하게, 3문장" |
