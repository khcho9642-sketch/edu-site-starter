# B07. 이거 진짜 되냐

<div class="tldr"><b>3줄요약</b>

1. AI 잘 쓰는 법 딱 하나만 고르라면: **"확인할 수단을 줘라"**
2. 테스트 = B3에서 쓴 **"다 된 기준"을 자동으로 채점**하는 것
3. AI 코드는 **그럴듯하게 틀림.** 일부러 괴롭혀봐라

</div>

## 1. AI가 뻥치는 패턴

| AI 주장 | 실제로 있었던 일 |
|---|---|
| "테스트 통과했습니다" | 테스트를 안 돌림 / 실패하는 테스트를 지움 |
| "버그 수정 완료" | 에러 메시지만 안 뜨게 숨김 |
| "모든 경우 처리했습니다" | 빈 파일, 마이너스 금액은 안 해봄 |
| "합계 523,400원입니다" | 헤더 행까지 더함 |

**"됐다"는 주장이고, 열어서 확인한 게 증거임.**

## 2. 검증 3단계

| 단계 | 질문 | 방법 |
|---|---|---|
| ① 돌아가나 | 열리긴 함? 에러 없음? | 직접 실행, F12 콘솔 |
| ② 맞게 돌아가나 | 결과가 기준이랑 같음? | B3 "다 된 기준"으로 O/X |
| ③ 괴롭혀도 버티나 | 이상한 거 넣으면? | 엣지 케이스 |

대부분 ①에서 멈춤. **③에서 진짜 버그 나옴.**

## 3. 엣지 케이스: 일부러 괴롭히기

| 넣을 거 | 기대 동작 |
|---|---|
| 빈 CSV | "데이터가 없어요" (멈추면 안 됨) |
| 금액 "만원" | 확인필요 표시 |
| 금액 -12,000 (환불) | 기획서에 정한 대로 (정했어야 함!) |
| 날짜 "2026/11/3" vs "2026-11-03" | 둘 다 인식 or 확인필요 |
| 같은 파일 두 번 | 중복 경고 |
| 1만 건 | 느려도 멈추진 않음 |
| 금액 0 (무료 쿠폰) | 0을 오류로 잡으면 안 됨 |

> AI한테 **"이 기능 망가뜨릴 만한 입력 10개 생각해줘"** 하면 잘 뽑아줌
