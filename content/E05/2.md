## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
실습 지출 CSV를 정리해 줘. 원본은 변경하지 마.
1. 헤더 제외 행 수와 열, 중복 거래번호를 먼저 보고.
2. 거래번호와 모든 값이 같은 X002 중복은 한 줄만 반영하고 제외 내역 기록.
3. 빈 금액 X004는 미확인으로 남기고 합계 제외. 환불 음수 유지.
4. 정리표/예외표/분류별 확인 합계/원본 대사표를 만들어 줘.
5. 확인된 합계와 전체 확정 여부를 구분. 계산식과 건수도 표시.
파일 생성이 가능하면 별도 정리본으로, 불가능하면 표와 CSV 본문으로 제시해 줘.
[지출 CSV 전체를 첨부하거나 붙여 넣기]
```

### 이어서 보낼 요청

```text
중복 포함 원본 숫자 합계, 중복 제외 확인된 합계, 미확인 건수를 대조해 줘. 차트에는 미확인을 0원으로 넣지 말고 제외 이유를 주석으로 적어 줘.
```

## 6. 기대 결과와 직접 검수

- [ ] 원본 6행, 동일 중복 제외 1행, 정리 후 고유 거래 5건입니다.
- [ ] 확인 금액 4건과 미확인 1건이 구분됩니다.
- [ ] 원본 숫자 합 58,000원 - 중복 18,000원 = 확인된 순액 40,000원입니다.
- [ ] 음료 25,000원·인쇄 15,000원이며 장소는 미확인입니다. 미확인을 포함한 전체 합계는 아직 확정할 수 없습니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.
