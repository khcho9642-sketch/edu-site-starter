## 2. 회사 업무 버전

같은 공식으로 이런 것들 됨:

| 업무 | 지시 예 |
|---|---|
| 설문 결과 정리 | "응답 엑셀에서 문항별 응답 수, 주관식은 비슷한 것끼리 묶어서 요약" |
| 매출 정리 | "지점별·월별 합계, 전월 대비 증감률" |
| 명단 정리 | "중복 이름 찾고, 전화번호 형식 통일 (원본 두고)" |
| 여러 파일 합치기 | "이 폴더 엑셀 12개(월별) 하나로 합치고 '월' 열 추가" |

## 3. 엑셀 받을 때 주의

| 상황 | 대처 |
|---|---|
| 10MB 넘음 | 필요한 시트·열만 잘라서 |
| 수식 있음 | 값으로 붙여넣기 한 사본 |
| 위에 제목줄·병합셀 | "3행부터가 헤더야" 알려주기 |
| 한글 깨짐 | "CSV UTF-8"로 다시 저장 |
