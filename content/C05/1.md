# C05. 엑셀 CSV 정리 탈출

<div class="tldr"><b>3줄요약</b>

1. 자동화 국룰: **샘플 5건 → 확인 → 전체.** 300건 한 번에 던지지 마라
2. 순서: **확인 → 정제 → 요약 → 차트**
3. **숫자는 무조건 교차검증.** 클코 합계, 엑셀 SUM으로 다시 맞춰봐라

</div>

## 0. 자동화 황금 공식

```
예시 1건 → 결과 확인 → 같은 대화에서 고쳐달라 → 형식 확정 → 전체 돌리기
```

**같은 대화에서** 고치는 게 포인트. 새 대화면 맥락 까먹음 (C3).

## 1. 4단계 따라하기

### ① 확인
> `@카드명세서.csv` 구조 설명해줘. 열 이름, 행 수, 빈 칸 있는 열, 이상해 보이는 값. 고치지 마.

### ② 정제
> 날짜 YYYY-MM-DD로 통일, 금액에서 '원'이랑 콤마 빼서 숫자로. 원본 두고 `명세서_정제.csv`로 저장

### ③ 요약
> 가게 이름 보고 카테고리(식비/교통/쇼핑/구독/기타) 붙이고, 월별·카테고리별 합계표. 각 합계 옆에 건수도. 분류 애매한 건 "미분류"로

### ④ 차트
> 카테고리별 합계 막대그래프 PNG로
