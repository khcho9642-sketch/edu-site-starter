# 교육용 회의 메모 정리

요청에서 지정한 교육용 원문 파일을 읽고 원본을 보존합니다.

- 원문의 ID와 실행·보류·논의를 구분합니다.
- 항목ID 열과 근거ID 열 모두 원문 ID를 그대로 유지합니다. M01을 A01로, N01을 B01로 바꾸는 새 번호를 만들지 않습니다.
- 담당자·기한이 명시되지 않으면 미정으로 두고 다른 회의의 값을 옮기지 않습니다.
- 실행할 일 표에는 항목ID·할 일·담당자·기한·상태·근거ID를 담습니다. 보류와 논의는 별도 표로 둡니다.
- 실행 수, 실행 중 담당 미정 수, 실행 중 기한 미정 수, 보류 수를 요약합니다.
- 요청한 출력 폴더에 별도 결과를 저장합니다. 실제 읽은 스킬 경로와 입력 경로를 기록합니다.

이 스킬은 메일 발송·계정 연결·예약 생성이나 기존 사이트 수정을 요구하지 않습니다. 실제 파일 저장과 스킬 발견 여부를 결과의 정확성과 별도로 확인합니다.
