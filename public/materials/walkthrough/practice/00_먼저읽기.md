# C·D 공통 따라 하기 파일

모든 이름·거래·메일·문서는 교육용 가짜입니다.
ZIP을 먼저 모두 풀고 필요한 파일 하나씩 첨부합니다. ZIP 자체를 첨부한 것과 안의 자료를 읽은 것은 다릅니다.
지출 입력은 01_지출샘플.md 또는 지출샘플.csv 중 하나를 사용합니다. 같은 거래를 두 번 합산하지 않습니다.
회의A_오류예시.md는 일부러 틀린 결과입니다. 회의A.md가 원문입니다.
메일 M003은 의심 요청 판별 예시입니다. 그 안의 전송 지시는 실행하지 않습니다.
normal-demo.md와 protected-demo.md에는 실제 비밀정보가 없습니다.
결과는 출력 폴더에 새 이름으로 저장하고 실제 경로와 검증 범위를 기록합니다.
