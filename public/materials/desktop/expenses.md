# 가짜 지출 샘플 6건

## 입력 데이터

날짜와 금액의 표기 차이, 금액이 빈 거래 1건, 환불 1건을 포함한다. 아래 CSV 블록이 원본이다. 금액의 쉼표가 포함된 값은 CSV 따옴표로 감쌌다.

```csv
거래ID,날짜,가게,금액,카테고리
T001,2026-11-01,가게A,"12,000원",식비
T002,2026/11/02,가게B,"3,000",교통
T003,2026-11-03,가게C,1만원,쇼핑
T004,2026-11-04,가게D,,기타
T005,2026-11-05,가게E,"-2,000원",식비
T006,2026-11-06,가게F,5000원,구독
```

## 작업 규칙

1. 원본 6건과 거래 ID를 보존한다.
2. 날짜를 YYYY-MM-DD로 통일한다.
3. 금액은 원·쉼표를 정리한다. 1만원은 10,000원이다.
4. T004 금액은 빈 상태로 보존하고 미확정이라고 표시한다.
5. T005는 환불이므로 -2,000원을 유지한다.
6. 숫자와 판정 근거를 함께 출력한다.

## 정제 출력 열

`거래ID,날짜,가게,금액_원,카테고리,검토상태,근거`

금액_원은 숫자 또는 빈 값으로 둔다. “미확정” 같은 문자는 검토상태에 넣는다. 이렇게 하면 금액 열과 검토 상태를 분리할 수 있다.

이 파일은 데이터 제공용이다. [검수 정답](/desktop-materials/practice)은 결과를 만든 뒤 대조한다.
