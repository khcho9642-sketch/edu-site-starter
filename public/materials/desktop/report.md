# 월별 지출 검토 보고서 견본

> 형식 참고용이다. 대괄호의 값을 새로운 입력 자료로 확인해 채운다. 빈칸에 숫자를 상상해 넣지 않는다.

## 1. 요약

- 대상 기간: [입력 자료에서 확인한 기간]
- 전체 거래 수: [건수]
- 확정 금액 거래 수: [건수]
- 확인된 금액 합계: [금액]원
- 미확정 거래 수: [건수]

합계는 확인된 거래의 합계이며, 미확정 금액을 포함한 전체 최종 금액이라고 단정하지 않는다.

## 2. 데이터와 처리 기준

| 항목 | 기재 내용 |
|---|---|
| 입력 | 실제 사용한 파일명 |
| 원본 보존 | 원본과 결과의 위치 |
| 금액 정리 | 통화·단위·쉼표·환불 처리 |
| 미확정 | 거래 ID·사유·추가 확인 필요 자료 |
| 검증 | 원본 대조·합계 교차검증 방법 |

## 3. 집계 결과

카테고리별 확정 합계와 건수를 표로 작성한다. 금액을 모르는 거래는 미확정 건수로 별도 표시한다. 근거가 없는 전월 대비 수치나 업계 평균을 넣지 않는다.

## 4. 확인필요 사항과 다음 조치

| 거래 ID/항목 | 확인할 내용 | 담당 | 기한 |
|---|---|---|---|
| [값] | [근거가 부족한 부분] | 미정이면 미정 | 미정이면 미정 |

## 최종 검수

원본 행 수, 환불 부호, 미확정 상태, 합계, 표의 잘림을 확인한다. 실제 Word에서 열지 못했다면 “미리보기 검수, Word 열람 미검증”으로 기록한다.
