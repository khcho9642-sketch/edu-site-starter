# [강좌] C04. 모델과 작업 노트 — 어제 하던 일 이어가기

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 앱의 대화 목록·모델 선택·계정 사용량 화면
> 터미널의 /context·/compact를 필수 조작으로 사용하지 않습니다.

> 먼저 읽을 강의: C01 · C02.

## 3줄요약

1. 같은 작업은 기존 대화에서 이어가고, 주제가 바뀌면 새 대화로 분리한다.
2. 대화 요약과 프로젝트 지침·기억은 역할이 다르다.
3. 사용 가능한 모델과 사용량을 실제 화면에서 확인한다. 모델 이름만으로 비용을 단정하지 않는다.

## 1. 준비와 오늘의 결과

C01의 대화나 [지출 샘플](실습자료/01_지출샘플.md)을 연다. 결과는 `작업인수인계.md` 한 개다.

## 2. 지난 작업 이어가기

1. 왼쪽 최근 대화·작업 목록에서 기존 작업을 연다.
2. 제목이나 이름 편집 메뉴가 있으면 `연습_지출정리`처럼 찾기 쉽게 바꾼다.
3. “지금까지 확정한 규칙과 아직 해결하지 않은 부분을 구분해줘”라고 요청한다.
4. 없는 기억을 안다고 답하면 원문 자료를 다시 첨부하고 근거를 확인한다.

> 인수인계 메모를 만들어줘. 목표, 사용한 파일명, 확정 규칙, 완료 작업, 미해결 항목, 다음 할 일, 결과 파일 위치를 적어줘. 확인하지 않은 내용을 완료했다고 쓰지 마.

5. 메모를 저장하고 새 대화에 첨부한다. 새 대화에서 **T004 금액 미확정, T005 환불**을 그대로 이해했는지 확인한다.
6. 새 대화를 열어도 파일이 삭제되는 것은 아니다. 반대로, 이전 대화 내용이 새 대화로 전부 자동 전달된다고 가정해서도 안 된다.

## 3. 모델과 사용량 확인

- 입력창의 모델 선택기를 열고 **현재 선택 가능한 모델만** 기록한다. 모델 이름과 제공 여부는 플랜·조직 설정에 따라 달라진다.
- 먼저 기본 모델로 작은 표 정리를 해본다. 복잡한 비교나 설계는 사용 가능한 더 높은 추론 설정을 검토한다.
- 비교 실습은 같은 입력과 같은 확인 기준으로 한다. “더 길게 답함” 대신 누락·정확성·작업 시간·소비한 사용량을 비교한다.
- 계정 설정의 사용량·요금 화면에서 현재 한도와 별도 과금 설정을 확인한다. 구독 사용량 제한과 API의 사용량 과금은 같은 개념이 아니다.
- 긴 대화, 큰 첨부, 도구 실행, 병렬 작업은 사용량에 영향을 줄 수 있다. 새 대화를 열면 무조건 싸진다고 단정하지 않는다.

## 4. 예상 결과와 막혔을 때

인수인계 메모에는 확인한 내용과 확인하지 못한 내용이 구분돼 있어야 한다. 샘플의 알려진 합계는 28,000원이고 미확정 거래는 1건이지만, 정제를 아직 하지 않았다면 메모에 “집계 검증 전”이라고 써야 한다. 특정 모델이 메뉴에 없으면 설치 오류로 단정하지 말고 현재 선택 가능한 모델끼리 비교한다.

## 화면 보며 따라 하기

**준비:** 이전 대화와 작업인수인계.md 저장 위치를 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** 모델 버튼에서 현재 모델과 노력 수준을 읽습니다. 그림에 보이는 모델은 캡처 당시 계정의 예시이며 필수 모델이 아닙니다.

1. 기존 대화에서 목표·입력 파일·확정 규칙·완료·미해결·다음 할 일·결과 경로를 요약해 달라고 합니다.
2. 확인하지 않은 계산을 검증 완료로 적지 않았는지 읽고 인수인계 MD로 저장합니다.
3. 새 대화에 메모와 필요한 원문을 함께 전달해 T004·T005를 다시 물어봅니다. 모델 선택은 현재 화면에 보이는 항목만 기록합니다.

**완료 확인**

- T004 미확정과 T005 환불이 유지됨
- 검증 전·완료·다음 작업이 구분됨

**막혔을 때:** 새 대화가 옛 첨부 파일을 자동으로 볼 수 있다고 생각하지 마세요. 모델 이름이나 사용량 수치를 다른 사람의 화면에서 그대로 복사하지 않습니다.

![따라 하기 화면](/materials/walkthrough/screens/claude-model-menu.png)

**이번 검토에서 확인한 범위:** 클로드 모델 메뉴를 직접 열어 확인했습니다. 사용량·결제 화면 및 새 대화 인수인계의 제품별 실행은 별도 검증 대상입니다.

## 숙제

1. 기존 대화의 확정 사항과 미해결 항목을 분리해 메모로 저장한다.
2. 메모를 새 대화에 첨부하고 T004·T005의 상태를 확인한다.
3. 계정의 사용량 화면을 찾아 확인일과 한도를 적되, 결제 정보는 원고에 복사하지 않는다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. 완전히 다른 업무를 시작할 때 좋은 방법은?

- A. 원본 파일을 삭제한다
- B. 무조건 최고 모델로 바꾼다
- C. 새 대화로 분리하고 필요한 자료만 전달한다
- D. 이전 작업에 계속 섞어 적는다

### Q2. 새 대화에 이전 작업을 정확히 전달하려면?

- A. 비밀번호까지 모두 붙인다
- B. 목표·규칙·미해결 항목을 정리한 메모를 첨부한다
- C. 다 기억하겠지 하고 시작한다
- D. 결과 파일명만 말한다

### Q3. 아직 합계를 검증하지 않았다면 인수인계에 어떻게 쓸까?

- A. 집계 검증 전으로 표시한다
- B. 검증 완료라고 쓴다
- C. 예상 숫자를 확정값으로 쓴다
- D. 미해결 항목을 지운다

### Q4. 특정 모델이 선택기에 없을 때는?

- A. 모든 파일이 손상된 것이다
- B. 항상 재설치가 정답이다
- C. 다른 사람 유료 계정을 빌린다
- D. 현재 계정과 정책에서 제공되는 선택지를 확인한다

### Q5. 구독 한도와 API 요금의 관계는?

- A. 둘 다 언제나 무제한이다
- B. 새 대화를 열면 둘 다 무료가 된다
- C. 서로 다른 이용·과금 방식을 구분해야 한다
- D. 항상 같은 금액이다

## 정답과 해설

1. **C** — 관련 없는 맥락이 섞이지 않도록 작업을 분리한다.

2. **B** — 확인 가능한 인수인계 자료를 전달하면 재시작이 쉬워진다.

3. **A** — 확인하지 않은 작업을 완료로 표시하면 다음 작업이 잘못된 전제를 갖는다.

4. **D** — 지원 모델은 계정·배포 환경·조직 설정 등에 따라 달라진다.

5. **C** — 자신이 사용하는 제품과 청구 방식을 확인해야 한다.

## 념글 박제

새 대화는 새 책상. 필요한 서류와 인수인계 메모는 챙겨 가자.
