# [강좌] C02. 파일 전달부터 결과 저장까지 — 첨부와 폴더 연결은 다름

> Claude Desktop 앱 전체 기준 · Windows 중심 · 공식 문서 확인: 2026-11-14
> 실습 화면: 일반 대화·업무 작업의 첨부/파일 결과, Code 경로는 비교 절
> 기존 원고에서 생략된 파일 전달·저장·검수 단계를 독립 실습으로 보강합니다.

> 먼저 읽을 강의: C01.

## 3줄요약

1. 파일 첨부는 전달한 파일, 폴더 연결은 허용한 로컬 범위를 다룬다.
2. 계정에 저장된 자료와 PC 파일의 위치를 구분한다.
3. 결과 카드가 생겨도 다운로드·저장·내용 확인을 끝내야 한다.

## 1. 폴더와 파일 이름 준비

탐색기에서 다음 구조를 만든다. 메일 주소나 실제 회사명 대신 연습 이름을 쓴다.

```text
Claude_연습/
  입력/
    01_지출샘플.md
  출력/
  검수/
```

목표 결과는 `출력/지출_확인_v1.md`, `출력/지출_확인_v2.md`, `검수/변경메모.md` 세 개다. [지출 샘플](실습자료/01_지출샘플.md)을 입력 폴더에 복사한다.

## 2. 첨부 방식으로 전달하기

1. 새 대화에서 파일 추가 버튼으로 샘플을 첨부한다.
2. 파일 카드의 이름이 맞는지 확인한다. 이름만 채팅에 쓴 것은 첨부가 아니다.
3. “첨부 자료의 파일명과 거래 수만 알려줘”라고 요청해 6건인지 확인한다.
4. 다음 결과를 만든다.

> 거래 수와 금액이 비어 있는 거래 ID를 지출_확인_v1.md로 만들어줘. 실제 파일 생성이 불가능하면 본문만 제공했다고 표시해줘.

5. 다운로드해 출력 폴더에 저장하고 연다.

## 3. 수정본과 결과물 관리

1. 같은 대화에서 “v1은 보존하고, 음수 금액의 거래 ID도 추가한 v2를 만들어줘”라고 요청한다.
2. v1에는 **6건·T004**, v2에는 여기에 **T005**가 추가됐는지 확인한다.
3. 두 파일을 열어 v1이 사라지지 않았는지 확인한다.
4. 변경메모에 어떤 입력을 사용했고 어떤 차이가 났는지 적는다.

같은 이름으로 다운로드하면 브라우저·앱이 번호를 붙이거나 덮어쓰기를 물을 수 있다. 파일명이 달라졌다면 실제 이름을 기록한다. 링크만 전달받았으면 만료·접근권한을 확인하고 필요한 파일을 본인 저장 공간에 보관한다.

## 4. 폴더 연결과 Code 경로 비교

로컬 파일 접근 기능이 제공되면 앱에서 연결할 폴더와 범위를 선택한다. 실제 연결된 폴더 이름을 확인하고, 그 폴더 밖이 언제나 차단됐다고 생각하지 않는다.

업무 프로젝트의 계정 파일은 PC의 같은 이름 폴더와 동일하지 않다. Code에서 Worktree를 켠 경우에는 원래 폴더가 아닌 별도 작업 복사본에 결과가 생길 수 있다. 원래 위치라고 추정하지 말고 실제 저장 경로를 확인한다.

## 5. 확인 방법과 막혔을 때

파일이 안 보이면 입력 첨부·계정 파일·다운로드 폴더·직접 저장 경로를 순서대로 구분한다. 모르는 다운로드 파일을 실행하지 않는다. 이 실습은 MD 자료의 내용 열람만으로 충분하다. 로컬 폴더 기능이 없다면 첨부와 다운로드만으로 세 결과를 완성할 수 있다.

## 화면 보며 따라 하기

**준비:** ZIP의 01_지출샘플.md와 빈 출력·검수 폴더를 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** 그림의 정제 CSV·검수 MD 카드는 실제 생성·다운로드 경로를 보여주는 별도 예시입니다. v1·v2 결과라고 오해하지 마세요.

1. 첨부 버튼에서 내 컴퓨터의 파일을 고릅니다. Claude의 통합 선택 창에서는 파일 업로드 또는 추가 → 컴퓨터에서 업로드를 한 번 더 누를 수 있습니다. ChatGPT에서는 현재 첨부 메뉴의 파일 업로드 경로를 따릅니다. 같은 이름의 클라우드 자료를 대신 고르지 않습니다.
2. v1에는 거래 수와 빈 금액 ID만 요청합니다. 결과 카드가 있으면 다운로드하고 지출_확인_v1.md로 저장합니다.
3. 같은 대화에서 v1을 유지하고 음수 거래도 추가한 v2를 요청합니다. 두 파일을 각각 열고 변경메모.md에 차이와 실제 경로를 씁니다.

**완료 확인**

- v1: 6건·T004 / v2: 여기에 T005 추가
- v1·v2·변경메모가 서로 다른 파일로 남음

**막혔을 때:** 다운로드는 보통 다운로드 폴더에 먼저 생깁니다. 거기서 출력 폴더로 복사해도 됩니다. 같은 이름 뒤에 (1)이 붙으면 실제 파일명을 기록하고, 링크만 받았다면 파일 저장 완료로 적지 않습니다.

**이번 검토에서 확인한 범위:** 클로드의 CSV·MD 두 파일 생성과 다운로드를 확인하고 CSV를 다시 읽었습니다. v1·v2 보존 실습과 ChatGPT 파일 첨부·자동 생성은 별도 확인이 필요합니다.

## 숙제

1. v1·v2·변경메모 세 파일을 만들고 실제 저장 위치를 기록한다.
2. v1이 보존됐는지 두 파일을 직접 열어 확인한다.
3. 파일명만 적기와 실제 첨부가 어떻게 다른지 설명한다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. 채팅에 파일명만 적으면 첨부된 것일까?

- A. 같은 이름이면 자동 전송된다
- B. 파일 내용이 자동으로 공개된다
- C. 실제 파일 카드나 접근 가능한 연결을 확인해야 한다
- D. 언제나 PC 전체에서 자동 검색된다

### Q2. v2에 새로 추가되는 검토 항목은?

- A. 거래 수를 30건으로 변경
- B. 음수 거래 T005
- C. 빈 금액 T004 삭제
- D. 모든 금액을 0으로 변경

### Q3. Code의 Worktree를 켜면 결과 위치는?

- A. 별도 작업 복사본일 수 있어 실제 경로를 확인한다
- B. 항상 원래 입력 폴더다
- C. 반드시 이메일 첨부가 된다
- D. 항상 계정 프로젝트로 자동 이동한다

### Q4. 다운로드 파일명에 번호가 붙었다면?

- A. 내용도 반드시 같으니 무시한다
- B. 원본을 먼저 지운다
- C. 앱을 재설치한다
- D. 실제 저장된 이름과 내용을 확인해 기록한다

### Q5. 로컬 폴더 연결이 지원되지 않으면?

- A. 파일을 읽었다고 가정한다
- B. 회사 공유 폴더를 전부 연결한다
- C. 첨부와 다운로드 경로로 실습한다
- D. 권한을 우회한다

## 정답과 해설

1. **C** — 이름 언급과 실제 자료 전달은 다르다.

2. **B** — v1의 6건·T004에 환불 거래 T005를 추가하는 실습이다.

3. **A** — 작업 환경에 따라 저장 위치가 달라질 수 있다.

4. **D** — 저장 과정의 이름 변경을 추적해야 파일을 혼동하지 않는다.

5. **C** — 동일한 학습 목표를 작은 파일 첨부로 달성할 수 있다.

## 념글 박제

파일명은 주소가 아니다. 전달했는지, 저장했는지, 열었는지 각각 확인.
