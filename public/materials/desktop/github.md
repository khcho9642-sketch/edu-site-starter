## 2. 원격 저장소 복제 후 넣을 가짜 파일

C15에서 만든 원격 저장소에는 README와 기존 커밋이 있다. C17에서 그 저장소를 복제한 뒤 아래 자료를 추가한다. 같은 이름의 로컬 폴더가 이미 있으면 내용과 Git 연결 상태부터 확인하고 덮어쓰지 않는다. 별개로 초기화한 로컬 기록을 원격에 강제 푸시하지 않는다.

```
my-gagyebu-practice/
├── README.md          ← 이 저장소가 뭔지 한 줄
├── 지출샘플.csv        ← 아래 내용 복사
├── 메모.md             ← 아무 메모
└── .gitignore         ← C17에서 만듦
```

`지출샘플.csv`: 기초·자료 작업 강의에서 쓰는 [지출 샘플](/desktop-materials/expenses)의 CSV 부분을 그대로 복사해 저장한다. 새 숫자를 만들지 않는다. 기준값은 C06과 같다: **6건, 확정 합계 28,000원, T004 금액 미확정, T005 환불 -2,000원**.

## 3. 일부러 만들어 둘 "올리면 안 되는 파일" (C16·C17 실습용)

| 파일 | 내용 | 왜 만드나 |
|---|---|---|
| `.env` | `FAKE_API_KEY=this-is-not-real-1234` | `.gitignore`가 막는지 확인 |

**진짜 키·진짜 카드내역을 넣지 마세요.** 위 내용은 모두 가짜입니다.
