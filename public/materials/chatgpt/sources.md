# 공식 참고와 원고 검토 기록

확인일: 2026-11-14. 화면과 계정별 제공 기능은 계속 달라질 수 있습니다.

## 반영 원칙
- ChatGPT 웹을 기준으로 대화와 자료 검수부터 시작. 터미널·API 키 설치 요구 없음.
- 기능이 없는 계정도 원문 붙이기·MD 저장·절차 첨부로 같은 판단을 연습.
- 프로젝트의 업로드 자료와 PC 폴더의 자동 접근을 혼동하지 않음.
- 웹 메모리와 로컬 도구 메모리의 제어를 혼동하지 않음.
- GPT 제작을 전 계정 공통 기능으로 단정하지 않음. Enterprise의 플러그인 전환 공식 안내를 반영.
- 설정 후보 작성·파일 생성·등록·설치·실제 발송을 서로 구분.
- 중복·빈칸·환불 데이터의 40,000원 확인 순액, 미확인 1건 검산.
- 가상 공지와 실제 검색을 분리. 게시일·적용일·확인일을 구분.
- 모든 강의에 정상 결과와 실패·미확인 상황, 숙제, 5문항과 해설 포함.
