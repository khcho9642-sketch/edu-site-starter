# ChatGPT 쉽게 배우기 — 과정 D 10강

ChatGPT 웹 중심입니다. 데스크톱은 같은 대화 실습을 하되 메뉴가 다를 수 있습니다. 터미널과 API 실습은 없습니다.

- D01. GPT 처음 써본 썰 — 브라우저에서 첫 대화를 하고 답을 직접 확인합니다.
- D02. 질문을 잘해야 답도 잘 나옴 — 목적·배경·조건·형식으로 모호한 요청을 고칩니다.
- D03. 한 번에 정답 찾지 마라 — 수정 대화에서도 원문 사실과 확정 조건을 지킵니다.
- D04. 내 자료 넣고 물어보기 — 첨부 자료를 읽은 범위와 근거를 확인합니다.
- D05. 엑셀·숫자 분석시키기 — 중복·누락·환불을 구분하고 40,000원을 대사합니다.
- D06. 자료 조사, 출처부터 확인 — 최신 정보는 직접 출처를 열어 주장과 연결합니다.
- D07. 메일·보고서 노가다 줄이기 — 회의의 결정·할 일·미정을 나누어 초안을 만듭니다.
- D08. 매번 같은 설명 안 하는 법 — 맞춤 지침·프로젝트·메모리를 용도별로 나눕니다.
- D09. 나만의 GPT·업무 도우미 만들기 — 반복 업무 지침과 자료를 묶고 세 가지 사례로 검증합니다.
- D10. GPT가 틀렸을 때 + 졸업 실습 — 원본부터 보고서까지 만들고 오류·누락을 검증합니다.

## 순서와 준비
D01~D03 대화 기초 → D04~D05 자료·숫자 → D06~D07 조사·문서 → D08~D09 반복 업무 → D10 검수·졸업.
각 강의는 원고, 복사 요청, 직접 실습, 기대 결과, 문제 해결, 숙제, 퀴즈 5개와 해설을 포함합니다.
각 강의 첫 단원에는 서로 다른 8컷 만화가 있습니다. 모든 인물·거래는 가짜입니다.
자료실에서 MD·CSV를 내려받습니다. 첨부가 없으면 원문을 복사합니다.
파일 생성이 없으면 표·MD·CSV 본문으로 저장합니다. 제작 메뉴가 없으면 절차 MD로 시험합니다.
계정·조직별 기능과 사용량은 다르며 이 강의를 위해 먼저 결제할 필요는 없습니다.

## 결과 보관
강의별 D01~D10 폴더를 만들고 입력·초안·최종본·검수 기록을 구분하세요.
실제 발송·공개 공유·비밀값 입력은 실습 범위에 없습니다.
퀴즈는 자가학습용이며 사이트에서 70점 이상 통과, 최고 점수는 해당 브라우저에 저장됩니다.
강의 완료는 세 단원 읽음으로 판단하며 로그인한 읽기 기록은 계정과 동기화됩니다.
