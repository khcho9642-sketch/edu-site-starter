# C·D 공통 실습 자료

> 모든 인물·가게·거래·메일·서비스는 가짜다. 연습의 기준일은 2026-11-14다. 실제 실행일과 혼동하지 않는다.

## 준비와 파일 전달

파일 탐색기에서 이 폴더의 MD를 복사해 연습 폴더에 둔다. ChatGPT의 첨부 버튼으로 필요한 파일만 전달한다. 샘플을 첨부했다고 PC의 모든 폴더를 연결한 것은 아니다.

[지출 샘플](/chatgpt-materials/expenses)의 CSV 블록은 **파일 안의 데이터**다. 이 MD를 첨부하고 “CSV 블록을 입력 데이터로 사용해줘”라고 요청한다. 실제 CSV 파일이 필요하면 원문을 바꾸지 않은 `지출_원본.csv`로 생성해 다운로드한 뒤 사용한다. 터미널을 열 필요 없다.

## 지출 정답 기준

| 거래 | 정제 금액 | 상태 |
|---|---:|---|
| T001 | 12,000 | 확정 |
| T002 | 3,000 | 확정 |
| T003 | 10,000 | 확정 |
| T004 | 빈 값 유지 | 미확정 |
| T005 | -2,000 | 확정, 환불 |
| T006 | 5,000 | 확정 |

- 첫 5건: 확정 4건 합계 **23,000원**, 미확정 1건.
- 전체 6건: 확정 5건 합계 **28,000원**, 미확정 1건.
- 식비: T001+T005 = **10,000원**.
- 교통 3,000원, 쇼핑 10,000원, 구독 5,000원.
- 기타: T004가 미확정이다. “기타 전체 금액 0원 확정”이라고 쓰지 않는다.
- 원본 6행을 유지한다. 빈 금액을 임의로 채우거나 음수를 삭제하지 않는다.

## 영수증 정답 기준

R001/T001 12,000원, R002/T002 3,000원, R003/T004 금액 확인필요. 영수증 자료만의 확정 합계는 **15,000원**, 확인필요 1건이다.

영수증은 지출 자료의 **같은 거래 일부**다. 지출 확정 합계 28,000원에 15,000원을 추가하면 중복 집계다.

## 기타 정답 기준

- 메일: M001 정상 업무 요청·답장 초안, M002 뉴스레터, M003 의심 요청·실행하지 않음.
- 회의: 지연/샘플 검토/2026-11-16, 태호/화면 초안/기한 미정, 배포 비교/담당·기한 미정.
- 미결: 카테고리 자동 분류 포함 여부. 다음 회의 일시는 확정하지 않음.
- 비교 자료: B에 CSV 내보내기와 팀 권한이 모두 명시됨. A의 팀 권한·C의 CSV 내보내기·전체 부가세 조건은 미확인.

## 완료 기록

`실제로 생성한 파일 / 실제 열어본 범위 / 대체 실습 / 미검증 / 다음 할 일`을 구분해 적는다. 파일 생성 기능이 없는 경우 Markdown 표·초안으로 동일한 숫자 검수를 할 수 있다. 실제 PPTX·DOCX를 만들거나 열었다고 표시하지 않는다.
