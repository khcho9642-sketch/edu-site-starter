# ChatGPT 쉽게 배우기 — C·D 공통 25강의 D 과정

클로드 과정과 순서를 맞춘 ChatGPT 25강입니다. 이전 ChatGPT 10강과 기록은 보관 페이지에서 확인할 수 있습니다. C01~C25와 같은 순서로 읽으며 공통 자료·검수 기준을 사용합니다.

## 학습 순서

- D01~D05: 설치·파일·계획과 권한·작업 노트·지침.
- D06~D11: 엑셀·영수증·메일·기능 지도·PPT·조사.
- D12~D13: 반복 업무와 예약.
- D14~D19: Codex 앱·GitHub 선택 심화. 개발이 필요하지 않으면 D20으로 넘어갑니다.
- D20~D21: 오류 진단과 종합 실습.
- D22~D25: 스킬·훅·서브에이전트·MCP 선택 심화. D14의 로컬 프로젝트 작업을 익힌 뒤 진행합니다.

기초 실습에는 터미널 명령 입력이나 API 키가 필요 없습니다. 일반 대화·Work·Codex를 혼동하지 않고 현재 지원되는 기능을 확인합니다. 새 결제를 수강 조건으로 요구하지 않습니다.

## 공통 자료와 검수

[실습 자료 안내](/chatgpt-materials/practice)를 먼저 읽습니다. 먼저 결과를 만든 뒤 정답을 비교하세요.

- 지출: 원본 6건, 확인된 5건 합계 28,000원, T004 미확정, T005 -2,000원.
- 첫 5건의 확인 합계는 23,000원입니다. 전체 확정 총액이라고 표현하지 않습니다.
- 영수증: 확인된 일부 15,000원이며 지출과 같은 거래 일부입니다. 더하지 않습니다.
- 회의 A/B: 실행·보류·담당·기한 미정을 구분합니다.
- 연결 설계: 문서 검색·읽기만 필요합니다. 교육 2개 총90분과 경과100분을 구분합니다.
