# [강좌] D12. 스킬·플러그인·연결 — 반복 업무를 저장하는 법

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D05 · D06.

## 3줄요약

1. 처음에는 화면에서 제공하는 스킬·플러그인을 찾아 작은 자료로 시험한다.
2. 내 절차를 스킬로 저장해도 결과의 정확성과 접근 권한은 따로 확인한다.
3. 훅의 차단 효과는 이벤트·구현·오류 처리에 달려 있다. 모든 위험을 막는 장치가 아니다.

## 1. 기능의 역할 구분

| 필요한 것 | 이번 ChatGPT·Codex 경로 |
|---|---|
| 공통 업무 기준 | ChatGPT 프로젝트 지침, Codex라면 AGENTS.md |
| 반복할 절차 | 스킬 또는 수동 첨부 절차 |
| 외부 자료·동작 | 제공되는 연결·MCP 도구 |
| 배포할 기능 묶음 | 플러그인 |
| 도구 이벤트 검사 | Codex 훅, 실제 호출 검증 필요 |
| 역할별 검토 | 지원되는 서브에이전트 또는 별도 대화 검토 |

제품별 설치 형식을 동일하다고 가정하지 않는다. 어떤 방식을 실제 수행했는지 결과 기록에 적는다.

## 2. 화면에서 찾아 시험하기

현재 앱에 **Skills** 또는 **Plugins**가 보이면 설명과 제공 범위를 확인한다. 독립 스킬과 플러그인으로 배포되는 스킬은 경로가 다를 수 있다. 웹에서 쓸 수 있는 기능과 Desktop only 표시도 구분한다.

내 계정·조직이 허용한 기능만 선택하고, 가짜 지출 샘플을 한 번 처리한다. 실제 사용한 도구·스킬 표시와 거래 수·합계를 별도로 확인한다. 메뉴가 없으면 절차 MD 첨부로 같은 검수를 진행한다.

## 3. 기존 지출 절차를 첨부하고 실제 등록은 구분하기

기존 [지출 정리 SKILL.md](/chatgpt-materials/expense-skill)는 제품 전용 명령이 없는 지시문이므로 그대로 쓴다.

1. 파일을 열어 name·description, 원본 보존·미확정·환불 규칙을 확인한다. 프로그램 설치 스크립트나 비밀값은 없다.
2. 현재 화면의 공식 스킬·플러그인 추가 방식이 제공되면 그 형식을 확인한다. Claude의 Upload a skill 메뉴나 ZIP 업로드 절차가 ChatGPT에 항상 있다고 가정하지 않는다.
3. 처음에는 이 SKILL.md와 지출 샘플을 대화에 첨부하고 “첨부 절차에 따라 첫 5건부터 처리”를 요청한다. 기록에는 **절차 파일 첨부**라고 쓴다.
4. 실제 등록을 연습하고 싶다면 D22의 Codex 프로젝트 경로를 사용한다. 등록한 위치·활성 상태·사용 흔적을 확인한 경우에만 스킬 호출로 기록한다.
5. 어떤 경로든 T004 미확정·T005 음수·확인된 합계 28,000원을 대조한다.

절차 첨부 결과가 좋아도 등록·설치 성공의 증거는 아니다. 필요 없는 플러그인이나 외부 계정을 추가하지 않는다.

## 4. 훅과 서브에이전트는 Codex 선택 심화

D22~D25는 Codex 선택 심화다. 훅은 실제 이벤트에 연결한 검사이며, 말로 주의하라고 하는 것과 다르다. 서브에이전트에게 검토 역할을 주는 것과 실제 권한을 좁히는 것도 다르다.

가짜 파일에서 실제 호출과 결과를 확인하고 지원되지 않는 기능은 미실행으로 남긴다. 기본 업무 활용만 필요하면 D20~D21까지 먼저 끝내도 된다. 이번 단계에서 제품 설정 파일을 연결하거나 실제 외부 계정에 로그인할 필요는 없다.

## 화면 보며 따라 하기

**준비:** expense-cleanup/SKILL.md와 지출 샘플을 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** 처음에는 절차 첨부로 연습하고 Codex 프로젝트 등록은 22강에서 다룹니다.

1. SKILL.md의 name·description과 미확정·환불·원본 보존 규칙을 읽습니다.
2. 먼저 절차 파일과 샘플을 함께 전달해 결과를 확인합니다. 실제 등록 UI가 있다면 등록 형식과 활성 상태를 따로 확인합니다.
3. 등록·활성·호출 표시와 28,000원 결과 검수를 각각 기록합니다. 파일을 첨부한 것만으로 설치 성공이라고 적지 않습니다.

**완료 확인**

- T004 미확정·T005 -2,000원·확정 합계 28,000원
- 실제 경로가 절차 첨부인지 스킬 등록인지 구분

**막혔을 때:** 스킬만 실행해서 원문을 못 찾으면 회의 A·B를 명시해 전달합니다. 항목ID와 근거ID도 대조하고 A01/B01처럼 새로 번호를 붙였으면 고칩니다. 스킬 파일 저장·발견·실제 사용·결과 검수는 각각 기록합니다.

### 실제 예약 실행에서 발견한 오류

원문의 `M01`을 결과의 항목ID에서 `A01`로, `N01`을 `B01`로 바꾸는 문제가 있었습니다. 근거ID가 맞아도 항목ID 변경을 놓치면 안 됩니다. 스킬에 **항목ID와 근거ID 모두 원문 ID를 그대로 유지**한다는 규칙을 추가했습니다.

원래 예약 출력과 수동 재검수 파일을 따로 보존했습니다. 예약이 실행됐다는 사실과 수정된 스킬의 재실행 검증은 구분합니다. 일반 ChatGPT의 절차 첨부와 이번 Codex 로컬 스킬 발견·읽기도 다른 경로입니다.

## ChatGPT 보충 · 나만의 업무 도우미

기존 GPT D09의 “정상 질문·자료 없는 질문·자료 속 지시” 세 시험을 이어 쓴다. 이번 자료에서는 합계 질문은 확인된 28,000원, T004 금액 질문은 미확정, 자료 속 외부 전송 지시는 실행하지 않는지가 기준이다.

나만의 GPT를 사용하던 계정은 현재 지원·전환 안내를 확인한다. GPT·플러그인·스킬의 등록 방식이 같다고 단정하지 않는다. 제작 메뉴가 없으면 지침과 참고자료를 묶어 수동 첨부한다. 이것은 설치 완료가 아니다.

## 숙제

1. 기존 SKILL.md에서 입력·절차·결과·금지·완료 기준을 찾는다.
2. 절차 첨부 또는 실제 등록 중 가능한 방식으로 샘플을 처리하고 수행 방식을 기록한다.
3. 절차 사용 표시와 28,000원 결과 검수를 따로 기록한다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. 스킬이 입력 규칙대로 작동했는지 확인하는 기준은?

- A. 미확정·환불·건수·합계를 원본과 대조한다
- B. 스킬 이름이 멋있는지 본다
- C. 완료라는 문구만 본다
- D. 자동 호출됐다고 항상 정확하다고 본다

### Q2. 사용자 지정 스킬의 제공 파일명은?

- A. 아무 폴더의 설명.txt
- B. 계정 비밀번호.txt
- C. 프로젝트 전체 압축만 가능
- D. expense-cleanup 폴더 안의 SKILL.md

### Q3. 업로드 기능이 없을 때의 대체 실습은?

- A. 업로드했다고 말한다
- B. 관계없는 모든 플러그인을 설치한다
- C. 절차 MD를 첨부해 실행하고 설치와 구분해 기록한다
- D. 정책을 우회한다

### Q4. 훅에 대한 올바른 설명은?

- A. 실행 후 훅은 과거 동작을 언제나 취소한다
- B. 이벤트·설정·오류 처리에 따라 차단 여부를 검증해야 한다
- C. 항상 모든 위험을 막는다
- D. 말로 요청하면 설정 검증이 필요 없다

### Q5. 읽기 전용 검토자를 만들었다고 판정하려면?

- A. 실제 사용 도구와 권한 제한도 확인한다
- B. 이름에 리뷰어를 넣으면 끝이다
- C. 읽기만 하라고 한 문장만 있으면 된다
- D. 수정 도구를 전부 자동 허용한다

## 정답과 해설

1. **A** — 절차 재사용과 결과 검증은 별개다.

2. **D** — 제공한 실습용 구조를 그대로 확인하고 확장자도 점검한다.

3. **C** — 학습 목표는 절차 재사용이며 실제 등록 여부는 정확히 보고해야 한다.

4. **B** — 관찰·차단·오류 시 동작을 구분해야 한다.

5. **A** — 역할 지시와 기술적 권한 제한은 다르다.
