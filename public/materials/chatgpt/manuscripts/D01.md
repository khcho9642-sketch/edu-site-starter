# [강좌] D01. 앱 설치와 첫 대화 — ChatGPT에서 시작하기

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: 선행 강의 없음.

## 3줄요약

1. ChatGPT는 앱 또는 웹에서 시작하고, 파일 작업은 지원되는 Chat/Work에서 한다.
2. 설치·이용 자격·자료 접근을 따로 확인한다. Codex는 개발 선택 심화다.
3. 첫 성공은 샘플의 6건·T004·T005 확인과 실제 결과 저장·열람이다.

## 1. 오늘의 결과와 준비물

목표는 가짜 지출 자료를 읽고 `첫_결과.md` 한 개를 저장하는 것. 실제 회사 파일은 쓰지 않는다. [지출 샘플](/chatgpt-materials/expenses)을 준비하고, 탐색기에서 `Documents/AI_연습/입력`과 `출력` 폴더를 만든다.

## 2. 설치하고 내 화면 확인하기

1. [공식 시작 안내](https://learn.chatgpt.com/docs/quickstart)의 Desktop 경로에서 현재 Windows용 공식 설치 링크를 연다. 이미 앱이 있으면 업데이트와 로그인 계정·작업 공간을 확인한다. 웹은 https://chatgpt.com 에서 시작한다.
2. **Chat**은 질문·수정 대화, **Work**는 여러 단계의 자료 작업과 검토할 결과물에 사용한다. 현재 계정에 Work가 없으면 일반 대화에서 같은 샘플을 다룬다.
3. **Codex**는 개발 화면과 변경 내역을 보며 작업할 때 선택한다. D14 이전의 기본 파일 실습에 Codex나 터미널이 필수는 아니다.
4. 파일 첨부·생성 기능이 제공되는지 작은 샘플로 확인한다. 플랜 이름만으로 이용 가능을 단정하거나 바로 결제하지 않는다.
5. 결과 파일을 생성할 수 없으면 본문을 메모장에 복사해 MD로 저장한다. 직접 저장한 대체 결과를 자동 파일 생성 성공으로 표시하지 않는다.

## 3. 첫 대화와 첫 파일

1. 새 대화 또는 새 작업을 연다.
2. 입력창의 파일 추가 버튼을 눌러 샘플 MD를 첨부한다. 파일을 끌어다 놓아도 된다. `@` 입력은 필수가 아니다.
3. 다음 문장을 붙여넣는다.

> 첨부 자료는 가짜 지출 6건이다. 원문 표에서 거래 수, 금액이 빈 거래 ID, 음수 금액이 있는 거래 ID만 찾아줘. 아직 정리하거나 값을 추정하지 마.

4. 답이 **6건 / T004 / T005**인지 직접 대조한다.
5. 이어서 요청한다.

> 방금 확인한 내용과 다음에 확인할 항목을 첫_결과.md로 만들어줘. 만들 수 없다면 저장했다고 말하지 말고 본문을 보여줘.

6. 결과 카드의 다운로드·저장 메뉴로 `AI_연습/출력`에 저장하고 탐색기에서 연다. 로컬 폴더에 직접 저장한 작업이라면 AI가 알려준 **실제 저장 경로**를 확인한다.

## 4. 확인 방법과 막혔을 때

- 파일을 첨부한 것과 PC 폴더 전체를 연결한 것은 다르다. 첨부하지 않은 자료를 읽었다고 가정하지 않는다.
- 선택한 작업 폴더는 기본 위치다. 폴더 선택만으로 바깥 접근이 완전히 막히는 것은 아니다. 도구 권한·연결 계정·앱 접근을 함께 확인한다.
- 메뉴를 못 찾으면 앱 버전과 보이는 메뉴명을 적고, 개인정보를 가린 화면 캡처를 첨부한다. AI가 현재 화면을 자동으로 보고 있다고 가정하지 않는다.
- 파일 카드가 없고 글만 있으면 아직 다운로드 파일이 만들어진 게 아니다. 기능이 없으면 메모장 저장으로 대체했다고 기록한다.

## 화면 보며 따라 하기

**준비:** 공통 실습 ZIP을 모두 풀고 입력 파일 01_지출샘플.md를 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** 기본 대화는 Chat에서 시작합니다. 이 캡처는 비로그인 웹의 텍스트 대체 실습입니다. 앱·로그인·첨부 성공을 보여주는 그림은 아닙니다.

1. 설치가 처음이면 별도 설치 안내를 먼저 마칩니다. 강의 화면의 자료 링크는 설명 페이지일 수 있으니 그 페이지의 MD 다운로드를 눌러 실제 파일을 받습니다.
2. 새 대화에서 첨부 버튼으로 파일을 고릅니다. 파일 카드에 이름이 나타난 뒤 요청문을 보냅니다. 파일을 붙이지 못하면 MD의 CSV 블록만 복사해 붙이고 텍스트 전달로 실습했다고 적습니다.
3. 거래 수·빈 금액·음수 거래를 먼저 물어봅니다. 답을 확인한 다음 첫_결과.md를 요청하고 내려받아 출력 폴더에서 엽니다.

**완료 확인**

- 6건 / 금액 미확정 T004 / 환불 T005
- 저장한 파일을 직접 열고 세 값이 있는지 확인

**막혔을 때:** 메모장으로 저장한다면 파일 형식은 모든 파일, 파일명은 첫_결과.md, 인코딩은 UTF-8을 선택합니다. 탐색기의 파일 확장명을 켜서 첫_결과.md.txt가 아닌지 확인합니다.

![따라 하기 화면](/materials/walkthrough/screens/chatgpt-first-result.png)

**이번 검토에서 확인한 범위:** 두 제품에서 가짜 CSV 텍스트를 보내 6건·T004·T005 답변을 직접 확인했습니다. 자동 첨부 경로는 검증하지 못했습니다.

## ChatGPT 보충 · 첫 요청을 짧게 시작하기

처음에는 “첨부 샘플의 거래 수와 금액이 빈 거래 ID만 알려줘”처럼 결과를 좁힌다. 답을 받은 뒤 원문에서 6건·T004를 직접 찾는다. 자연스러운 문장도 검수 대상이다. 저장할 때 입력·초안·검수된 최종본을 구분한다.

기존 GPT D01의 첫 대화·직접 확인 원칙을 같은 지출 샘플에 적용했다. 기존 교육 안내문의 날짜·정원은 이 실습에 섞지 않는다.

## 숙제

1. 현재 화면이 ChatGPT의 Chat·Work·Codex 중 무엇인지, 앱·웹 중 어디인지 적는다.
2. 샘플을 첨부하고 6건·T004·T005를 확인한다.
3. 첫_결과.md를 저장한 뒤 실제로 열고 저장 위치를 메모한다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. ChatGPT 파일 작업을 시작할 때 적절한 방법은?

- A. 현재 계정의 Chat/Work 지원을 확인하고 샘플을 첨부한다
- B. 무조건 Codex부터 선택한다
- C. 회사 전체 폴더를 연결한다
- D. 파일명을 쓰면 PC 전체가 자동 검색된다

### Q2. 작업 폴더를 고르면 무엇이 정해질까?

- A. 그 폴더 밖 접근이 무조건 불가능해진다
- B. 모든 메일 발송 권한이 생긴다
- C. 실제 회사 자료가 자동으로 익명화된다
- D. 기본 작업 위치이며 접근 범위는 권한도 확인해야 한다

### Q3. 샘플에서 금액이 빈 거래는?

- A. T003
- B. T006
- C. T004
- D. T001

### Q4. 첫 파일 생성 실습의 완료 증거는?

- A. 앱을 닫은 것
- B. 저장한 파일을 직접 열어 내용을 확인한 것
- C. AI가 완료라고 답한 것
- D. 입력창에 파일명을 적은 것

### Q5. 내 화면에 없는 메뉴를 물어볼 때 적절한 방법은?

- A. 버전과 가린 화면 캡처를 함께 제공한다
- B. AI가 이미 화면을 본다고 생각한다
- C. 실제 비밀번호가 보이는 화면을 보낸다
- D. 아무 플러그인이나 설치한다

## 정답과 해설

1. **A** — 자료 접근과 제공 기능을 확인하고 작은 입력으로 시작한다.

2. **D** — 폴더 선택은 모든 도구를 격리하는 보안 보장이 아니다.

3. **C** — T004의 금액은 빈 값이다. 0원으로 임의 변경하지 않는다.

4. **B** — 답변 문구와 실제 생성·저장·열람은 구분해야 한다.

5. **A** — 확인 가능한 화면 정보를 제공하되 비밀값은 가린다.
