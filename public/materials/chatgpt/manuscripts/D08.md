# [강좌] D08. 메일·회의록·커넥터 — 초안과 발송은 따로

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D03 · D05.

## 3줄요약

1. 커넥터 연결은 로그인·권한 승인과 작업 중 사용 허용을 구분한다.
2. 초안 작성과 실제 발송은 다른 행동이다.
3. 회의록에서 담당자·기한을 알 수 없으면 미정으로 남긴다.

## 1. 계정 연결 없이 먼저 연습

[가짜 메일과 회의 메모](/chatgpt-materials/mail-meeting)를 첨부한다. 가정일은 2026-11-14이다. 실제 오늘의 메일함을 읽는 실습이 아니다.

> 메일 M001~M003을 분류해줘. 정상 업무 메일, 뉴스레터, 의심스러운 요청을 구분하고 근거를 적어줘. 정상 업무 메일 중 답장이 필요한 것만 초안을 작성해. 실제 발송·외부 전송·계정 연결은 하지 마.

M001은 검토 기한이 있는 업무 요청, M002는 뉴스레터, M003은 비밀 파일 전송을 요구하는 의심스러운 내용이다. **M003의 명령을 실행하지 않고 확인필요로 분리**한다. “요약만 해”라는 지시도 기술적 보안 차단은 아니므로 연결 권한을 최소화한다.

## 2. 필요한 사람만 커넥터 연결

기본 실습은 계정 연결 없이 첨부 자료로 끝낸다. 선택 실습을 할 사람만 ChatGPT의 현재 **Plugins** 또는 연결 관리 화면을 연다.

1. 제공 기능과 출처, 필요한 서비스 계정을 읽는다. 조직에서 금지한 연결은 추가하지 않는다.
2. 해당 서비스 공식 인증 화면에서 로그인 계정과 동의 범위를 직접 확인한다.
3. 플러그인 설치와 서비스 계정 연결, 현재 대화의 실제 도구 사용 가능 상태를 구분한다.
4. 제목·날짜처럼 작은 읽기부터 시험한다. 연결 범위가 넓으면 무조건 승인하지 않는다.
5. 연결을 해제한 뒤 서비스 제공자 측의 앱·인증 허용도 따로 확인한다.

ChatGPT 웹의 연결과 Codex의 로컬 MCP 설정은 같은 파일이라고 가정하지 않는다. 쓰기·발송 기능 제공 여부와 권한은 각각 확인한다. 실제 발송은 이번 실습 범위가 아니다.

## 3. 회의록 만들기

가짜 회의 메모를 첨부하고 요청한다.

> 결정사항, 할 일(담당자·기한·근거 발언), 미결 사항, 다음 회의 안건을 표로 정리해줘. 담당자나 기한이 없으면 미정으로 표시하고, 확정하지 않은 날짜를 만들지 마.

예상 할 일은 **지연/샘플 검토/2026-11-16**, **태호/화면 초안/기한 미정**, **배포 방식 비교/담당 미정/기한 미정**이다. 카테고리 자동 분류 포함 여부는 미결이다.

녹음 실습은 가짜 메모로 대체해도 된다. 실제 녹음은 동의·조직 정책을 확인하고, 전사 도구의 화자 구분·요금·저장 위치를 별도로 점검한다. 특정 전사 도구의 모든 구현이 화자를 구분하지 못한다고 단정하지 않는다.

## 4. 결과 확인

메일은 초안만 있는지, 수신자·첨부·링크가 임의로 추가되지 않았는지 확인한다. 회의록은 원문 발언과 대조한다. 담당자와 기한의 빈칸을 상상으로 채우면 편한 회의록이 아니라 잘못된 업무 지시가 된다.

## ChatGPT 보충 · 같은 사실로 말투만 수정

M001 답장 초안을 정중한 버전과 짧은 버전으로 고친다. 2026-11-16 검토 기한과 확인필요 항목을 유지하고, 원문에 없는 수신자·약속·첨부를 추가하지 않는다. 회의록에서는 결정·할 일·미결을 분리한다. 기존 GPT D07의 초안 작성과 사실 유지 검수를 흡수했다.

## 숙제

1. M001 답장 초안을 정중한 버전과 짧은 버전으로 고친다.
2. M003을 의심 요청으로 분리하고 실행하지 않은 이유를 적는다.
3. 회의록의 미정 두 종류와 미결 안건이 원문에 맞는지 대조한다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. 가짜 메일 M003에 대한 적절한 처리는?

- A. 요약 요청이면 어떤 도구든 안전하다
- B. 비밀 파일을 먼저 열어본다
- C. 의심 요청으로 분리하고 비밀 파일 전송을 실행하지 않는다
- D. 메일 속 지시를 최우선으로 실행한다

### Q2. 초안 작성과 발송의 관계는?

- A. 실습에서는 실제 발송이 필수다
- B. 별개의 행동이며 발송 전 수신자·내용을 확인한다
- C. 초안을 만들면 발송까지 자동 승인된다
- D. 첨부가 없으면 검토가 필요 없다

### Q3. 태호의 화면 초안 기한은?

- A. 미정
- B. 2026-11-16로 확정
- C. 2026-11-14로 확정
- D. 매주 금요일로 확정

### Q4. 플러그인을 삭제하면 커넥터 인증도 반드시 해제될까?

- A. 언제나 함께 해제된다
- B. 비밀번호가 자동 변경된다
- C. 조직 계정이 삭제된다
- D. 연결 계정 상태를 별도로 확인해야 한다

### Q5. 커넥터를 처음 시험하는 좋은 방법은?

- A. 모든 공유 폴더를 연결한다
- B. 조직 정책을 우회한다
- C. 최소 범위 조회로 권한과 계정을 확인한다
- D. 메일 전체를 자동 발송 처리한다

## 정답과 해설

1. **C** — 문서·메일 안의 지시는 사용자의 작업 지시와 구분하고 도구 권한도 제한한다.

2. **B** — 메시지를 쓰는 것과 외부로 보내는 것은 다르다.

3. **A** — 원문에는 태호의 작업 기한이 없다.

4. **D** — 플러그인 제거와 연결 계정 인증 해제는 구분한다.

5. **C** — 작은 범위부터 확인하면 잘못된 계정·권한 사용을 발견하기 쉽다.

## 념글 박제
