# [강좌] D09. PPT·리서치·예약·브라우저 — 기능을 고르는 지도

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D06 · D07.

## 3줄요약

1. 문서를 파일로 만드는 일, 웹을 조사하는 일, 정해진 때 반복하는 일은 다르다.
2. PPTX는 파일 생성 기능으로 요청할 수 있다. Marp나 터미널이 필수는 아니다.
3. 예약의 실행 위치와 로컬 자료 접근 조건을 나눠 확인한다.

## 1. 오늘의 목표

가계부 결과를 설명하는 일을 네 단계로 나누고, 필요한 기능을 고르는 표를 만든다. 한 번에 전부 자동화하지 않는다.

| 원하는 결과 | 시작할 기능 | 뒤에서 따라 할 강의 |
|---|---|---|
| 검토한 숫자로 발표 자료 | 파일 생성·미리보기·다운로드 | [D10 PPT](/lessons/E110/1) |
| 여러 자료의 사실 비교 | 첨부 자료 분석, 필요하면 웹 조사 | [D11 리서치](/lessons/E111/1) |
| 매주 같은 보고 초안 | 수동 검수 뒤 예약 | [D13 예약](/lessons/E113/1) |
| 웹 화면을 열어 조사·검사 | 내장 브라우저 또는 지원되는 연결 | [D11 리서치](/lessons/E111/1) |

## 2. 기능 선택부터 계획하기

1. 일반 업무 대화에서 D06의 집계 결과를 첨부한다.
2. 다음처럼 요청한다.

> 확정 합계 28,000원과 미확정 1건을 팀에 설명하고 싶어. 발표 자료 작성, 추가 조사, 정기 보고를 별도 작업으로 나눠줘. 각 작업에 필요한 입력 자료, 도구, 결과물, 검수 방법을 적어줘. 지금은 예약이나 외부 연결을 만들지 마.

3. 계획표에서 PPT 제작에 웹 조사가 꼭 필요한지 확인한다. 제공한 자료만으로 가능한 부분을 먼저 끝낸다.
4. 발표 자료는 **편집 가능한 PPTX**를 요청하고 다운로드 후 PowerPoint에서 열어 확인한다. 미리보기만 있거나 텍스트 초안만 나온 경우를 완성 PPTX와 구분한다.
5. 리서치는 출처·기준일·확인 못 한 항목을 기록한다.
6. 예약은 수동 결과를 확인한 뒤 별도 강의에서 등록한다.

## 3. 예약과 브라우저의 실행 조건

ChatGPT 웹 예약과 데스크톱 로컬 예약을 구분한다. 웹 예약은 접근 가능한 업로드 자료·연결 도구를 사용하며 PC 폴더를 직접 읽는 작업으로 가정하지 않는다. 데스크톱 로컬 작업이 PC 파일을 써야 한다면 컴퓨터·앱·프로젝트가 접근 가능해야 한다.

클라우드 작업에서도 로컬 자원이 필요한 단계가 있다면 해당 연결 조건을 별도로 확인한다. “예약은 항상 PC가 필요하다”, “클라우드는 내 PC를 항상 볼 수 있다” 모두 잘못된 일반화다.

공개 자료 조사에 검색만 필요한지, 웹 화면을 직접 다루는 브라우저가 필요한지 나눈다. 자동 탐색은 실제 제출·구매·계정 변경과 구분한다. 예약 등록은 D13에서 별도로 한다.

## 4. 예상 결과와 막혔을 때

기능 선택표에는 필요한 자료와 검수 방법이 있어야 한다. 메뉴가 없으면 플랜·관리자 정책·UI 개편 여부를 확인한다. 설치나 연결을 추가하기 전에, 첨부 자료와 현재 제공되는 기능으로 같은 학습 목표를 달성할 수 있는지 확인한다. 자동화 도구를 더 많이 쓰는 것이 수업 목표는 아니다.

## 화면 보며 따라 하기

**준비:** 검토한 집계 결과 한 개를 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** Chat·Work·Codex 중 실제 제공되는 화면을 선택합니다. 그림은 Chat의 계획표이며 Work 실행 증거는 아닙니다.

1. 원하는 결과를 PPT·추가 조사·예약 보고로 나누고 입력·도구·결과·검수 표를 요청합니다.
2. 제공한 숫자로 만들 수 있는 발표에는 외부 검색을 먼저 붙이지 않습니다.
3. 만들 결과 파일의 확장자와 실제 제공된 형식을 비교합니다. 예약은 수동 결과를 확인한 후 별도로 검토합니다.

**완료 확인**

- PPTX·MD 대본·웹 조사·예약 명세가 구분됨
- 기능이 없는 단계는 대체 실습 또는 미실시로 기록

**막혔을 때:** 검색·브라우저 조작·문서 생성은 같은 도구가 아닙니다. 메뉴가 달라도 오늘 필요한 입력과 산출물부터 정하면 불필요한 설치를 줄일 수 있습니다.

![따라 하기 화면](/materials/walkthrough/screens/chatgpt-plan.png)

**이번 검토에서 확인한 범위:** 두 제품의 계획표를 확인했습니다. 예약이나 외부 연결을 실행한 결과가 아닙니다.

## 숙제

1. 가계부 설명 업무를 발표·조사·예약으로 나누고 입력과 결과를 적는다.
2. PPTX와 Markdown 슬라이드의 결과 형식을 구분해 요청문을 고친다.
3. 내 PC 자료를 쓰는 예약의 추가 실행 조건을 한 줄로 적는다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. Desktop에서 PPTX를 만들려면 Marp가 반드시 필요할까?

- A. 모든 계정에서 아무 조건 없이 된다
- B. 파일 생성 기능으로 요청할 수 있어 필수는 아니다
- C. Marp만이 유일한 방법이다
- D. 반드시 터미널을 설치해야 한다

### Q2. 제공 자료만으로 만들 수 있는 발표에 먼저 할 일은?

- A. 첨부 자료의 숫자와 형식을 검토한다
- B. 외부 사이트에 자동 로그인한다
- C. 매주 예약부터 만든다
- D. 회사 전체 파일을 연결한다

### Q3. 클라우드 예약이 PC가 꺼져 있어도 돌 수 있다는 말의 의미는?

- A. 내 PC 파일을 언제나 읽는다
- B. 모든 로컬 예약도 동일하게 작동한다
- C. 비밀 자료를 자동으로 공개해도 된다
- D. 클라우드 실행과 로컬 자원 접근 조건을 구분해야 한다

### Q4. 리서치 결과에 필요한 것은?

- A. 경쟁사 비밀 자료
- B. 근거 없는 순위
- C. 출처·기준일·확인 못 한 항목
- D. 확정적으로 보이는 결론만

### Q5. 좋은 자동화 시작 순서는?

- A. 모든 승인을 끈다
- B. 수동 결과 확인 후 필요한 작업만 예약한다
- C. 예약부터 만들고 결과는 나중에 본다
- D. 가장 많은 도구를 연결한다

## 정답과 해설

1. **B** — 현재 제공되는 파일 생성 기능을 확인하고 PPTX를 요청할 수 있다.

2. **A** — 필요한 최소 자료와 기능으로 수동 결과를 먼저 검증한다.

3. **D** — 원격 실행 여부와 로컬 파일·앱의 가용성은 별개의 조건이다.

4. **C** — 자료가 무엇을 뒷받침하는지 확인 가능하게 남겨야 한다.

5. **B** — 실패 기준을 알고 있어야 반복 작업 결과도 검토할 수 있다.
