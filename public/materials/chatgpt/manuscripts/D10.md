# [강좌] D10. PPT 5장 만들기 — 원본 숫자부터 슬라이드 검수까지

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D07 · D09.

## 3줄요약

1. PPT를 만들기 전에 이야기와 숫자를 확정한다.
2. PPTX 파일 생성, 미리보기, 다운로드, 실제 열람을 구분한다.
3. 편집 가능한 요소와 이미지로 굳은 요소를 직접 확인한다.

## 1. 준비와 오늘의 결과

D06 집계표와 D07의 검토한 보고서를 첨부한다. 아직 없다면 [보고서 견본](/chatgpt-materials/report)과 샘플의 검증 기준을 사용한다. 산출물은 `지출보고_5장.pptx`, 또는 파일 기능이 없는 경우 `지출보고_대본.md`다.

## 2. 먼저 5장 구성만 받기

> 첨부한 가짜 지출 자료로 5장 발표 구성을 제안해줘. 1장 목적, 2장 데이터 품질, 3장 카테고리별 확정 집계, 4장 확인필요 T004, 5장 다음 조치. 확정 5건 합계 28,000원과 미확정 1건을 구분하고, 없는 전월 비교나 외부 통계는 넣지 마. 아직 파일은 만들지 마.

구성에서 **전체 6건·확정 5건·미확정 1건**이 일치하는지 확인한다. 표와 차트는 원본 수치를 과장하지 않아야 한다.

## 3. 파일 생성과 수정

1. 구성이 맞으면 “이 구성으로 편집 가능한 PPTX를 만들어줘. 각 장은 제목·핵심 메시지·짧은 근거를 넣고 발표자 노트도 작성해줘”라고 요청한다.
2. 글씨가 작거나 표가 잘리면 **제출본 5장은 유지**하고 내용량·표 배치를 조절한다. 세부 설명은 발표자 노트로 옮긴다. 디자인 수정 중에도 숫자와 단위를 보존하도록 요청한다.
3. 회사 템플릿은 외부 제공이 허용된 견본만 첨부한다. 먼저 1~2장 적용 결과를 보고 전체에 적용한다.
4. 결과 카드에서 PPTX를 다운로드한다. 텍스트 대본이나 이미지 묶음만 있으면 편집 가능한 PPTX를 만들었다고 판정하지 않는다.

## 4. 예상 결과와 검수표

| 항목 | 확인 |
|---|---|
| 장 수 | 정확히 5장 |
| 수치 | 6건 / 확정 5건 / 미확정 1건 / 28,000원 |
| 식비 | 환불 포함 10,000원 |
| 미확정 | T004가 0원 확정으로 표현되지 않음 |
| 편집 | 제목과 표의 실제 편집 가능 여부 확인 |
| 화면 | 글자 겹침·잘림·범례·단위 확인 |
| 발표자 노트 | 요청한 노트가 실제 포함됐는지 확인 |

PowerPoint에서 직접 열었다면 그 결과를 기록한다. 프로그램이 없어 앱 미리보기만 봤다면 **실제 PowerPoint 열람 미검증**이라고 남긴다. 파일 기능이 없으면 대본 5장과 표를 Markdown으로 작성하는 대체 실습으로 진행한다.

## 5. 막혔을 때

PPTX 다운로드가 없으면 생성 도구의 사용 가능 여부를 확인한다. 단순히 확장자만 pptx로 바꾸지 않는다. 글자·표가 이미지로 들어갔으면 어떤 요소가 편집 가능한지 확인하고 필요한 부분의 재생성을 요청한다. 내용이 많으면 글씨를 무작정 줄이기보다 다섯 장 안에서 내용을 재배치하거나 본문을 줄이고 세부 설명은 노트로 옮긴다. 이번 제출본의 완료 기준은 끝까지 5장이다.

## 화면 보며 따라 하기

**준비:** 보고서 견본과 검토한 28,000원 집계를 준비합니다.

[공통 실습 파일 ZIP 받기](/materials/walkthrough/cd-practice-starter.zip) · ZIP을 모두 푼 뒤 00_먼저읽기.md부터 확인합니다.

**내 화면에서:** Work가 제공되면 같은 검토 구성을 사용합니다. 일반 Chat에서 파일이 안 나오면 대본으로 대체합니다.

1. 목적 → 데이터 품질 → 분류별 집계 → T004 → 다음 조치 순서로 5장 구성만 먼저 받습니다.
2. 6건·확정 5건·미확정 1건·28,000원과 식비 10,000원을 확인한 뒤 편집 가능한 PPTX를 요청합니다.
3. 파일이 없으면 대본 5장을 MD로 저장합니다. PPTX가 있으면 실제 슬라이드 수와 노트·표 편집·잘림을 따로 확인합니다.

**완료 확인**

- 표지 포함 총 5장
- 표·슬라이드의 숫자와 미확정 표시가 보고서와 같음

**막혔을 때:** 대본에 .pptx 확장자를 붙여도 PowerPoint 파일이 되지 않습니다. 글씨가 작으면 5장 안에서 본문을 줄이고 노트로 옮기도록 요청합니다.

![따라 하기 화면](/materials/walkthrough/screens/slides-outline.png)

**이번 검토에서 확인한 범위:** 5장 구성과 수치 기준을 대조했습니다. 그림은 MD 대본 검수 예시이며 PPTX 생성·PowerPoint 편집 검증을 뜻하지 않습니다.

## ChatGPT에서 파일 만들기

Work가 제공되면 검토한 5장 구성을 주고 PPTX를 요청한다. 일반 대화에서도 현재 지원되는 파일 기능을 확인할 수 있지만 모든 계정에 생성을 보장하지 않는다. 생성 파일을 열 수 없으면 “파일 열람 미검증”, 대본만 만들었으면 “MD 대본”으로 기록한다. PPTX로 확장자만 바꾸는 것은 대체 실습이 아니다.

## 숙제

1. 5장 구성과 수치를 먼저 검수한 뒤 파일을 만든다.
2. 다운로드 파일 또는 대체 대본의 형식을 정확히 기록한다.
3. 숫자·미확정 표시·실제 편집 여부·잘림을 확인한다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. PPTX 생성 전에 먼저 확정할 것은?

- A. 예약 실행 시간
- B. 구성과 근거 수치
- C. 표지 색상만
- D. 최고 모델의 이름

### Q2. 이번 발표의 장 수는?

- A. 5장
- B. 3장
- C. 10장
- D. 제한 없음

### Q3. 편집 가능한 PPTX인지 확인하려면?

- A. 파일명 끝만 확인한다
- B. 표지 이미지가 예쁘면 된다
- C. 완료 문구만 읽는다
- D. 실제 파일에서 텍스트와 표의 편집 여부를 본다

### Q4. 이번 자료에서 식비 확정 합계는?

- A. 14,000원
- B. 28,000원
- C. 10,000원
- D. 12,000원

### Q5. 미리보기만 확인했을 때 정확한 보고는?

- A. 검토 기록을 지운다
- B. 실제 PowerPoint 열람은 미검증이라고 적는다
- C. PowerPoint 검증 완료라고 적는다
- D. 파일을 만들지 않았다고 무조건 적는다

## 정답과 해설

1. **B** — 이야기와 숫자가 정해져야 수정 과정에서 내용이 흔들리지 않는다.

2. **A** — 이번 실습의 완료 기준은 정해진 다섯 장이다.

3. **D** — PPTX 안에 이미지로 굳은 요소가 있을 수 있다.

4. **C** — 식비 12,000원에서 환불 2,000원을 차감한 값이다.

5. **B** — 미리보기와 실제 편집 프로그램에서의 열람은 구분한다.
