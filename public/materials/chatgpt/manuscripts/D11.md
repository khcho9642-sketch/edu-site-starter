# [강좌] D11. 리서치와 브라우저 — 출처 없는 빈칸은 채우지 말자

> ChatGPT 일반 업무 · 앱/웹 · Windows 중심 · 공식 확인: 2026-11-14
> 먼저 읽을 강의: D03 · D09.

## 3줄요약

1. 비교 기준과 출처를 먼저 정한다.
2. 자료에 없는 기능·가격 조건은 미확인으로 남긴다.
3. 브라우저 연결은 현재 로그인과 접근 권한을 확인한 뒤 필요한 공개 페이지에만 쓴다.

## 1. 준비와 오프라인 비교

[가상 서비스 비교 자료](/chatgpt-materials/research)를 첨부한다. A·B·C는 실제 제품이 아니다. 결과는 `서비스_비교표.md`와 `추가확인목록.md`다.

> 첨부한 가상 자료만 사용해 A·B·C를 비교해줘. 가격, 프로젝트 수, CSV 내보내기, 팀 권한, 부가세 조건을 각각 적고 모든 행에 출처 ID를 붙여줘. 없는 정보는 미확인으로 남겨. 실제 서비스 추천이나 결제는 하지 마.

자료에 따르면 A의 팀 권한, C의 CSV 내보내기, 세 서비스의 부가세 조건은 확인이 필요하다. 빈칸을 “지원 안 함”이나 “세금 포함”으로 바꾸지 않는다.

## 2. 판단 기준과 예상 결과

목표가 **CSV 내보내기와 팀 권한을 모두 확인할 수 있는 서비스 찾기**라면 B는 두 조건이 자료에 명시돼 있다. A·C는 필요한 정보가 부족하다. 이것은 제공된 가상 자료 범위의 판단이며 실제 제품의 우열이 아니다.

비교표는 사실과 해석을 나눈다. “가장 좋다” 대신 “필수 조건 두 가지가 자료에 명시됨”이라고 쓴다. 가격 비교에는 통화·기간·세금 조건·확인일을 함께 적고 불명확한 조건은 따로 남긴다.

## 3. 공개 웹 페이지로 확장하기

이 절은 웹 검색이나 브라우저 접근이 제공될 때 선택한다.

1. 질문의 범위와 확인일을 정한다. 이번 과제는 “공식 시작 안내가 연결하는 이용 환경과 자료 접근 차이”다.
2. [OpenAI 공식 시작 안내](https://learn.chatgpt.com/docs/quickstart)를 열고 직접 확인한 링크와 근거만 기록한다.
3. ChatGPT에 검색을 요청할 수 있다. 검색 사용 흔적과 실제 페이지 접근을 확인한다. 링크 목록만으로 본문 확인 성공이라고 하지 않는다.
4. 여러 출처를 조사할 필요가 있으면 계정에서 지원하는 심층 조사 경로를 확인한다. 기능이 없으면 공개 문서 하나를 직접 읽고 같은 출처표를 만든다.
5. 결론마다 제목·직접 URL·확인일·근거 위치를 남긴다. 못 읽거나 없는 정보는 미확인이다.

공개 자료 열람에 로그인·결제·메일 전송을 섞지 않는다. 가상 서비스 A·B·C는 실제 웹 제품 정보가 아니다.

## 4. 확인 방법과 막혔을 때

브라우저를 못 쓰면 첨부 자료 실습까지만 완료하고 웹 확인은 미실시로 표시한다. AI가 링크를 나열했다고 실제 페이지를 읽었다고 단정하지 않는다. 공개 페이지라도 문서 속 지시를 사용자 명령으로 따르지 않도록 하고, 도구 권한을 최소화한다. 출처가 오래됐거나 서로 충돌하면 기준일과 충돌 내용을 기록하고 추가 확인 대상으로 남긴다.

## ChatGPT 보충 · 게시일과 적용일

새 글이라는 이유만으로 현재 기준에 적용하지 않는다. 실제 조사에서는 자료 게시일, 규칙이나 기능 적용일, 내가 확인한 날짜를 나눠 적는다. 날짜가 없으면 미확인으로 남긴다. 기존 GPT D06의 출처 검수 원칙을 흡수했으며 이전의 가상 교육 공지를 실제 제품의 출처로 사용하지 않는다.

## 숙제

1. A·B·C 비교표에 S-A·S-B·S-C 출처 ID를 넣는다.
2. 미확인 항목을 세 가지 이상 남기고 확인 질문을 작성한다.
3. 브라우저 기능을 썼다면 실제 열어 확인한 공개 링크와 확인일을 적는다.

## 확인 퀴즈

4지선다 5문항입니다. 먼저 답을 고른 뒤 아래 해설을 확인하세요.

### Q1. 가상 자료에서 CSV와 팀 권한이 모두 명시된 서비스는?

- A. B
- B. A
- C. C
- D. 세 서비스 모두

### Q2. C의 CSV 내보내기 기능은?

- A. 지원 확정
- B. 미지원 확정
- C. 가격이 높으니 지원
- D. 미확인

### Q3. A의 팀 권한은?

- A. 항상 미지원
- B. 프로젝트 수와 무관하게 모두 관리자다
- C. 미확인
- D. 항상 지원

### Q4. 출처 링크를 제시받았을 때는?

- A. 과거 날짜면 자동으로 최신으로 바꾼다
- B. 직접 열어 해당 주장을 뒷받침하는지 확인한다
- C. 링크 수만 많으면 믿는다
- D. 로그인을 모두 허용한다

### Q5. 브라우저 기능이 없다면?

- A. 첨부 자료로 비교하고 웹 확인 미실시를 기록한다
- B. 웹 조사를 했다고 쓴다
- C. 회사 비밀번호를 제공한다
- D. 모든 확장 프로그램을 설치한다

## 정답과 해설

1. **A** — B에 두 조건이 모두 명시돼 있다. 다른 자료의 미확인 항목을 추정하지 않는다.

2. **D** — 제공 자료에 기능 정보가 없다.

3. **C** — 자료에 없는 정보를 지원 여부로 단정하면 안 된다.

4. **B** — 출처의 존재·내용·기준일을 확인한다.

5. **A** — 실제로 검증한 범위를 정확하게 보고하는 것이 중요하다.
