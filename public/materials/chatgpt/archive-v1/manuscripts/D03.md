# [강좌] D03. 한 번에 정답 찾지 마라

> ChatGPT 웹 대화 중심 · 가짜 자료 실습 · 예상 25~40분
> 별도 터미널·API 키 없이 시작합니다. 기능이 없는 계정의 대체 실습도 포함합니다.

## 3줄요약

1. 수정 대화에서도 원문 사실과 확정 조건을 지킵니다.

2. 가짜 자료로 직접 실행하고 원문·기대 결과를 대조합니다.

3. 기능이 없으면 제공된 대체 실습으로 같은 검수 기준을 확인합니다.

## 1. 초안은 출발점

첫 답이 길거나 딱딱하다고 실패가 아닙니다. 초안을 놓고 구체적으로 수정하면 됩니다. "이상해"보다 "첫 문장을 줄이고 신청 기한은 마지막 문장으로 이동"이 행동을 알려 줍니다.

다만 고치라는 요청이 쌓이면서 앞서 맞았던 사실이 바뀔 수 있습니다. 날짜·금액·이름처럼 고정할 내용을 먼저 적고, 이번에는 표현만 바꿀 것인지 내용까지 바꿀 것인지 구분하세요.

## 2. 한 번에 하나씩 바꾸는 이유

내용, 길이, 말투를 한꺼번에 크게 바꾸면 무엇 때문에 결과가 좋아졌는지 알기 어렵습니다. 교육 안내를 먼저 짧게 만들고, 다음에 정중한 말투로 다듬어 보세요. 각 단계에서 핵심 사실이 유지됐는지 확인합니다.

같은 문서의 두 안을 A안·B안이라고 부르고 목적에 맞는 것을 고르면 좋습니다. 양쪽의 장점을 합칠 때도 "시간·정원·미정 항목은 원문대로"라는 조건을 다시 줍니다.

## 3. 대화가 길어지면 확정 요약을 남기기

이전 대화를 무제한 정확하게 기억한다고 가정하지 마세요. 중간에 폐기한 아이디어와 확정한 결정을 구분한 짧은 인계문을 만듭니다. 최종 목적·원자료·고정 사실·남은 질문·최신 초안이 있으면 새 대화에서도 작업을 이어 가기 쉽습니다.

새 대화가 이전 파일이나 맥락을 자동으로 모두 가져온다고 생각하면 안 됩니다. 필요한 원자료와 확정 요약을 직접 다시 제공하세요. 프로젝트를 활용하는 방법은 D08에서 다룹니다.

## 4. 수정 요청에도 검수가 붙는다

AI에게 바뀐 점 표를 요구하는 것은 편리하지만 그것 역시 AI의 출력입니다. 원문과 수정본을 직접 펼쳐 고정 사실을 확인하세요. 최종본이 확정되면 파일 이름에 버전이나 날짜를 넣어 보관합니다.

이전 초안에서 만들어 낸 오류가 뒤 대화에서 사실처럼 굳어질 수 있습니다. 발견한 오류는 원문 근거와 함께 명시적으로 정정합니다. "앞서 20명이라고 한 내용은 오류, 원문 정원 12명으로 복구"처럼 쓰세요.

## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
D02에서 만든 안내를 두 안으로 고쳐 줘.
A안은 세 문장의 친근한 안내, B안은 세 문장의 정중한 안내.
2026-12-03 14:00~15:00, 정원 12명, 신청 기한 2026-12-01은 고정.
접속 링크와 녹화 여부는 미정으로 유지. 형식과 표현만 바꿔 줘.
[원문과 현재 초안 붙여 넣기]
```

### 이어서 보낼 요청

```text
B안을 선택할게. 신청 기한을 마지막 문장에 놓아 줘.
원문 대비 유지된 사실과 바뀐 표현을 구분해 줘.
이후 새 대화에 붙일 확정 요약도 별도로 만들어 줘.
```

## 6. 기대 결과와 직접 검수

- [ ] 두 안 모두 같은 교육일·정원·미정 상태를 갖습니다.
- [ ] 선택한 수정안에서 신청 기한이 마지막 문장에 있습니다.
- [ ] 인계문에 확정 사실·원문·남은 미정 사항이 있고 폐기한 안이 섞이지 않습니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 날짜가 슬쩍 바뀜 | 원문 날짜를 인용해 정정하고 전체 고정 항목을 다시 대조합니다. |
| 새 대화가 내용을 모름 | 확정 요약과 원자료를 직접 붙입니다. |
| 수정이 끝없이 반복됨 | 수락 기준을 3개로 정하고 통과하면 최종본으로 저장합니다. |

## 숙제

초안→길이 수정→말투 수정의 세 버전을 저장하세요. 각 버전에서 고정 사실 5개가 유지됐는지 확인한 표를 작성하세요.

제출용 메모에는 사용 자료, 처음 생긴 문제, 수정 요청, 최종 확인 근거를 함께 적으세요.

## 확인 퀴즈

### Q1. 구체적인 수정 요청은?

- A. 다시 해
- B. 별로야
- C. 첫 문장을 줄이고 날짜는 유지해
- D. 알아서 완벽하게

### Q2. 수정할 때 고정할 항목은?

- A. 문장의 길이만
- B. 글자 색만
- C. 감탄사만
- D. 원문의 날짜·금액·정원

### Q3. 새 대화로 옮길 때는?

- A. 중요 맥락이 모두 자동 전달된다고 믿는다
- B. 확정 요약과 필요한 원자료를 제공한다
- C. 이전 오류도 확정한다
- D. 최종본을 삭제한다

### Q4. 변경점 표를 AI가 만들었다면?

- A. 원문과 수정본을 직접 대조한다
- B. 표 자체를 정답으로 본다
- C. 날짜 검수를 생략한다
- D. 원문을 버린다

### Q5. 이전 답의 정원이 틀렸다면?

- A. 틀린 수를 계속 쓴다
- B. 말투만 바꾼다
- C. 원문 근거로 바로잡고 다른 고정 사실도 확인한다
- D. 새 숫자를 추첨한다

## 정답과 해설

1. **C** — 고칠 위치와 유지 조건을 함께 지정합니다.
2. **D** — 사실을 표현 수정과 분리해야 합니다.
3. **B** — 새 대화에 필요한 근거를 직접 전달합니다.
4. **A** — 자기 검토 출력도 확인 대상입니다.
5. **C** — 오류가 대화의 전제로 굳지 않게 명시적으로 고칩니다.

## 념글 박제

> 수정 대화에서도 원문 사실과 확정 조건을 지킵니다. 답의 완성도는 직접 확인한 근거로 판단합니다.
