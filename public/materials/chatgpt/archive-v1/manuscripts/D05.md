# [강좌] D05. 엑셀·숫자 분석시키기

> ChatGPT 웹 대화 중심 · 가짜 자료 실습 · 예상 25~40분
> 별도 터미널·API 키 없이 시작합니다. 기능이 없는 계정의 대체 실습도 포함합니다.

## 3줄요약

1. 중복·누락·환불을 구분하고 40,000원을 대사합니다.

2. 가짜 자료로 직접 실행하고 원문·기대 결과를 대조합니다.

3. 기능이 없으면 제공된 대체 실습으로 같은 검수 기준을 확인합니다.

## 1. 합계보다 원본 구조부터

지출 CSV에는 헤더를 제외하고 6행이 있습니다. 거래번호 X002가 같은 내용으로 한 번 반복돼 있습니다. 먼저 행 수·열 이름·중복 기준을 확인하세요. 원본은 그대로 보관하고 정리본을 따로 만듭니다.

거래번호가 같아도 내용이 다르면 임의 삭제하면 안 됩니다. 이 자료에서는 X002의 날짜·분류·금액·설명이 모두 같으므로 한 건만 반영합니다. 원본 행 번호와 처리 사유를 남겨야 나중에 왜 빠졌는지 설명할 수 있습니다.

## 2. 빈칸은 0원이 아니다

X004의 금액은 빈칸입니다. 이는 0원이 확인됐다는 뜻이 아니라 금액을 아직 모른다는 뜻입니다. X005는 -5,000원으로 확인된 환불입니다. 음수를 지우거나 절댓값으로 바꾸면 합계가 틀립니다.

이 실습의 규칙은 완전 동일한 중복 한 줄 제외, 빈 금액은 미확인으로 별도 표시, 환불은 음수 유지입니다. 임의 추정이나 통화 변환은 하지 않습니다. 규칙을 정하기 전 "정리해 줘"만 요청하면 도구가 멋대로 판단할 수 있습니다.

## 3. 정답이 되는 계산을 직접 적기

확인된 순액은 12,000 + 18,000 + 15,000 - 5,000 = 40,000원입니다. 이는 미확인 금액 1건을 제외한 확인된 합계이며, 전체 지출이 확정됐다는 뜻은 아닙니다. 원본 숫자를 단순 합하면 중복 때문에 58,000원이 나옵니다. 이 차이 18,000원의 이유가 X002 중복입니다.

정리 후 거래는 고유 5건, 그중 금액 확인 4건과 미확인 1건입니다. 음료 순액 25,000원, 인쇄 15,000원, 장소 미확인으로 분리합니다. 검수는 계산 결과뿐 아니라 건수와 예외까지 맞아야 통과입니다.

## 4. 차트는 합계를 숨기는 장식이 아니다

분류별 표와 막대그래프를 요청할 수 있지만 장소 미확인 금액을 0원 막대로 표시하지 마세요. 확인된 금액만 그렸다는 주석을 붙입니다. 파일 생성 기능이 있으면 정리본·예외표·검수표를 별도 시트로 요청하고 실제 다운로드해 열어 봅니다.

차트나 파일을 만들 수 없다면 텍스트 표와 CSV 본문으로 같은 규칙을 확인합니다. "파일을 만들었다"는 말만 있고 실제 다운로드가 없으면 생성 완료로 보지 마세요. 수식·숫자·단위를 직접 확인하는 것이 핵심입니다.

## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
실습 지출 CSV를 정리해 줘. 원본은 변경하지 마.
1. 헤더 제외 행 수와 열, 중복 거래번호를 먼저 보고.
2. 거래번호와 모든 값이 같은 X002 중복은 한 줄만 반영하고 제외 내역 기록.
3. 빈 금액 X004는 미확인으로 남기고 합계 제외. 환불 음수 유지.
4. 정리표/예외표/분류별 확인 합계/원본 대사표를 만들어 줘.
5. 확인된 합계와 전체 확정 여부를 구분. 계산식과 건수도 표시.
파일 생성이 가능하면 별도 정리본으로, 불가능하면 표와 CSV 본문으로 제시해 줘.
[지출 CSV 전체를 첨부하거나 붙여 넣기]
```

### 이어서 보낼 요청

```text
중복 포함 원본 숫자 합계, 중복 제외 확인된 합계, 미확인 건수를 대조해 줘. 차트에는 미확인을 0원으로 넣지 말고 제외 이유를 주석으로 적어 줘.
```

## 6. 기대 결과와 직접 검수

- [ ] 원본 6행, 동일 중복 제외 1행, 정리 후 고유 거래 5건입니다.
- [ ] 확인 금액 4건과 미확인 1건이 구분됩니다.
- [ ] 원본 숫자 합 58,000원 - 중복 18,000원 = 확인된 순액 40,000원입니다.
- [ ] 음료 25,000원·인쇄 15,000원이며 장소는 미확인입니다. 미확인을 포함한 전체 합계는 아직 확정할 수 없습니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 58,000원이 나옴 | X002 중복을 제외했는지 확인합니다. |
| 50,000원이 나옴 | 환불 -5,000원을 +5,000원으로 바꿨는지 확인합니다. |
| 장소 0원으로 표시됨 | 빈칸은 미확인이라는 규칙을 다시 적용하고 전체 확정 표현을 고칩니다. |

## 숙제

정리표·예외표·검수표를 저장하세요. 다른 사람이 원본만 보고 40,000원과 미확인 1건을 재현할 수 있도록 처리 규칙을 적으세요.

제출용 메모에는 사용 자료, 처음 생긴 문제, 수정 요청, 최종 확인 근거를 함께 적으세요.

## 확인 퀴즈

### Q1. 이 실습의 빈 금액은?

- A. 0원 확정
- B. 미확인 금액
- C. 평균값 자동 입력
- D. 삭제할 행

### Q2. 정리 후 확인된 순액은?

- A. 58,000원
- B. 50,000원
- C. 40,000원
- D. 45,000원

### Q3. X002를 한 번만 반영하는 근거는?

- A. 금액이 크기 때문
- B. 날짜가 같기만 해서
- C. 설명이 짧아서
- D. 거래번호와 모든 값이 동일한 중복이어서

### Q4. 정리 후 고유 거래 5건 중 금액 미확인은?

- A. 1건
- B. 0건
- C. 2건
- D. 5건

### Q5. 40,000원의 올바른 설명은?

- A. 모든 지출의 확정 총액
- B. 미확인 1건을 제외한 확인된 순액
- C. 환불을 제외한 총액
- D. 원본 6행 단순 합

## 정답과 해설

1. **B** — 빈칸은 모르는 값이므로 0으로 대체하지 않습니다.
2. **C** — 12,000+18,000+15,000-5,000=40,000원입니다.
3. **D** — 번호와 내용 모두 같은 중복임을 확인했습니다.
4. **A** — X004 한 건의 금액이 비어 있습니다.
5. **B** — 미확인 금액이 있으므로 전체 총액은 확정할 수 없습니다.
