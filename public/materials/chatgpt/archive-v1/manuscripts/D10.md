# [강좌] D10. GPT가 틀렸을 때 + 졸업 실습

> ChatGPT 웹 대화 중심 · 가짜 자료 실습 · 예상 25~40분
> 별도 터미널·API 키 없이 시작합니다. 기능이 없는 계정의 대체 실습도 포함합니다.

## 3줄요약

1. 원본부터 보고서까지 만들고 오류·누락을 검증합니다.

2. 가짜 자료로 직접 실행하고 원문·기대 결과를 대조합니다.

3. 기능이 없으면 제공된 대체 실습으로 같은 검수 기준을 확인합니다.

## 1. 졸업 기준은 한 업무의 끝까지

도구 이름을 많이 아는 것보다 입력을 받고, 작업 범위를 정하고, 결과를 확인하고, 다른 사람에게 넘길 수 있어야 합니다. 오늘은 가짜 교육 준비 보고서 하나를 완성합니다. 입력은 교육 안내문·회의 메모·지출 CSV입니다.

산출물은 정리표, 예외표, 한 페이지 보고서, 메일 초안, 검수·인계 기록입니다. 실제 발송, 계정 연결, 공개 공유는 이번 졸업 범위가 아닙니다. 원본은 유지하고 결과를 별도 이름으로 저장합니다.

## 2. 틀린 답은 원인부터 좁히기

숫자가 틀렸다면 입력을 제대로 읽었는지, 중복 규칙이 맞는지, 계산이 틀렸는지, 보고서로 옮기며 바뀌었는지 나눠 봅니다. "다시 잘해"만 반복하면 원인을 알기 어렵습니다. 틀린 행과 기대값을 직접 알려 주고 최소 범위부터 수정합니다.

예를 들어 58,000원이 나오면 X002 중복 18,000원부터 확인합니다. 50,000원이 나오면 환불 부호를 확인합니다. 40,000원이 나와도 미확인 1건을 숨겼다면 실패입니다. 숫자 하나가 맞는 것과 보고서가 정확한 것은 다릅니다.

## 3. 일부러 오류가 있는 요약도 검수

자료실의 오류 찾기 초안은 정원 16명, 지출 확정 58,000원, 녹화 가능이라고 일부러 틀리게 썼습니다. 이를 원문과 대조해 정원 12명, 확인된 순액 40,000원과 미확인 1건, 녹화 미정으로 바로잡으세요.

AI가 "검토 완료"라고 한 것을 증거로 삼지 말고 원본 행·계산식·근거 문장을 붙입니다. 외부 최신 정보가 필요한 주장에는 실제 확인일과 출처가 있어야 합니다. 이번 보고서는 가짜 자료만으로 완성하므로 실제 웹 검색을 한 것처럼 적지 않습니다.

## 4. 인계에는 한계와 다음 행동이 들어간다

최종 파일 목록과 확인된 사실, 아직 미정인 사항, 검수 결과, 다음 담당자가 할 일을 남깁니다. 장소 비용·녹화·접속 링크가 미정이라는 사실이 다음 행동으로 이어져야 합니다. 

다음에 실제 자료로 활용할 때는 조직의 입력·저장·공유 규칙과 권한을 확인하세요. 가짜 자료로 연습한 도우미가 곧바로 모든 실제 업무에 안전하거나 정확한 것은 아닙니다. 날짜가 바뀌면 자료도 다시 읽고, 기능이 바뀌면 공식 안내도 다시 확인합니다.

## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
가짜 교육 준비 보고서를 완성해 줘. 제공한 세 자료만 사용.
입력: 교육 안내문, 회의 메모, 지출 CSV. 원본 변경 금지.
순서: 자료 목록·작업 범위 확인 → 지출 정리 → 보고서·메일 초안 → 검수·인계.
지출 규칙: 완전 동일 X002 중복 한 줄 제외, 빈 금액은 미확인, 환불 음수 유지.
산출물: 정리표, 제외·미확인 예외표, 한 페이지 보고서, 발송하지 않은 메일 초안, 검수표.
확인된 순액과 전체 확정 여부를 구분하고 근거·계산식·건수 표시.
없는 사실·실행하지 않은 검색·발송·설치를 완료했다고 쓰지 마.
[세 자료 전체 첨부 또는 붙여 넣기]
```

### 이어서 보낼 요청

```text
오류 찾기 초안의 각 주장을 원문으로 반박하고 수정해 줘:
“정원 16명, 지출 확정 58,000원, 녹화 가능.”
최종 결과에서 같은 오류가 남았는지도 확인하자.
인계문에 파일 목록/확인된 사실/미정 사항/검수 근거/다음 행동을 써 줘.
```

## 6. 기대 결과와 직접 검수

- [ ] 원본 6행→동일 중복 1행 제외→고유 5건, 확인 4건·미확인 1건입니다.
- [ ] 확인 순액 40,000원, 교육 정원 12명, 녹화·접속 링크 미정이 일치합니다.
- [ ] 가람·나래의 담당과 기한이 원문과 같고 메일은 초안입니다.
- [ ] 검수표는 실제 원문 행·근거·계산식을 가리킵니다.
- [ ] 미확인 장소 비용과 링크·녹화 확인을 다음 행동으로 남깁니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 합계만 맞고 예외가 없음 | 중복 제외 내역과 X004 미확인 건을 별도로 보고하게 합니다. |
| 검토 완료라는 말만 있음 | 행 번호·계산식·근거 문장을 요구하고 직접 확인합니다. |
| 결과 파일이 안 열림 | 실제 파일 존재와 확장자를 확인하고 지원되지 않으면 MD·CSV로 저장합니다. |

## 숙제

다섯 산출물을 완성하고 아래 수락 기준을 스스로 채점하세요. 한 항목이라도 틀리면 관련 원문으로 돌아가 수정한 뒤 다시 검수하세요.

제출용 메모에는 사용 자료, 처음 생긴 문제, 수정 요청, 최종 확인 근거를 함께 적으세요.

## 확인 퀴즈

### Q1. 졸업 결과가 정확하려면?

- A. 합계만 맞으면 됨
- B. 확인 합계와 미확인·제외 내역을 함께 보고
- C. 문장 길이만 맞춤
- D. AI 완료 선언만 필요

### Q2. 58,000원이 나왔다면 먼저 볼 곳은?

- A. 정원
- B. 메일 제목
- C. X002 중복 처리
- D. 개인화 말투

### Q3. 오류 초안의 녹화 가능은?

- A. 원문 녹화 미정으로 수정
- B. 항상 유지
- C. 신청 기한으로 대체
- D. 외부 링크를 임의 생성

### Q4. 다음 담당자에게 넘길 내용은?

- A. 최종 문장만
- B. 과장된 성과만
- C. 모든 것이 완료됐다는 말
- D. 파일·확인 사실·미정·검수 근거·다음 행동

### Q5. AI의 검토 완료라는 표현은?

- A. 독립 증거로 충분
- B. 원본·계산식 대조로 확인해야 함
- C. 오류가 없다는 보증
- D. 실제 발송 완료를 의미

## 정답과 해설

1. **B** — 결과·예외·검수 근거를 함께 남깁니다.
2. **C** — 원본 단순 합계에서 중복 18,000원을 제외해야 합니다.
3. **A** — 제공 자료의 미정 상태가 기준입니다.
4. **D** — 인계에는 남은 일과 한계도 필요합니다.
5. **B** — 주장과 검증 증거를 구분합니다.

## 념글 박제

> 원본부터 보고서까지 만들고 오류·누락을 검증합니다. 답의 완성도는 직접 확인한 근거로 판단합니다.
