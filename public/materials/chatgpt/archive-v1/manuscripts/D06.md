# [강좌] D06. 자료 조사, 출처부터 확인

> ChatGPT 웹 대화 중심 · 가짜 자료 실습 · 예상 25~40분
> 별도 터미널·API 키 없이 시작합니다. 기능이 없는 계정의 대체 실습도 포함합니다.

## 3줄요약

1. 최신 정보는 직접 출처를 열어 주장과 연결합니다.

2. 가짜 자료로 직접 실행하고 원문·기대 결과를 대조합니다.

3. 기능이 없으면 제공된 대체 실습으로 같은 검수 기준을 확인합니다.

## 1. 검색이 필요한 질문과 아닌 질문

주어진 안내문 요약은 원문만으로 할 수 있습니다. 반면 현재의 서비스 기능이나 최근 공지는 시간이 지나면 바뀌므로 최신 출처를 확인해야 합니다. 질문의 범위와 기준일을 먼저 정하세요. "좋은 도구 추천"보다 "오늘 확인한 공식 안내에서 파일 입력 지원 여부 찾기"가 검증하기 쉽습니다.

검색 기능이 있는 환경에서는 검색을 요청하고, 기능이 없으면 직접 공식 페이지를 열어 필요한 부분을 제공하세요. 실제로 웹을 확인하지 않았다면 검색했다고 적지 않습니다. 실습용 가상 문서는 현실의 서비스 정보를 증명하지 못합니다.

## 2. 링크가 붙었다고 근거가 되는 것은 아님

출처가 해당 주장을 직접 뒷받침하는지 본문을 열어 확인합니다. 홈페이지 주소만 있거나 검색 결과의 짧은 설명만 있다면 부족할 수 있습니다. 제목·발행 주체·게시일·적용일·확인일을 구분해 적으세요.

자료실의 가상 공지 A는 2026년 11월 10일 게시됐지만 교육 인원 변경은 12월 10일 적용입니다. 가상 공지 B는 11월 12일 게시됐고 12월 1일부터 교육실을 예약할 수 있다는 내용입니다. 게시일이 더 최근이라고 모든 항목의 기준이 바뀌는 것은 아닙니다.

## 3. 심층 조사는 결과물의 범위를 정한 뒤

계정에서 심층 조사 또는 관련 조사 도구가 보이면 범위·기간·선호 출처·결과 표를 먼저 정합니다. 버튼 이름과 제공 여부는 달라질 수 있습니다. 기능이 없어도 공식 문서 두 개를 직접 읽고 같은 출처표를 만들 수 있습니다.

긴 보고서일수록 출처가 많다는 이유로 신뢰하지 마세요. 핵심 주장 두세 개부터 대조하고 접근하지 못한 자료는 미확인으로 남깁니다. 자료들끼리 충돌한다면 적용 대상과 시점을 비교하고 결론을 보류할 수도 있습니다.

## 4. 오프라인 연습과 실제 조사를 구분

먼저 가상 공지 두 개로 날짜 구분을 연습하고, 다음에 실제 공식 문서 하나로 출처표를 만듭니다. 가상 공지를 실제 웹 출처처럼 인용하거나 존재하지 않는 URL을 만들면 실패입니다.

실제 조사에서는 확인한 URL과 날짜를 직접 기록합니다. 인용은 필요한 짧은 문장으로 제한하고 주된 결과는 자신의 말로 요약합니다. 모르는 항목 하나를 명시한 짧은 보고서가 추측으로 빈칸을 채운 긴 보고서보다 실무에 유용합니다.

## 5. 직접 해 보기

예상 15~25분. 먼저 [실습 자료실](/chatgpt-materials)에서 필요한 자료를 열어 보세요. 원문이 필요한 요청의 대괄호 부분은 실제 자료 전체로 바꿉니다.

1. 새 대화에서 원자료를 확인합니다.
2. 아래 요청을 붙이고 답을 받습니다.
3. 이어지는 수정 요청을 보냅니다.
4. 기대 결과와 대조하고 결과를 별도 MD·CSV로 저장합니다.

```text
자료실의 가상 공지 A·B만으로 날짜 읽기 연습을 해 줘.
기준일: 2026-12-03. 두 자료는 실습용이며 실제 웹 검색 결과가 아님.
질문: 이날 정원은 몇 명인가? 새 정원은 언제부터인가? 예약 개시일은?
표: 주장/근거 문장/게시일/적용일/기준일에 맞는 결론/미확인.
존재하지 않는 URL을 만들지 말고 자료 A·B로 표시해 줘.
[가상 공지 A·B 전체 붙여 넣기]
```

### 이어서 보낼 요청

```text
이제 ChatGPT 공식 문서 https://learn.chatgpt.com/docs/image-inputs 를 직접 열어 이미지 입력 안내를 확인하자. 검색·접근이 가능한 경우에만 확인한 내용과 직접 URL·확인일을 기록해 줘. 접근하지 못하면 못 했다고 말해 줘. 나는 링크를 직접 열어 주장과 본문을 대조할게.
```

## 6. 기대 결과와 직접 검수

- [ ] 가상 공지 기준 12월 3일 정원은 기존 12명이며 새 정원 16명은 12월 10일부터입니다.
- [ ] 교육실 예약 개시일은 12월 1일입니다. 게시일과 혼동하지 않습니다.
- [ ] 가상 자료는 실제 웹 출처와 분리됩니다. 실제 페이지는 직접 열어 확인한 항목만 기록합니다.

AI가 스스로 맞다고 평가한 문장만으로 통과 처리하지 마세요. 원자료를 열어 값과 근거를 확인합니다. 실제 지원 기능이 없는 경우 표·MD 본문으로 검수하고 기능을 실행한 것처럼 기록하지 않습니다.

## 7. 막혔을 때

| 증상 | 확인과 수정 |
| --- | --- |
| 검색이 안 됨 | 직접 공식 페이지를 열어 발췌를 제공하고 접근하지 못한 범위를 명시합니다. |
| 최신 글이니 무조건 적용이라 함 | 게시일과 적용일, 기준일을 별도 열로 다시 확인합니다. |
| 출처 링크가 다른 내용임 | 해당 주장을 미확인으로 돌리고 직접 뒷받침하는 출처를 찾습니다. |

## 숙제

가상 자료 날짜표와 실제 공식 문서 출처표를 따로 저장하세요. 실제 표에는 확인한 주장 2개, 직접 URL, 확인일, 접근하지 못한 범위를 남기세요.

제출용 메모에는 사용 자료, 처음 생긴 문제, 수정 요청, 최종 확인 근거를 함께 적으세요.

## 확인 퀴즈

### Q1. 출처 검수에서 필요한 행동은?

- A. 링크 개수만 센다
- B. 공식처럼 보이면 믿는다
- C. 본문이 주장을 뒷받침하는지 직접 확인한다
- D. 검색 제목만 복사한다

### Q2. 12월 3일 가상 교육 정원은?

- A. 16명
- B. 12명
- C. 20명
- D. 미정이므로 임의 선택

### Q3. 가상 공지에 없는 실제 URL은?

- A. 만들어 넣는다
- B. 비슷한 회사 링크 사용
- C. 검색했다고 쓴다
- D. 추측해서 만들지 않는다

### Q4. 심층 조사 기능이 없다면?

- A. 직접 자료를 열어 같은 검수표를 만든다
- B. 조사 완료라고 쓴다
- C. 출처를 생략한다
- D. 접근 권한을 공유한다

### Q5. 게시일과 적용일은?

- A. 항상 같다
- B. 최근 게시일이 무조건 우선이다
- C. 서로 다를 수 있어 따로 확인한다
- D. 기준일과 관계없다

## 정답과 해설

1. **C** — 출처와 주장 사이의 연결을 확인해야 합니다.
2. **B** — 16명 변경은 12월 10일부터 적용됩니다.
3. **D** — 가상 자료는 실제 웹 근거가 아닙니다.
4. **A** — 조사의 핵심은 기능 버튼보다 근거 확인입니다.
5. **C** — 언제 공개했는지와 언제 효력이 시작되는지는 다를 수 있습니다.

## 념글 박제
