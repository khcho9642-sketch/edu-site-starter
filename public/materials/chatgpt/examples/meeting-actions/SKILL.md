# 회의 메모 정리 절차

이 파일은 교육용 예시입니다. 예시 폴더에 존재하는 것만으로 스킬이 등록·호출되는 것은 아닙니다.

## 입력

요청에 명시한 회의 메모 파일을 읽습니다. 파일 경로와 실제 접근 가능 여부를 확인합니다.

## 순서

1. 항목ID와 실행·보류·논의를 구분합니다.
2. 담당자·기한은 원문 값만 사용하고 없으면 미정으로 둡니다.
3. 실행할 일은 항목ID·할 일·담당자·기한·상태·근거ID 표로 정리합니다.
4. 보류·논의는 별도 표로 둡니다.
5. 실행 수·담당자 미정 수·기한 미정 수·보류 수를 요약합니다.
6. 원본을 바꾸지 않고 요청한 출력 경로에 별도 결과를 저장합니다.
7. 저장할 수 없으면 본문만 제공했음을 기록합니다.

## 금지와 완료 기준

원문에 없는 담당자·기한을 추가하지 않습니다. 메일·예약·외부 서비스 변경을 하지 않습니다.
모든 결과에서 원문 근거ID를 확인할 수 있어야 합니다. 호출 여부와 결과 검수는 별도로 기록합니다.

항목ID 열과 근거ID 열 모두 원문의 ID를 그대로 유지합니다. M01→A01, N01→B01처럼 새 번호로 바꾸지 않습니다.
